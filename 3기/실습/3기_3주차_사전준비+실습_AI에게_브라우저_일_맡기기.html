복사해서 붙여넣는 법 (매번 똑같습니다)

  1. 회색 상자 위의 초록색 「복사」 단추를 한 번 누릅니다. 옆에 “복사했습니다”가 뜨면 된 것입니다.
  2. ChatGPT 앱의 맨 아래 입력창을 한 번 클릭합니다.
  3. Ctrl + V → 상자의 글이 통째로 들어옵니다. 고치지 않습니다. (상자 아래에 “바꿔도 된다”고 적힌 부분만 바꿔도 됩니다.)
  4. Enter → Codex가 일을 시작합니다.

키 두 개를 함께 누르는 법: 「Ctrl + V」는 앞의 키(Ctrl)를 누른 채로 뒤의 키(V)를 누르라는 뜻입니다. Ctrl + C는 복사, Ctrl + V는 붙여넣기입니다.

어느 채팅에 붙여넣나요?

  • 준비 3은 준비 1에서 연 채팅에 붙여넣습니다.
  • 준비 4부터 실습 끝까지는 준비 4에서 새로 연 채팅 하나에 이어서 붙여넣습니다. 그래야 Codex가 앞에서 만든 것을 기억합니다.
  • 한 상자를 붙여넣은 뒤에는 Codex가 결과를 알려 줄 때까지 기다렸다가 다음 상자로 갑니다.

Codex가 “해도 될까요?”라고 물으면

앱 설정에 따라 허락 창(「한 번만 허용」·「이 대화 허용」·「거부」)이 뜰 수 있습니다. 무슨 작업인지 모르겠으면 Codex에게 쉬운 말로 설명해 달라고 한 뒤 허용하세요.

  • Codex가 설명한 설치·확인 작업이면 「한 번만 허용」을 누릅니다.
  • “파일을 삭제”하겠다는 내용이면 누르지 말고 “왜 지워야 해? 지우지 않는 방법으로 해 줘.”라고 씁니다.
  • 화면이 어두워지며 「이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?」가 뜨면 Windows 창입니다. 준비 1·2에서 내가 설치 파일을 실행했을 때, 그리고 Codex가 방금 “관리자 권한이 필요합니다”라고 말한 직후에만 「예」, 아무 일도 안 시켰는데 뜨면 「아니요」. 새 계정·결제·보안 기능 끄기를 요구하면 진행하지 말고 허브에 질문하세요.
내가 직접 하는 일: 프로그램 두 개 설치 · 내 계정으로 로그인 · 본인 인증 · 로봇 확인(“로봇이 아닙니다” 같은 그림 맞히기, 캡차). Aside 계정 만들기 말고는 가입·결제·카톡 발송을 하지 않습니다. 나머지는 AI가 합니다.
화면 배치 팁: 줌 화면은 작게 줄이고, ChatGPT 앱과 Aside 창을 나란히 놓으면 보기 편합니다. Aside 창이 안 보이면 작업 표시줄(화면 맨 아래 줄)에서 Aside를 누르세요.
준비 1 · 내가 합니다

ChatGPT 앱 설치하고 로그인하기 (10분)

지난주까지 ChatGPT 앱으로 Codex를 쓰고 있었다면 「설치하기」·「로그인하기」는 건너뛰고 아래 「Codex 채팅 열기」부터 하세요. 있는지 모르겠으면 키보드의 Windows 키(창문 모양, 왼쪽 아래)를 한 번 누르고 ChatGPT라고 칩니다. 검색 결과에 ChatGPT 앱이 보이면 설치된 것입니다.

브라우저(크롬·엣지)에서 여는 chatgpt.com과는 다른 것입니다. 컴퓨터에 프로그램으로 설치하는 ChatGPT 앱 안에 Codex(내 컴퓨터를 직접 만져 주는 AI)가 들어 있습니다.

설치하기

  1. 아래 주소를 누릅니다. 설치 파일이 다운로드 폴더에 저절로 받아집니다.
    👉 https://get.microsoft.com/installer/download/9PLM9XGG6VKS?cid=website_cta_psi
  2. 받은 파일을 두 번 클릭해 실행합니다. (브라우저 오른쪽 위 또는 아래쪽에 받은 파일이 보입니다. 안 보이면 Windows + E → 왼쪽 다운로드에서 찾습니다.)
  3. Microsoft Store 창이 열리면 「설치」를 누르고 끝날 때까지 기다립니다.
  4. 「열기」를 누릅니다. 다음부터는 Windows 키 → ChatGPT 입력 → Enter로 엽니다.

위 주소가 안 열리면 Microsoft Store 앱을 열어 ChatGPT를 검색하고, 만든 곳이 OpenAI인 앱을 설치하세요.

로그인하기

  1. 앱이 열리면 로그인을 누릅니다.
  2. 평소 쓰는 ChatGPT 유료 계정으로 로그인합니다. 구글 계정으로 가입했다면 「Google로 계속하기」를 누릅니다.
  3. 로그인 화면이 인터넷 창으로 열릴 수도 있습니다. 거기서 로그인하면 앱으로 돌아옵니다. 비밀번호·인증 번호는 직접 입력합니다.

Codex 채팅 열기

  1. 앱 왼쪽 메뉴에서 「Codex」를 한 번 누르고, 「새 채팅」을 누릅니다.
  2. 폴더를 고르라고 하면: 폴더 고르는 창 왼쪽에서 문서를 누릅니다. 빈 곳을 마우스 오른쪽 단추로 누르고 → 새로 만들기 → 폴더. 이름 칸에 ai-practice를 치고 Enter. 그 폴더를 한 번 누르고 「폴더 선택」. “이 폴더를 신뢰할까요?”라고 물으면 「폴더 신뢰」(내가 방금 만든 빈 폴더라 안전합니다).
  3. 화면 맨 아래에 글 쓰는 칸(입력창)이 보이면 아래 상자를 붙여넣어 봅니다.
안녕. 나는 컴퓨터를 잘 몰라. 앞으로 쉬운 말로 짧게 대답해 줘.

Codex가 대답하면 준비 1 끝입니다. 이 채팅은 준비 3에서 이어서 씁니다. ChatGPT 앱은 켜 둔 채 준비 2로 갑니다. 혹시 앱을 껐다면 다시 열고 Codex → 왼쪽 목록에서 방금 채팅을 누르면 그대로 있습니다. 앱이 안 열리거나 왼쪽에 Codex가 안 보이면 「잘 안될 때」의 표를 보세요.

준비 2 · 내가 합니다

Aside 설치하고 내 계정으로 로그인하기 (10분)

Aside를 이미 설치하고 내 계정으로 로그인했다면(심화실습 #3 등에서) 건너뛰고 준비 3으로 가세요.

Aside는 Codex가 쓰는 AI용 브라우저입니다. 크롬·엣지 같은 인터넷 창인데, Codex가 이 창을 직접 움직일 수 있습니다. 설치와 로그인은 내 계정이 필요해서 직접 합니다.

Aside 화면은 영어로 나옵니다. 아래에 누를 글자를 영어 그대로 적어 두었습니다. 그 글자만 찾아 누르면 됩니다.

설치하기

  1. 아래 주소를 엽니다. 내 컴퓨터에 맞는 설치 파일이 저절로 받아집니다.
    👉 https://aside.com/download
  2. 받은 파일을 두 번 클릭해 설치합니다. 「이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?」가 뜨면 「예」.
  3. 설치가 끝나면 Aside가 열립니다. 안 열리면 Windows 키 → Aside 입력 → Enter.

Aside 계정 만들기

  1. Aside가 처음 열리면 로그인(Sign in) 화면이 나옵니다. 계정이 없으면 새로 만듭니다. ChatGPT에 쓰는 것과 같은 구글 계정이나 이메일로 만들면 기억할 것이 줄어듭니다.
  2. 이어서 다른 브라우저의 데이터 가져오기(Import), 비밀번호 관리자(Password Manager) 설정 화면이 나옵니다. 오늘은 필요 없습니다. 「Skip」(건너뛰기)이 보이면 누르고 넘어갑니다.
Aside 결제나 새 API 키는 필요 없습니다. 이번에는 ChatGPT 앱의 Codex가 Aside를 직접 읽고 클릭합니다. Aside 창 안에 있는 AI(설정의 Models·Providers 연결)는 쓰지 않습니다.

로그인까지 했으면 Aside 창은 켜 둔 채 ChatGPT 앱으로 돌아갑니다.

준비 3 · Codex가 합니다

상자 하나로 나머지 준비 (10~15분)

준비 1에서 연 Codex 채팅에 붙여넣습니다. Codex가 aside 명령(CLI)과 Aside 사용법(스킬)을 설치하고, 앞으로 웹 일은 Aside로 하되 내 다른 작업을 방해하지 않는다는 규칙(전역 지침)을 적어 둡니다. 허락 창이 뜨면 「먼저 읽기」의 기준대로 누릅니다.

아래 상자는 Codex가 읽는 글입니다. 모르는 말이 많아도 괜찮습니다. 읽지 말고, 복사해서 붙여넣기만 하세요.
나는 컴퓨터 초보자다. Windows PC에 ChatGPT 앱을 설치해 로그인했고, Aside 브라우저를 설치해 내 Aside 계정으로 로그인했다. 이번 실습은 Codex가 aside repl로 직접 조작하며 Aside 안의 별도 AI에게 맡기지 않는다.

이 컴퓨터에서 네가 직접 다음을 해 줘. 내가 할 일은 최소로 줄여 줘.
1. Aside CLI를 설치해 줘. 먼저 PowerShell에서 Test-Path "$env:LOCALAPPDATA\Aside\CLI\current\aside.exe" 로 이미 있는지 보고, True면 다시 설치하지 말고 공식 업데이트(--update)만 확인해 줘. False면 맨 아래 [Aside 공식 Windows 설치 명령]을 PowerShell에서 그대로 실행해 줘. 아직 Aside가 없어서 하는 설치이니 PowerShell로 공식 주소에서 내려받으면 돼. 서명 확인을 빼거나 Windows 보안을 끄지 마. 설치 직후 aside 라고만 쳐서 안 잡히면 ChatGPT 앱이 설치 전부터 켜져 있어 새 경로를 아직 모르는 것이니, 위의 전체 경로로 실행해 확인해 줘.
2. aside --update, aside guide, aside account list 를 실행해서 CLI가 작동하고 내 Aside 계정이 로그인돼 있는지 확인해 줘. Aside 계정 로그인과 대상 웹사이트 로그인은 별개임을 알려 줘. 이번 직접 조작 실습을 위해 ChatGPT Subscription 연결·새 API 키·Aside 결제를 요구하지 마.
3. Codex가 실제로 읽는 사용자 skills 폴더에 aside-browser 스킬을 설치해 줘. 현재 공식 문서의 사용자 경로(~/.agents/skills 또는 Windows의 해당 사용자 홈)를 확인하고 설치해 줘. 잘못된 위치에 파일만 두고 설치됐다고 하지 마. Aside가 공식으로 제공하는 방법을 먼저 찾고, 없으면 "Aside를 쓰기 전에 aside --update 와 aside guide 를 실행해 읽고 그대로 따른다"는 내용의 작은 SKILL.md를 만들어 줘. 출처가 불분명한 다른 사람의 설치 스크립트는 쓰지 마. 스킬 파일 경로와 새 채팅에서 읽는 방법을 확인해 줘.
4. Codex가 실제로 쓰는 전역 지침 파일(전역 AGENTS.md, CODEX_HOME이 다르면 그 실제 홈)을 찾아서, 원래 있던 내용은 그대로 두고 아래 규칙을 덧붙여 줘. 특정 프로젝트 폴더의 파일에 적고 끝내지 마.
   "웹사이트를 열고, 읽고, 입력하고, 결과를 확인하는 모든 웹 작업은 Aside(aside CLI와 aside-browser 스킬)로 한다. 쓰기 전에 aside --update 와 aside guide 를 실행해 읽는다. 스터디 실습에서는 Codex가 aside repl로 직접 읽고 클릭한다. aside exec, aside "할 일", aside URL처럼 Aside 안의 AI 작업을 시작하는 명령은 사용하지 않는다. 웹 읽기·클릭과 결과 열기는 aside repl 안에서 한다(같은 주소가 이미 열려 있으면 새로 열지 말고 새로고침한다). Aside가 안 되면 다른 브라우저로 바꾸지 말고 먼저 나에게 알린다. 단, Aside CLI 자체를 설치·업데이트·복구할 때는 Aside 공식 주소(releases.aside.com, docs.aside.com)를 PowerShell로 내려받아도 된다."

다 본 뒤 — 이번에 연 탭 닫기

결과를 다 봤으면 같은 채팅에 보냅니다. AI가 연 탭만 닫고, 내가 원래 열어 둔 탭은 그대로 둡니다.

그 탭들을 연 지속 세션에서 닫고, 내가 원래 열어 둔 탭은 건드리지 마. 로컬 서버는 그대로 둬도 돼(결과를 다시 열 수 있게).
닫은 뒤 listBrowserTabs로 그 탭들이 실제로 사라졌는지 다시 확인해. 닫은 탭 수와 지속 세션을 끝냈는지 알려 주고, 남은 탭이 있으면 그 제목과 주소를 알려 줘. 내가 직접 닫을게.

AI가 닫지 못한 탭이 있다고 하면 Aside에서 그 탭의 × 단추로 직접 닫습니다. 결과 파일은 실습 폴더에 그대로 남습니다.
