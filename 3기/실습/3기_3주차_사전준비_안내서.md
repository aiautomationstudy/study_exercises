## 1단계. ChatGPT 앱 설치하고 로그인하기

> **이미 설치하고 로그인했으면 2단계로 가세요.**

브라우저(크롬·엣지)에서 여는 chatgpt.com 과는 **다른 것**입니다. 컴퓨터에 **프로그램으로 설치하는 ChatGPT 앱** 안에 **Codex**(내 컴퓨터를 직접 만져 주는 AI)가 들어 있습니다. 앞으로 회색 상자는 전부 이 앱에 붙여넣습니다.

### 1-1. 설치하기

1. 아래 주소를 누릅니다. 설치 파일이 **다운로드 폴더**에 저절로 받아집니다.
   👉 https://get.microsoft.com/installer/download/9PLM9XGG6VKS?cid=website_cta_psi
2. 받은 파일을 **두 번 클릭**해 실행합니다. (브라우저 오른쪽 위 또는 아래쪽에 받은 파일이 보입니다. 안 보이면 **Windows 키 + E** → 왼쪽 **다운로드**에서 찾습니다.)
3. **Microsoft Store** 창이 열리면 **「설치」** 를 누르고 끝날 때까지 기다립니다.
4. **「열기」** 를 누릅니다. 다음부터는 **Windows 키 → `ChatGPT` 입력 → Enter** 로 엽니다.

> 위 주소가 안 열리면 **Microsoft Store** 앱을 열어 `ChatGPT` 를 검색하고, 만든 곳이 **OpenAI**인 앱을 설치하세요.

### 1-2. 로그인하기

1. 앱이 열리면 **로그인** 을 누릅니다.
2. 평소 쓰는 **ChatGPT 유료 계정**으로 로그인합니다. 구글 계정으로 가입했다면 **「Google로 계속하기」** 를 누릅니다.
3. 로그인 화면이 인터넷 창으로 열릴 수도 있습니다. 거기서 로그인하면 앱으로 돌아옵니다. 비밀번호·인증 번호는 **직접** 입력합니다.
4. 대화 화면이 보이면 끝입니다.

### 1-3. Codex 열어 보기

1. 앱 **왼쪽 메뉴**에서 **「Codex」** 를 한 번 누릅니다.
2. **「새 채팅」** 을 누릅니다.
3. 화면 **맨 아래에 글 쓰는 칸(입력창)** 이 보이면 준비 끝입니다.

입력창을 한 번 클릭하고 이렇게 쳐서 **Enter** 를 눌러 보세요.

```text
안녕. 나는 컴퓨터를 잘 몰라. 앞으로 쉬운 말로 짧게 대답해 줘.
```

(짧으니 직접 쳐도 되고, 복사해서 붙여넣어도 됩니다.)

Codex가 대답하면 1단계 성공입니다. **ChatGPT 앱은 끄지 말고 그대로 두세요.** 3단계에서 이 채팅에 이어서 씁니다. 혹시 껐다면 다시 열고 **Codex** → 왼쪽 목록에서 방금 채팅을 누르면 그대로 있습니다.

> **「새 채팅」을 눌렀더니 폴더를 고르라고 하면:** 폴더 고르는 창 왼쪽에서 **문서**를 누릅니다. 창 안의 **빈 곳을 마우스 오른쪽 단추로 누르고 → 새로 만들기 → 폴더**를 고릅니다. 이름 칸에 `ai-setup` 을 치고 Enter. 그 폴더를 한 번 누르고 **「폴더 선택」**. “이 폴더를 신뢰할까요?”라고 물으면 **「폴더 신뢰」**(내가 방금 만든 빈 폴더라 안전합니다).

## 2단계. Aside 설치하고 내 계정으로 로그인하기

**Aside**는 Codex가 쓰는 **AI용 브라우저**입니다. 크롬·엣지 같은 인터넷 창인데, Codex가 이 창을 직접 움직일 수 있습니다. 설치와 로그인은 **내 계정**이 필요해서 직접 합니다.

> Aside 화면은 **영어**로 나옵니다. 아래에 누를 글자를 영어 그대로 적어 두었습니다. 그 글자만 찾아 누르면 됩니다.

### 2-1. 설치하기

1. 아래 주소를 엽니다. 내 컴퓨터에 맞는 설치 파일이 **저절로** 받아집니다.
   👉 https://aside.com/download
2. 받은 파일을 **두 번 클릭**해 설치합니다. 「이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?」가 뜨면 **「예」**.
3. 설치가 끝나면 Aside가 열립니다. 안 열리면 **Windows 키 → `Aside` 입력 → Enter**.

### 2-2. Aside 계정 만들기

1. Aside가 처음 열리면 **로그인(Sign in)** 화면이 나옵니다. 계정이 없으면 **새로 만듭니다**. **ChatGPT에 쓰는 것과 같은 구글 계정이나 이메일**로 만들면 기억할 것이 줄어듭니다.
2. 이어서 **다른 브라우저의 데이터 가져오기(Import)**, **비밀번호 관리자(Password Manager)** 설정 화면이 나옵니다. 오늘은 필요 없습니다. **「Skip」(건너뛰기)** 이 보이면 누르고 넘어갑니다.

> 이번 실습에서는 **Aside 결제나 새 API 키를 추가하지 않습니다.** 이번 실습은 ChatGPT 앱의 Codex가 `aside repl`로 브라우저를 직접 읽고 클릭합니다. Aside 안의 AI에게 일을 맡기는 기능과는 다릅니다.

### 2-3. Aside 안의 AI도 쓰고 싶다면 — 선택 사항

**오늘 실습의 필수 단계는 아닙니다.** ChatGPT 앱(Codex)이 직접 브라우저를 조작하는 실습에는 이 연결을 요구하지 않습니다. Aside 창 안의 AI를 별도로 쓸 때만 아래를 따라 하세요.

1. Aside에서 **설정(Settings)** 을 엽니다. **톱니바퀴 모양**이나 **내 이름**을 누르면 나오는 메뉴 안에 있습니다.
2. 설정 화면에 **Models** 가 보이면 누릅니다. 화면이 다르면 이 선택 설정을 건너뛰고 3단계로 가세요.
3. 나온 화면에서 **Providers** 를 누릅니다.
4. **Connect** 를 누릅니다.
5. **Subscription** 이라는 제목 아래에 있는 **ChatGPT Subscription** 을 누릅니다.
6. 로그인 창이 뜨면 **1단계와 같은 ChatGPT 계정**으로 로그인합니다. 허락을 묻는 화면이 나오면 **Allow** 나 **Continue** 중 **보이는 단추**를 누릅니다.
7. Aside로 돌아와서 **Providers** 목록에 **ChatGPT Subscription** 이 보이면 연결 끝입니다.

여기까지 했으면 **Aside 창은 그대로 둡니다**(꺼도 됩니다). 이제 **ChatGPT 앱**으로 돌아갑니다.

## 3단계. 상자 ① 붙여넣기 — 나머지는 Codex가 합니다

### 상자는 어디에 붙여넣나요?

**ChatGPT 앱 → Codex → 1단계에서 연 채팅의 맨 아래 입력창** 입니다.

| ⭕ 여기에 붙여넣습니다 | ❌ 여기가 아닙니다 |
| --- | --- |
| **ChatGPT 앱**의 **Codex** 화면 **맨 아래 입력창** | **Aside** 창 (Aside에도 글 쓰는 칸이 있어서 헷갈리기 쉽습니다) |
| | 크롬·엣지로 연 chatgpt.com |
| | 검은 창(PowerShell), 메모장 |

**복사해서 붙여넣는 법 (매번 똑같습니다)**

1. 회색 상자 **오른쪽 위 구석**에 마우스를 올리면 **네모 두 개가 겹친 모양의 복사 단추**가 나타납니다. 한 번 누릅니다.
   (단추가 안 보이면 상자 안의 글을 마우스로 **처음부터 끝까지 끌어서** 색이 칠해지게 한 뒤 **Ctrl + C**.)
2. **ChatGPT 앱**의 맨 아래 **입력창을 한 번 클릭**합니다.
3. **Ctrl + V** → 상자의 글이 통째로 들어옵니다. **고치지 않습니다.**
4. **Enter** → Codex가 일을 시작합니다.

### Codex가 “해도 될까요?”라고 물으면

Codex는 프로그램을 받거나 설치하기 전에 ChatGPT 앱 안에 **허락 창**(「한 번만 허용」·「이 대화 허용」·「거부」 단추가 있는 창)을 띄웁니다. 앱 설정에 따라 허락을 물을 수 있습니다. 무슨 작업인지 모르겠으면 Codex에게 쉬운 말로 설명해 달라고 한 뒤 허용하세요.

- Codex가 설명한 설치·확인 작업이면 **「한 번만 허용」** 을 누릅니다.
- **“파일을 삭제”** 하겠다는 내용이면 누르지 말고 입력창에 “왜 지워야 해? 지우지 않는 방법으로 해 줘.”라고 쓰고 Enter.
- 화면이 어두워지며 「이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?」가 뜨면 **Windows 창**입니다. **Codex가 방금 “관리자 권한이 필요합니다”라고 말한 직후에만 「예」**, 아무 일도 안 시켰는데 뜨면 **「아니요」**. 새 계정·결제·보안 기능 끄기를 요구하면 진행하지 말고 허브에 질문하세요.

> **아래 상자는 Codex가 읽는 글입니다.** 모르는 말이 많아도 괜찮습니다. **읽지 말고, 복사해서 붙여넣기만** 하세요.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ① — Aside를 앞으로의 웹 작업 도구로 설정**

```text
나는 컴퓨터 초보자다. Windows PC에 ChatGPT 앱을 설치해 로그인했고, Aside 브라우저를 설치해 내 Aside 계정으로 로그인했다. 이번 실습은 Codex가 aside repl로 직접 조작하며 Aside 안의 별도 AI에게 맡기지 않는다.

이 컴퓨터에서 네가 직접 다음을 해 줘. 내가 할 일은 최소로 줄여 줘.
1. Aside 공식 문서 https://docs.aside.com/help/developers 의 Windows 방법(서명을 확인하는 공식 설치 스크립트)으로 Aside CLI를 설치해 줘. 이미 설치돼 있으면 다시 설치하지 말고 공식 업데이트를 확인해 줘. 설치 뒤 aside 명령이 안 잡히면 새 PowerShell 창에서 다시 확인해 줘.
2. aside --update, aside guide, aside account list 를 실행해서 CLI가 작동하고 내 Aside 계정이 로그인돼 있는지 확인해 줘. Aside 계정 로그인과 대상 웹사이트 로그인은 별개임을 알려 줘. 이번 직접 조작 실습을 위해 ChatGPT Subscription 연결·새 API 키·Aside 결제를 요구하지 마.
3. Codex가 실제로 읽는 사용자 skills 폴더에 aside-browser 스킬을 설치해 줘. 현재 공식 문서의 사용자 경로(~/.agents/skills 또는 Windows의 해당 사용자 홈)를 확인하고 설치해 줘. 잘못된 위치에 파일만 두고 설치됐다고 하지 마. Aside가 공식으로 제공하는 방법을 먼저 찾고, 없으면 "Aside를 쓰기 전에 aside --update 와 aside guide 를 실행해 읽고 그대로 따른다"는 내용의 작은 SKILL.md를 만들어 줘. 출처가 불분명한 다른 사람의 설치 스크립트는 쓰지 마. 스킬 파일 경로와 새 채팅에서 읽는 방법을 확인해 줘.
4. Codex가 실제로 쓰는 전역 지침 파일(전역 AGENTS.md, CODEX_HOME이 다르면 그 실제 홈)을 찾아서, 원래 있던 내용은 그대로 두고 아래 규칙을 덧붙여 줘. 특정 프로젝트 폴더의 파일에 적고 끝내지 마.
   "웹사이트를 열고, 읽고, 입력하고, 결과를 확인하는 모든 웹 작업은 Aside(aside CLI와 aside-browser 스킬)로 한다. 쓰기 전에 aside --update 와 aside guide 를 실행해 읽는다. 스터디 실습에서는 Codex가 aside repl로 직접 읽고 클릭한다. aside exec, aside "할 일", aside URL처럼 Aside 안의 AI 작업을 시작하는 명령은 사용하지 않는다. 웹 읽기·클릭과 결과 열기는 aside repl 안의 openTab으로 한다. Aside가 안 되면 다른 브라우저로 바꾸지 말고 먼저 나에게 알린다."
   "Aside의 탭·DOM 조작으로 백그라운드에서 처리한다. 실제 마우스 이동·클릭이나 전역 키보드 입력을 하지 않고, 창을 앞으로 가져오거나 내가 보고 있는 탭·데스크톱을 바꾸지 않는다. 작업 대상 탭만 다루고 내가 다른 일을 하는 탭은 건드리지 않는다. 이번 스터디는 Codex가 aside repl로 직접 읽고 클릭한다. aside exec, aside "할 일", aside URL처럼 Aside 안의 AI 작업을 시작하는 명령은 사용하지 않는다. 웹 읽기·클릭과 결과 열기는 aside repl 안의 openTab으로 한다. 백그라운드로 안 되는 단계는 다른 방법을 먼저 찾고, 화면 조작이 꼭 필요하면 필요한 조작과 영향을 설명한 뒤 내 허락을 받는다."
   이 컴퓨터에서 Claude도 사용 중이면 Claude의 전역 지침에도 같은 규칙을 추가하고, 없으면 설치하지 마. 지침 파일이 자동 생성되는 파일이면 정본을 수정하고 적용해 줘. 기존 지침에 "aside exec에 작업을 맡길 때도 이 조건을 전달한다"처럼 별도 Aside AI를 쓰게 하는 옛 문장이 있으면, 지침의 나머지는 보존하고 그 문장만 위의 직접 조작 규칙으로 바꿔 줘.
5. 다 끝나면 무엇을 설치했고, 어떤 파일의 어디에 무엇을 적었는지, 실제로 확인한 결과를 쉬운 한국어로 짧게 알려 줘. 내 로그인이나 Windows 허락 창처럼 사람이 꼭 해야 하는 일이 있을 때만, 그 한 단계를 무엇을 어디서 누르는지까지 알려 주고 기다려 줘.
```

**기다리는 동안:** 화면에 글이 계속 올라오는 것은 **Codex가 일하는 중**입니다. 끄지 말고 두어도 되고, 다른 일을 해도 됩니다. **AI는 내 마우스나 보고 있는 화면을 건드리지 않도록 설정합니다.** 허락 창이 뜨면 위 기준대로 누릅니다.

**끝났는지 보는 법:** Codex가 **정리된 답**을 보여 주고 더 이상 글이 올라오지 않으면 끝입니다. 그 답에 **Aside 설치·확인을 마쳤다**는 말이 있으면 3단계 성공입니다. **10분이 넘도록 화면이 그대로**면 아래 「잘 안될 때」로 가세요.

> 궁금하면 같은 입력창에 이렇게 물어보세요. “CLI가 뭐야? 스킬은 뭐고, 전역 지침은 뭐야? 내 컴퓨터를 예로 쉽게 설명해 줘.”

## 4단계. 상자 ② 붙여넣기 — 잘 됐는지 확인

이번에는 **새 채팅**에서 합니다. 방금 적은 규칙이 **새 채팅에서도 저절로 지켜지는지** 보려는 것입니다.

1. ChatGPT 앱 → **Codex** → **「새 채팅」** 을 누릅니다.
2. 아래 상자 ②를 붙여넣고 **Enter**.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ② — 확인**

```text
스터디 실습 안내서가 모여 있는 https://github.com/aiautomationstudy/study_exercises 를 Aside의 백그라운드 탭·DOM 조작으로 읽어서, 3기/실습 폴더에 있는 안내서 제목을 모두 알려 줘. 실제 마우스·키보드 입력이나 창·활성 탭·데스크톱 전환을 하지 마. aside-browser 스킬을 읽고 Codex인 네가 aside repl로 직접 페이지를 열어 읽어 줘. aside exec, aside "할 일", aside URL처럼 Aside 안의 AI 작업을 시작하는 명령은 쓰지 마. 웹 읽기·클릭은 aside repl 안의 openTab으로 해. 어떤 실제 페이지와 도구로 읽었는지, 스킬 경로와 다른 작업을 방해하지 않는 전역 규칙의 저장 위치를 알려 줘. 기억이나 로컬 파일 목록으로 대신하지 마.
```

**이렇게 나오면 성공입니다:** 안내서 제목 목록이 나오고, **“Aside로 읽었다”** 고 대답하며, 스킬을 읽은 경로와 다른 작업을 방해하지 않는 규칙을 저장한 위치를 알려 줍니다. 단순히 “설치됐다”는 답이 아니라 실제 GitHub 페이지를 읽은 결과여야 합니다. 확인하는 동안 **내 마우스와 보고 있는 창·탭·데스크톱이 그대로인지**도 봅니다. **준비 끝입니다!** 🎉

**다른 도구로 열었다고 하면:** 같은 채팅에 이렇게 붙여넣으세요.

```text
전역 지침에는 웹 작업을 Aside로 하라고 적었어. 왜 Aside를 쓰지 않았는지 확인하고, 지침이나 스킬을 고친 뒤 Aside로 다시 열어서 확인해 줘.
```

### Windows 설치 인증키 오류

**`Cannot open Windows installation key aside.install.sig`**는 Aside가 설치 확인에 쓰는 인증키를 Windows에서 열지 못했다는 뜻입니다. 프로그램이 설치되어 있고 `aside --update`가 성공해도 이 오류가 날 수 있습니다. **이 오류만으로 한글 사용자 이름이 원인이라고 단정할 수는 없습니다.**

1. Aside 창과 ChatGPT 앱(Codex)을 **평소 사용하는 같은 Windows 계정**에서 엽니다. 두 앱 모두 **「관리자 권한으로 실행」은 누르지 않습니다.**
2. 아래 상자를 **ChatGPT 앱(Codex)**에 붙여넣습니다.

```text
Aside CLI에서 "Cannot open Windows installation key aside.install.sig" 오류가 나. aside --update는 되지만 aside account list는 실패해.
설치를 반복하기 전에 현재 Windows 계정, aside 실행 파일 경로와 버전, 실제 오류 문구를 확인해 줘. 한글 경로가 원인이라고 추측해서 사용자 이름을 바꾸지 마.
Aside 공식 개발자 안내 https://docs.aside.com/help/developers 를 다른 읽기 도구로 확인하는 것은 이번 진단에서 허용해. 웹 실습은 계속 Aside로 해 줘.
공식 안내의 Settings > Developers에서 제공하는 CLI 설치·업데이트·재설치 방법을 확인해 줘. 내가 눌러야 하는 곳은 화면에 보이는 이름으로 한 단계씩 알려 줘.
설치 인증키 삭제·초기화, Windows 보안 끄기, 인증서 검사 생략, 로그아웃은 하지 마. 키·쿠키·비밀번호 값도 출력하지 마.
다시 확인해도 같은 오류면 재설치를 반복하지 말고 멈춰. Aside 지원팀에 보낼 버전·오류 문구·시도한 조치를 짧게 정리해 줘. 메일은 보내지 마.
```

3. 계속 같은 오류라면 **Aside → Settings → Send feedback**으로 오류를 보냅니다. 또는 [Aside 공식 문제 해결 안내](https://docs.aside.com/help/troubleshooting)에 나온 **support@aside.com**으로 Codex가 정리한 내용을 보내세요. **비밀번호·인증키·대화 전체는 보내지 않습니다.**

**끝났는지 보는 법:** `aside account list`가 오류 없이 계정 목록을 보여 주고, 4단계의 안내서 제목 읽기가 성공해야 준비 완료입니다. 지원팀 답변을 기다리는 동안에는 이미 만든 실습 폴더와 파일을 그대로 두세요.

## Mac을 쓰신다면

- ChatGPT 앱은 [OpenAI 빠른 시작 페이지](https://learn.chatgpt.com/docs/quickstart)의 **Desktop** 에서 macOS용을 받습니다.
- Aside는 같은 주소(https://aside.com/download)에서 받습니다. 받은 Aside를 **응용 프로그램(Applications)** 폴더로 끌어다 놓고 엽니다.
- 상자 ①을 붙여넣을 때 맨 앞에 “나는 macOS를 사용해. Windows 부분을 내 컴퓨터에 맞게 바꿔 줘.”를 붙이세요.

**한 문장으로 기억하기:** ChatGPT 앱과 Aside를 설치해 내 계정으로 로그인하고, 나머지는 상자 하나로 Codex에게 맡깁니다.

## 설치와 실제 작동 확인은 다릅니다

`aside --update`와 `aside guide` 성공은 설치 확인입니다. **4단계 새 채팅에서 GitHub 페이지를 실제로 읽어야** 준비가 끝납니다. 설치했는데 스킬이 보이지 않으면 ChatGPT 앱을 다시 열어 새 채팅에서 확인하세요. Windows 설치 인증키 오류 대처는 위 표를 그대로 따릅니다.

작업 탭이 앞에 보이지 않거나 AI 실행 뒤 닫혀도 결과 파일은 남습니다. Codex에게 정확한 접속 주소를 물어 Aside 주소창에 붙여넣어 여세요. 페이지를 열었다는 로그만으로 화면에 보인다고 보지 않습니다.

설정 기준: [OpenAI 사용자 스킬 경로](https://learn.chatgpt.com/docs/build-skills), [전역 지침 읽기](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [Aside 공식 개발자 안내](https://docs.aside.com/help/developers).
