복사해서 붙여넣는 법 (매번 똑같습니다)

  1. 회색 상자 위의 초록색 「복사」 단추를 한 번 누릅니다. 옆에 “복사했습니다”가 뜨면 된 것입니다.
  2. ChatGPT 앱의 맨 아래 입력창을 한 번 클릭합니다.
  3. Ctrl + V → 상자의 글이 통째로 들어옵니다. 고치지 않습니다. (상자 아래에 “바꿔도 된다”고 적힌 부분만 바꿔도 됩니다.)
  4. Enter → Codex가 일을 시작합니다.

같은 채팅에 이어서 붙여넣습니다. 1 → 2 → 3 단계를 한 채팅에서 합니다. 그래야 Codex가 앞에서 만든 것을 기억합니다. 한 상자를 붙여넣은 뒤에는 Codex가 결과를 알려 줄 때까지 기다렸다가 다음 상자로 갑니다.

Codex가 “해도 될까요?”라고 물으면 — 허락 창(「한 번만 허용」·「이 대화 허용」·「거부」)이 뜹니다. 정상입니다.

  • 「한 번만 허용」이나 「이 대화 허용」을 누릅니다.
  • “파일을 삭제”하겠다는 내용이면 누르지 말고 “왜 지워야 해? 지우지 않는 방법으로 해 줘.”라고 씁니다.
내가 직접 하는 일은 네 가지뿐입니다: 로그인 · 본인 인증 · 로봇 확인(“로봇이 아닙니다” 같은 그림 맞히기, 캡차) · 결제. 나머지는 AI가 합니다.

오늘은 「지켜보기」로 합니다. 상자 맨 앞의 [지켜보기] 줄은 AI가 일하는 탭을 Aside 맨 앞에 띄우라는 부탁입니다. 평소에는 사전준비 때 정한 규칙대로 뒤쪽 탭에서 조용히 일하고, 여러분은 다른 일을 하면 됩니다. 오늘은 배우는 날이라 지켜봅니다.

화면 배치 팁: 줌 화면은 작게 줄이고, ChatGPT 앱과 Aside 창을 나란히 놓으면 보기 편합니다. Aside 창이 안 보이면 작업 표시줄(화면 맨 아래 줄)에서 Aside를 누르세요.
준비

Codex 새 채팅 열기 (3분)

  1. ChatGPT 앱 → 왼쪽 메뉴 Codex → 「새 채팅」을 누릅니다.
  2. 폴더를 고르라고 하면: 폴더 고르는 창 왼쪽에서 문서를 누릅니다. 빈 곳을 마우스 오른쪽 단추로 누르고 → 새로 만들기 → 폴더. 이름 칸에 ai-practice를 치고 Enter. 그 폴더를 한 번 누르고 「폴더 선택」. “이 폴더를 신뢰할까요?”라고 물으면 「폴더 신뢰」. (안 물어보면 그냥 넘어갑니다.)

  4. Aside를 켜 둡니다. 꺼져 있으면 Windows 키 → Aside → Enter.

2. 평소 브라우저에서 하던 일 하나를 맡겨 보기

이번에는 지켜보지 않아도 됩니다. [지켜보기] 줄이 없으면 AI는 사전준비 때 정한 규칙대로 뒤쪽 탭에서 조용히 일합니다. 그동안 여러분은 다른 일을 하세요. 아래는 예시입니다. [ ] 안만 내 것으로 바꿔 보내거나, 평소 하던 일로 바꿔 보세요.

우리 동네 [동네 이름] 근처 내과 중에서 토요일 오후에 진료하는 곳 3곳을 찾아, 진료 시간·전화번호·주소를 표로 정리해 줘.
병원 홈페이지나 지도 서비스에서 실제로 열어 본 정보만 쓰고, 확인하지 못한 것은 '미확인'이라고 적어 줘. 언제 확인한 정보인지 날짜도 적어 줘.
[구 이름] 구청 홈페이지의 새소식·공지에서 이번 달 주민 대상 행사와 무료 강좌를 찾아 날짜순으로 정리해 줘.
행사마다 대상·장소·신청 방법·마감일과 원래 페이지 주소를 적어 줘. 확인하지 못한 것은 '미확인'이라고 적어 줘.
[사고 싶은 물건]을 쇼핑몰 세 곳에서 찾아 배송비를 포함한 가격, 도착 예정일, 반품 조건을 비교해 줘.
로그인과 결제는 하지 마. 결제는 내가 직접 할게. 실제로 열어 본 페이지 주소를 함께 적어 줘.

끝나면 물어보세요. “방금 한 일을 쉬운 말로 설명해 줘.” “다음에 이 일을 더 빨리 맡기려면 어떻게 말하면 돼?” 맡겨 본 일과 결과도 「과제·실습 공유」에 올려 주시면 다른 분들께 좋은 예시가 됩니다.
