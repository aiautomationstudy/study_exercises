실습하다 막히셨다면 내 상황과 맞는 항목 하나만 보세요. 처음부터 다시 하실 필요는 없습니다. 컴퓨터에 설치한 ChatGPT 앱(Codex)이 확인하고 고칠 수 있는 것은 AI에게 맡깁니다. 로그인, 휴대폰에서 버튼 누르기처럼 여러분이 해야 하는 일은 따로 설명했습니다.

1. 무엇을 물어봐야 할지 모르겠어요

실습 안내서 주소와 지금 막힌 내용을 함께 보여 주세요. 오류의 뜻을 몰라도 됩니다.

지금 하실 것

  1. 학습자료에서 하던 실습의 안내서를 엽니다.
  2. 안내서가 열린 인터넷 창 맨 위 주소창을 한 번 누르고 Ctrl+C로 주소를 복사합니다.
  3. ChatGPT 앱(Codex)의 그 실습 대화에 주소를 붙여넣고, 아래 상자도 함께 보냅니다.
이 안내서의 실습을 하려고 해. 나는 컴퓨터를 잘 몰라.
지금 막힌 내용은 이 글 아래에 붙일게.
안내서와 내가 이미 한 작업을 먼저 확인해 줘.
네가 확인·설치·수정·실행할 수 있는 것은 직접 해결해 줘.
기존 파일은 지우지 말고, 내가 꼭 해야 하는 것만 쉬운 말로 한 단계씩 알려 줘.
끝에는 실제로 무엇이 만들어졌는지, 어디에서 확인하는지 알려 줘.
실제로 성공한 것을 확인하기 전에는 해결됐다고 말하지 마.

그 아래에 Codex가 한 말이나 오류 문구를 붙여넣습니다. "준비 4에서 막혔어요"처럼 안내서의 단계도 적으면 좋습니다.

오류 화면만 있나요? Windows에서 Windows 키+Shift+S를 누르고 필요한 부분을 드래그해 찍습니다. 질문 입력창을 누르고 Ctrl+V로 붙여넣습니다. 비밀번호·인증번호·봇 토큰이 보이는 부분은 빼고 찍어 주세요.

성공 확인: AI의 "끝났습니다"라는 말과 함께, 실제 결과 파일·웹 화면·휴대폰 메시지가 보이는지 확인합니다.

2. 같은 말만 반복해요 / Codex에게 말을 걸 수 없어요

같은 방법으로 두 번 실패했다면 ChatGPT.com에 물어보세요. Codex가 아예 켜지지 않아도 이 방법으로 다음 행동을 안내받을 수 있습니다.

지금 하실 것

  1. 크롬이나 엣지에서 chatgpt.com을 열고 본인 계정으로 로그인합니다.
  2. 실습 안내서 주소와 아래 상자를 붙여넣습니다.
  3. 그 아래에 막힌 단계, 오류 문구, 이미 해 본 것을 붙여넣습니다.
이 안내서의 실습을 하다가 막혔어. 나는 컴퓨터 초보자야.
아래에 막힌 단계와 ChatGPT 앱(Codex)이 한 말, 이미 해 본 것을 붙일게.
같은 실패를 반복시키지 말고 다음에 할 행동을 하나씩 쉽게 알려 줘.
Codex가 대화 가능한 상태라면, 거기에 그대로 복사해서 붙여넣을 해결 문장을 만들어 줘.
내가 직접 해야만 하는 일은 어느 앱에서 무엇을 누르는지 순서대로 설명해 줘.
내 화면을 확인하지 않고 메뉴 위치나 원인을 단정하지 마.
파일 삭제·재설치·Windows 보안 끄기부터 권하지 마.

참고: ChatGPT.com은 해결 방법을 알려 주는 곳입니다. 거기서 "고쳤다"고 말해도 내 컴퓨터의 파일이 실제로 바뀐 것은 아닐 수 있습니다. Codex에 해결 문장을 전달하거나, 안내받은 조작을 한 뒤 결과를 확인해 주세요.

3. 보내기 화살표가 회색이에요 / 앱이 흰 화면이에요

보내기 버튼만 안 눌릴 때

  1. 왼쪽에서 지금 실습하는 프로젝트를 선택했는지 확인합니다. 처음이면 안내서에서 정한 실습 폴더를 연결합니다. 폴더 안내를 보세요.
  2. 입력한 글 맨 끝을 한 번 누르고 스페이스바를 한 번 누른 다음 보내기를 눌러 봅니다. 한글 입력이 끝나지 않은 상태인지 확인하는 간단한 방법입니다.
  3. 앞 작업이 아직 진행 중인지 확인합니다. 멈춤·중지 버튼이 보이면 현재 작업 상태를 먼저 봅니다.
  4. 여전히 안 되면 입력한 글을 복사해 메모장에 보관하고 앱을 완전히 종료했다가 다시 엽니다.

성공 확인: 내가 보낸 글이 대화에 올라가고 Codex가 답을 시작합니다. 버튼이 안 눌리는 원인은 이 점검만으로 확정할 수 없습니다.

흰 화면·모델 오류 때문에 대화 자체가 안 될 때

  1. 쓰던 글을 보관하고 ChatGPT 앱을 완전히 종료했다가 다시 엽니다. 창만 닫은 뒤 오른쪽 아래 작업 표시줄에 ChatGPT 아이콘이 남아 있으면 그 아이콘의 오른쪽 버튼 메뉴에서 종료합니다.
  2. 계속 안 되면 2번의 방법으로 ChatGPT.com에 그 화면과 오류 문구를 보여 주세요.
  3. model is not supported라는 문구가 보이면 그 영어 문구 전체를 붙여넣고, 내 앱에서 고를 수 있는 모델과 업데이트 여부를 확인하는 방법을 요청합니다. 안내서에 적힌 예전 모델 이름을 억지로 입력하지 않습니다.

앱이 안 돼도 자동화하고 싶은 일을 정리하는 문서는 ChatGPT.com에서 먼저 만들 수 있습니다. 내 컴퓨터의 파일을 만들고 프로그램을 실행하는 실습은 앱이 실행된 뒤 이어갑니다.

명령을 실행해도 되냐는 허락 창이 뜰 때

이것은 오류가 아니라 내 허락을 기다리는 화면일 수 있습니다. 명령의 뜻을 모르겠으면 같은 대화에서 "이 명령이 무엇을 하는지, 파일을 바꾸거나 밖으로 보내는지 쉬운 말로 설명해 줘"라고 물어보세요. 하려던 작업에 필요한 명령인지 확인하고 「한 번만 허용」을 누릅니다.

4. 폴더를 고르라고 해요 / 어제 하던 일을 이어가고 싶어요

그 실습에 쓰던 프로젝트와 대화를 먼저 엽니다. 같은 이름의 폴더를 계속 새로 만들지 않습니다.

폴더를 못 찾겠다면 Codex에 보내세요

이전에 이 실습에서 만든 폴더를 찾아 줘. 같은 폴더를 새로 만들지는 마.
지금 작업하는 폴더의 전체 위치와, 그 안에 이미 있는 실습 파일을 확인해 줘.
작업 폴더를 내가 직접 골라야 한다면 선택할 폴더와 화면에서 누를 것을 쉽게 알려 줘.
파일을 지우거나 옮기지는 마.

녹음 비서 실습이라면 녹음자동처리 폴더 안에 inbox, notes, config 등이 있는지 확인하게 합니다. 컴퓨터마다 「문서」의 위치가 다를 수 있습니다.

내가 직접 폴더를 골라야 할 때: 프로젝트의 폴더 선택 창에서 Codex가 알려 준 위치를 엽니다. 선택할 폴더 이름을 한 번 누르고 「폴더 선택」을 누릅니다. 해당 버튼이 보이지 않으면 화면을 찍어 2번 방법으로 물어보세요.

다음 날 이어갈 때

이 실습을 이어서 하자. 안내서와 이 폴더에 있는 파일을 읽어 줘.
어디까지 실제로 완료됐고 어디부터 남았는지 확인해 줘.
이미 된 것은 다시 만들지 말고, 남은 첫 단계부터 진행해 줘.
내가 직접 할 일만 한 단계씩 알려 줘.

참고: 컴퓨터에서 돌아가는 녹음 처리·알림은 컴퓨터를 끄면 멈춥니다. 켠 뒤 자동으로 다시 시작하도록 준비됐는지는 Codex에게 실제 설정을 확인하게 하세요.

5. Aside 브라우저·CLI·스킬 중 어디에서 막혔나요?

Aside 창이 켜진 것만으로 준비가 끝난 것은 아닙니다. 아래 네 가지를 따로 확인합니다. 모르는 영어 명령은 직접 입력할 필요 없이 아래 문장을 ChatGPT 앱(Codex)에 복사해 보내세요.

확인할 것준비가 된 모습
브라우저Aside가 열리고 내 Aside 계정으로 로그인돼 있습니다.
CLI: AI가 Aside를 부르는 연결 도구Codex에서 설치 위치·버전을 확인하고, 계정 확인 명령도 성공합니다.
스킬: AI가 읽는 Aside 사용 안내Codex가 aside-browser를 인식하고 실제 SKILL.md를 읽습니다.
실제 웹 작업실습할 Codex 대화에서 Aside로 실제 페이지를 읽고 제목·주소·읽은 내용을 알려 줍니다.

ChatGPT 계정과 Aside 계정의 이메일은 달라도 됩니다. 네이버·티스토리 같은 사이트 로그인도 따로 합니다. 오류의 “같은 사용자(same OS user)”는 이메일이 아니라 Windows에서 명령을 실행하는 사용자를 뜻합니다. 두 앱을 같은 사람이 열었어도 Codex의 보호된 실행 공간에서는 다른 Windows 계정으로 명령이 실행될 수 있습니다.

A. 「aside 명령을 찾지 못했다」고 해요

  1. 사전준비 안내서의 CLI 복구 상자를 ChatGPT 앱(Codex)에 보냅니다. 이미 설치한 앱·파일은 보존합니다.
  2. Aside 창의 Settings → Developers에서도 CLI 설치·업데이트를 할 수 있습니다. 화면에 보이는 단추 이름은 버전에 따라 다르므로, 못 찾겠으면 그 화면을 보여 주세요.
  3. 설치 직후 명령을 못 찾으면 ChatGPT 앱을 완전히 종료했다 다시 열어 새 실행 경로를 인식하게 합니다. 먼저 하던 작업을 저장하고 실행 중인 일이 끝났는지 확인합니다. Windows에서 창의 ×만 눌렀는데 앱이 남아 있다면, 화면 오른쪽 아래 숨겨진 아이콘에서 ChatGPT의 종료 메뉴가 있는지 확인합니다. Mac은 ChatGPT 앱에서 ⌘+Q입니다.

명령을 찾았어도 계정 확인이 실패했다면 아래 C로 갑니다. 앱을 다시 설치하는 단계로 돌아가지 않습니다.

B. 「aside-browser 스킬이 없다」고 해요

aside skills list에 Gmail·Notion 등이 나오는 것은 Aside 안의 서비스용 스킬 목록입니다. Codex의 aside-browser 설치 확인과 다릅니다. 기존 스킬을 지우거나 사용자 폴더를 바꾸기 전에 아래 문장을 보냅니다.

Aside CLI는 있지만 Codex에서 aside-browser 스킬을 찾지 못했어.
현재 Codex가 실제로 읽는 사용자·프로젝트 스킬 위치부터 확인해줘.
aside skills install --help를 읽고, 지원하면 공식 명령 aside skills install --target codex로 설치해줘.
실제 설치한 SKILL.md 경로와 name·description을 확인하고 내용을 읽어줘.
현재 공식 사용자 경로는 내 사용자 홈의 .agents/skills야. 다른 위치에 설치됐다면 이 Codex가 인식하는지 실제로 확인해줘.
이미 있는 파일은 보존하고, 출처 모를 설치 스크립트나 스킬을 만들지 마.
접근 거부나 명령 미지원이면 원문을 알려주고 멈춰. 관리자 권한이나 보안 해제부터 요구하지 마.
프로젝트 안에만 설치했다면, 다른 프로젝트에서도 쓰는 공통 설치와 구분해줘.
파일을 만들었다는 말만 하지 말고, 앱을 다시 열어 새 대화에서 인식·읽기를 확인하는 방법을 알려줘.

Codex가 쓰기 권한 때문에 설치하지 못할 때만: 기존 스킬 파일이 없다는 것을 확인했고, 현재 CLI가 위 공식 설치 명령을 지원한다면 직접 연 일반 Windows PowerShell에서 아래 한 줄을 실행할 수 있습니다. PowerShell 여는 법은 아래 C에 있습니다. 기존 파일이 있다면 먼저 보존하도록 안내받고, 무조건 덮어쓰지 않습니다.

aside skills install --target codex

설치 위치가 표시되면 Codex에 알려 주고 새 대화에서 읽는지 확인합니다. 명령 미지원·접근 거부가 나오면 그 오류를 보존하고 멈춥니다.

기존 작업이 끝난 뒤 앱을 다시 열고 같은 실습 폴더의 새 Codex 대화에서 “aside-browser 스킬을 읽고 어디에서 읽었는지 알려줘”라고 합니다. 파일이 있어도 인식되지 않으면 준비 완료로 넘기지 않습니다. 전역 작업 규칙을 적은 파일과 스킬 파일도 서로 다릅니다.

C. 켜져 있는데 인증·권한 오류가 나요

보이는 말·상황다음에 할 일
Cannot open Windows installation key / local authentication failed공식 안내는 Windows 실행 계정 차이를 우선 확인합니다. 키를 지우거나 로그아웃·재설치하지 않습니다.
EPERM + mkdir·rename·native 경로실패한 파일 경로와 실행 환경을 확인합니다. 같은 폴더 권한 허용 뒤에도 실패했다면 그 결과를 재사용합니다.

스터디 허브에서 학습자료를 누릅니다. 주차별 안내서와 녹화 영상을 찾아볼 수 있습니다. 아직 시작하지 못했다면 하려던 기본 실습 안내서 하나부터 보세요. 이 안내서는 새 과제가 아니라 막힌 곳을 해결하는 도움말입니다.

결과 올리기

  1. 과제·실습 공유를 엽니다.
  2. 「글쓰기」를 누르고 제목과 무엇을 만들어 봤는지 적습니다.
  3. 공개해도 되는 결과 링크를 붙이거나 캡처 이미지를 올립니다. 캡처 붙여넣기가 안 되면 글쓰기 화면의 이미지 첨부에서 저장한 PNG/JPG 파일을 선택합니다.
  4. 저장한 뒤 내 글을 다시 열어 이미지나 링크가 실제로 보이는지 확인합니다.

미완성이어도 어디까지 됐고 어디에서 막혔는지 함께 적을 수 있습니다. 질문은 묻고 답하기에 남겨 주세요.

.md 파일만 있나요? Codex에 "이 문서를 읽기 편한 HTML 파일로 만들어 줘. 내가 내용을 확인한 뒤 공유할 수 있게 해 줘. 아직 공개하지는 마"라고 요청합니다. .md는 글 문서입니다. MarkText로 열면 보기 편합니다. 메모장에서 보이는 #·**는 문서 서식 표시입니다.

요구사항 정의서에 대한 개별 답변은 해당 학습자료 글의 댓글에서 확인합니다. 파일 첨부·본문 길이 오류가 나면 같은 글을 여러 번 올리지 말고 오류 화면과 글 제목을 질문에 함께 적어 주세요.

10. 음성 입력·사용 한도·사이트 수정에서 막혔어요

말을 했는데 엉뚱한 글자가 나와요

지금 실습은 글로 입력해서 먼저 이어갈 수 있습니다. Windows의 「음성 녹음기/녹음기」에서 짧게 녹음해 내 목소리가 들리는지 확인합니다. 들리지 않거나 ChatGPT에서만 잘못 받아쓰면 그 결과와 화면을 ChatGPT.com에 보여 주고 한 단계씩 점검해 달라고 하세요. 마이크 고장이라고 단정하지 않습니다.

사용 한도에 도달했다고 나와요

화면에 나온 도구 이름·한도 안내·다시 쓸 수 있는 시각을 확인합니다. 어떤 서비스의 한도인지 모른 채 추가 결제하지 않습니다. ChatGPT.com을 쓸 수 있으면 화면을 보여 주고 "지금 한도가 무엇인지, 추가 결제 없이 언제 무엇을 할 수 있는지 설명해 줘"라고 물어보세요. 기다리는 동안에는 안내서를 읽거나 다음에 만들 내용을 메모해 둘 수 있습니다.

만든 사이트가 수정되지 않아요 / 게시가 차단됐어요

이미 만든 사이트를 수정하려다 막혔어. 아래에 사이트 주소와 오류를 붙일게.
원본 파일과 현재 공개된 화면을 각각 확인해 줘.
어떤 수정이 저장됐고 실제 사이트에는 무엇이 반영됐는지 구분해 줘.
가능한 수정은 기존 결과를 보존하고 직접 진행해 줘.
게시 권한이나 로그인에서 사람이 할 일이 있다면 한 단계씩 알려 줘.
실제 사이트를 다시 열어 확인하기 전에는 반영됐다고 말하지 마.
이미 실패한 방법을 반복하거나 보호 설정을 임의로 바꾸지 마.

허락 요청조차 안 된다는 오류가 반복되면 2번으로 옮겨 물어보세요. 임시로 컴퓨터에서 열리는 결과 파일을 만들 수 있는지도 확인하게 합니다. 컴퓨터에서 보이는 파일과 다른 사람이 볼 수 있는 공개 사이트는 다릅니다.

11. 그래도 막히면 이렇게 질문해 주세요

묻고 답하기 또는 Q&A 챗봇에 아래 형식으로 남기면 확인하기 쉽습니다.

하던 실습과 안내서 주소:
막힌 단계:
화면에 나온 말(그대로 복사):
이미 해 본 것과 결과:
사용 중인 컴퓨터: Windows / Mac

화면도 함께 올릴 수 있습니다. 이름·전화번호·계정·비밀번호·봇 토큰은 가려 주세요. 전체 설정 파일이나 전체 대화 기록을 올릴 필요는 없습니다.

Q&A 챗봇의 답은 그 질문 대화에서 확인합니다. 운영진의 추가 답변도 같은 대화에 남을 수 있으니 Q&A의 질문 기록에서 내 질문을 다시 열어 보세요.

4주차 모임에서는 어디에서 막혔는지뿐 아니라, 무엇을 해 보니 한 단계라도 진행됐는지도 함께 나눠 주세요. 이 안내서로 해결됐다면 어떤 문장을 보내고 무엇이 달라졌는지 이야기해 주시면 다른 분께 도움이 됩니다.

이 안내서는 카톡에서 반복된 질문, 묻고 답하기 게시판, Q&A 질문과 현재 실습 안내서를 확인해 정리했습니다. 특정 참가자의 컴퓨터에서 해결됐다고 보장하는 문서는 아닙니다. 같은 증상도 실제 원인은 다를 수 있어, 확인은 AI에게 맡기고 실제 결과로 성공을 판단합니다.
