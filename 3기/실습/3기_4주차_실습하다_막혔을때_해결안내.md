## 1. 무엇을 물어봐야 할지 모르겠어요

**실습 안내서 주소와 지금 막힌 내용을 함께 보여 주세요.** 오류의 뜻을 몰라도 됩니다.

### 지금 하실 것

1. [학습자료](https://study.saedongne.com/automation/board.html?board=9)에서 하던 실습의 안내서를 엽니다.
2. 안내서가 열린 인터넷 창 맨 위 **주소창**을 한 번 누르고 `Ctrl+C`로 주소를 복사합니다.
3. **ChatGPT 앱(Codex)의 그 실습 대화**에 주소를 붙여넣고, 아래 상자도 함께 보냅니다.

```text
이 안내서의 실습을 하려고 해. 나는 컴퓨터를 잘 몰라.
지금 막힌 내용은 이 글 아래에 붙일게.
안내서와 내가 이미 한 작업을 먼저 확인해 줘.
네가 확인·설치·수정·실행할 수 있는 것은 직접 해결해 줘.
기존 파일은 지우지 말고, 내가 꼭 해야 하는 것만 쉬운 말로 한 단계씩 알려 줘.
끝에는 실제로 무엇이 만들어졌는지, 어디에서 확인하는지 알려 줘.
실제로 성공한 것을 확인하기 전에는 해결됐다고 말하지 마.
```

그 아래에 **Codex가 한 말이나 오류 문구**를 붙여넣습니다. "준비 4에서 막혔어요"처럼 안내서의 단계도 적으면 좋습니다.

**오류 화면만 있나요?** Windows에서 `Windows 키+Shift+S`를 누르고 필요한 부분을 드래그해 찍습니다. 질문 입력창을 누르고 `Ctrl+V`로 붙여넣습니다. 비밀번호·인증번호·봇 토큰이 보이는 부분은 빼고 찍어 주세요.

**성공 확인:** AI의 "끝났습니다"라는 말과 함께, 실제 결과 파일·웹 화면·휴대폰 메시지가 보이는지 확인합니다.

## 2. 같은 말만 반복해요 / Codex에게 말을 걸 수 없어요

**같은 방법으로 두 번 실패했다면 [ChatGPT.com](https://chatgpt.com)에 물어보세요.** Codex가 아예 켜지지 않아도 이 방법으로 다음 행동을 안내받을 수 있습니다.

### 지금 하실 것

1. 크롬이나 엣지에서 [chatgpt.com](https://chatgpt.com)을 열고 본인 계정으로 로그인합니다.
2. 실습 안내서 주소와 아래 상자를 붙여넣습니다.
3. 그 아래에 **막힌 단계, 오류 문구, 이미 해 본 것**을 붙여넣습니다.

```text
이 안내서의 실습을 하다가 막혔어. 나는 컴퓨터 초보자야.
아래에 막힌 단계와 ChatGPT 앱(Codex)이 한 말, 이미 해 본 것을 붙일게.
같은 실패를 반복시키지 말고 다음에 할 행동을 하나씩 쉽게 알려 줘.
Codex가 대화 가능한 상태라면, 거기에 그대로 복사해서 붙여넣을 해결 문장을 만들어 줘.
내가 직접 해야만 하는 일은 어느 앱에서 무엇을 누르는지 순서대로 설명해 줘.
내 화면을 확인하지 않고 메뉴 위치나 원인을 단정하지 마.
파일 삭제·재설치·Windows 보안 끄기부터 권하지 마.
```

**참고:** ChatGPT.com은 해결 방법을 알려 주는 곳입니다. 거기서 "고쳤다"고 말해도 내 컴퓨터의 파일이 실제로 바뀐 것은 아닐 수 있습니다. Codex에 해결 문장을 전달하거나, 안내받은 조작을 한 뒤 결과를 확인해 주세요.

## 3. 보내기 화살표가 회색이에요 / 앱이 흰 화면이에요

### 보내기 버튼만 안 눌릴 때

1. 왼쪽에서 **지금 실습하는 프로젝트**를 선택했는지 확인합니다. 처음이면 안내서에서 정한 실습 폴더를 연결합니다. [폴더 안내](#folder)를 보세요.
2. 입력한 글 맨 끝을 한 번 누르고 **스페이스바를 한 번** 누른 다음 보내기를 눌러 봅니다. 한글 입력이 끝나지 않은 상태인지 확인하는 간단한 방법입니다.
3. 앞 작업이 아직 진행 중인지 확인합니다. 멈춤·중지 버튼이 보이면 현재 작업 상태를 먼저 봅니다.
4. 여전히 안 되면 입력한 글을 복사해 메모장에 보관하고 앱을 완전히 종료했다가 다시 엽니다.

**성공 확인:** 내가 보낸 글이 대화에 올라가고 Codex가 답을 시작합니다. 버튼이 안 눌리는 원인은 이 점검만으로 확정할 수 없습니다.

### 흰 화면·모델 오류 때문에 대화 자체가 안 될 때

1. 쓰던 글을 보관하고 ChatGPT 앱을 완전히 종료했다가 다시 엽니다. 창만 닫은 뒤 오른쪽 아래 작업 표시줄에 ChatGPT 아이콘이 남아 있으면 그 아이콘의 오른쪽 버튼 메뉴에서 종료합니다.
2. 계속 안 되면 [2번](#chat)의 방법으로 ChatGPT.com에 **그 화면과 오류 문구**를 보여 주세요.
3. `model is not supported`라는 문구가 보이면 **그 영어 문구 전체**를 붙여넣고, 내 앱에서 고를 수 있는 모델과 업데이트 여부를 확인하는 방법을 요청합니다. 안내서에 적힌 예전 모델 이름을 억지로 입력하지 않습니다.

앱이 안 돼도 **자동화하고 싶은 일을 정리하는 문서**는 ChatGPT.com에서 먼저 만들 수 있습니다. 내 컴퓨터의 파일을 만들고 프로그램을 실행하는 실습은 앱이 실행된 뒤 이어갑니다.

### 명령을 실행해도 되냐는 허락 창이 뜰 때

이것은 오류가 아니라 **내 허락을 기다리는 화면**일 수 있습니다. 명령의 뜻을 모르겠으면 같은 대화에서 "이 명령이 무엇을 하는지, 파일을 바꾸거나 밖으로 보내는지 쉬운 말로 설명해 줘"라고 물어보세요. 하려던 작업에 필요한 명령인지 확인하고 「한 번만 허용」을 누릅니다.

## 4. 폴더를 고르라고 해요 / 어제 하던 일을 이어가고 싶어요

**그 실습에 쓰던 프로젝트와 대화를 먼저 엽니다.** 같은 이름의 폴더를 계속 새로 만들지 않습니다.

### 폴더를 못 찾겠다면 Codex에 보내세요

```text
이전에 이 실습에서 만든 폴더를 찾아 줘. 같은 폴더를 새로 만들지는 마.
지금 작업하는 폴더의 전체 위치와, 그 안에 이미 있는 실습 파일을 확인해 줘.
작업 폴더를 내가 직접 골라야 한다면 선택할 폴더와 화면에서 누를 것을 쉽게 알려 줘.
파일을 지우거나 옮기지는 마.
```

녹음 비서 실습이라면 `녹음자동처리` 폴더 안에 `inbox`, `notes`, `config` 등이 있는지 확인하게 합니다. 컴퓨터마다 「문서」의 위치가 다를 수 있습니다.

**내가 직접 폴더를 골라야 할 때:** 프로젝트의 폴더 선택 창에서 Codex가 알려 준 위치를 엽니다. 선택할 폴더 이름을 한 번 누르고 「폴더 선택」을 누릅니다. 해당 버튼이 보이지 않으면 화면을 찍어 [2번](#chat) 방법으로 물어보세요.

### 다음 날 이어갈 때

```text
이 실습을 이어서 하자. 안내서와 이 폴더에 있는 파일을 읽어 줘.
어디까지 실제로 완료됐고 어디부터 남았는지 확인해 줘.
이미 된 것은 다시 만들지 말고, 남은 첫 단계부터 진행해 줘.
내가 직접 할 일만 한 단계씩 알려 줘.
```

**참고:** 컴퓨터에서 돌아가는 녹음 처리·알림은 컴퓨터를 끄면 멈춥니다. 켠 뒤 자동으로 다시 시작하도록 준비됐는지는 Codex에게 실제 설정을 확인하게 하세요.

## 5. Aside를 켰는데도 연결이 안 돼요

**Aside 로그인과 Codex에서의 연결은 따로 확인해야 합니다.** "실행 중이 아니다"라는 말이 나와도 실제로 꺼져 있다고 단정할 수는 없습니다.

### 지금 하실 것

1. Aside 브라우저를 열고 본인 계정으로 로그인돼 있는지 봅니다. 조사하려는 사이트의 로그인도 그 사이트에서 따로 합니다.
2. **같은 실습 프로젝트의 ChatGPT 앱(Codex)**에 아래 상자를 붙여넣습니다. 그 아래에 지금 오류 문구도 붙여넣습니다.

```text
3기 3주차 Aside 실습에서 막혔어. 나는 컴퓨터 초보자야.
Aside 브라우저는 켜져 있어. 아래 오류와 이미 해 본 것을 읽고 직접 확인해 줘.
최신 Aside 안내를 확인한 뒤 설치 위치·로그인·실행하는 Windows 계정이 맞는지 점검해 줘.
내 PowerShell에서는 됐다는 정보가 있으면, 네 실행 환경과의 차이를 읽기만 해서 비교해 줘.
연결에 필요한 명령 하나에 허락이 필요하면 그 명령과 이유를 쉽게 설명하고 요청해 줘.
이미 허락 요청도 실패했거나 불가능하다면 같은 방법을 반복하지 마.
재설치·로그아웃·인증키 삭제·Windows 보안 끄기·사용자 이름 바꾸기부터 하지 마.
연결됐다는 말만 하지 말고, 실제 웹페이지 내용을 읽을 수 있는지 확인해 줘.
내가 직접 할 것만 한 단계씩 알려 줘.
```

**성공 확인:** Codex가 실제 페이지를 읽고 조사 결과를 보여 줍니다. 계정 목록이 나오는 것만으로 웹 조사가 성공한 것은 아닙니다.

### 같은 오류가 계속 나올 때

| 화면에 나온 말 | 다음 행동 |
|---|---|
| `Aside isn't running` / `fetch failed` | 켜진 Aside와 Codex의 연결을 위 문장으로 확인합니다. 껐다 켜기를 이미 했다면 반복하지 말고 그 사실을 함께 적습니다. |
| `Cannot open Windows installation key` / `EPERM` | Windows 제품 인증키와는 다른 문제입니다. 오류 문구를 Codex에 보여 주고 실행 계정·접근 차이를 확인하게 합니다. 키를 지우지 않습니다. |
| `uv_os_get_passwd returned ENOMEM` | 이 문구만으로 메모리 부족이라고 단정할 수 없습니다. 메모리를 사거나 사용자 이름을 바꾸지 말고, [2번](#chat)의 문장에 오류를 넣어 물어봅니다. |
| `sandbox_approval` 차단 / 허락 창을 띄울 수 없음 | 이미 실패한 승인 요청을 반복하지 않습니다. 아래 대안으로 조사 실습을 먼저 이어갈 수 있습니다. |

### Codex 연결을 기다리는 동안 조사 실습을 이어가는 대안

**Aside 브라우저 자체 대화가 정상 동작하는 경우에만** 사용합니다.

1. Aside 안의 AI 대화 입력창을 엽니다.
2. **3주차 실습 안내서에서 내가 하려던 조사 문장**을 복사해 붙여넣습니다. 함께 보낼 링크: [3주차 실습 안내서](./3기_3주차_실습_AI에게_브라우저_일_맡기기.html).
3. "나는 컴퓨터 초보자야. 실제 페이지를 확인해 조사하고 결과를 먼저 보여 줘. 게시판이나 카톡에는 보내지 마"를 덧붙여 보냅니다.

조사 내용을 확인하고 저장하는 것까지 먼저 해 보세요. **이 대안으로 결과를 만들었어도 Codex와 Aside의 연결이 복구된 것은 아닙니다.** Aside 자체 대화도 안 되면 [11번](#question)으로 질문을 남깁니다.

## 6. 텔레그램 테스트 메시지가 안 와요 / Python을 설치하래요

녹음 비서 안내서의 **13-3 「테스트 메시지 보내기」**에서 막힌 경우입니다.
Python은 컴퓨터에서 알림 프로그램을 실행하는 데 필요한 도구입니다. **먼저 Codex에게 설치 확인과 해결을 맡기세요.**

### 지금 하실 것

1. 휴대폰 텔레그램에서 **내가 만든 봇** 대화창을 엽니다. BotFather나 번호 알려 주는 봇이 아닙니다.
2. 아직 누르지 않았다면 **Start(시작)**를 누르고 `안녕하세요`라고 한 줄 보냅니다.
3. 녹음 비서를 만들던 **ChatGPT 앱(Codex) 대화**에 아래 상자를 붙여넣습니다.

```text
3기 심화실습 #2의 13-3 텔레그램 테스트에서 막혔어. 나는 컴퓨터 초보자야.
안내서: https://github.com/aiautomationstudy/study_exercises/blob/main/3기/실습/3기_심화실습_2_녹음하면_알아서_정리하는_내_비서_만들기.md
내 봇에게 Start를 누르고 인사했어. 기존 녹음자동처리 폴더에서 이어서 해결해 줘.
Python이 실제로 설치돼 있고 실행 가능한지 네가 먼저 확인해 줘.
이미 있으면 그 프로그램으로 실행해 줘. 없으면 공식 설치 방법을 확인하고 가능한 설치는 직접 해 줘.
내가 설치 허용을 누르거나 앱을 다시 켜야 한다면 그 단계만 쉽게 알려 줘.
알림 프로그램과 설정 파일의 실제 위치도 확인하고, 필요한 수정은 백업 후 직접 해 줘.
봇 토큰은 내가 메모장에 저장한 파일을 프로그램에서 사용해. 대화창에 달라고 하거나 화면·로그에 보여 주지 마.
테스트 메시지를 한 번 보내고 실제 전송 결과를 확인해 줘. 내 휴대폰에 왔는지도 물어봐 줘.
안 되면 같은 실패를 반복하지 말고 다음에 할 한 가지만 알려 줘.
```

**성공 확인:** 내 휴대폰의 **내 봇 대화창**에 「녹음 자동 정리 알림 테스트입니다」가 도착합니다.

### 내가 직접 Python 설치를 해야 할 때만

Codex가 설치할 수 없다고 확인한 경우에만 아래를 합니다. 먼저 이미 설치돼 있는지 Codex가 확인하게 하세요.

1. [Python 공식 설치 안내](https://www.python.org/downloads/)를 엽니다. **Python install manager**라고 적힌 설치 항목을 찾습니다. 페이지가 다르면 화면을 ChatGPT.com에 보여 주고 그 항목을 짚어 달라고 하세요.
2. 내려받은 설치 파일을 엽니다. **Python install manager** 설치 화면이면 「Install(설치)」을 누릅니다. Microsoft Store로 안내된 경우에는 그 앱의 설치를 누릅니다.
3. 설치가 끝나면 ChatGPT 앱을 완전히 종료했다가 다시 엽니다. 녹음 실습 프로젝트의 원래 대화를 엽니다.
4. "Python 설치 관리자를 설치했어. 필요한 Python 실행 준비를 네가 마무리하고 위 테스트를 이어서 해 줘"라고 보냅니다.

**설치 화면이 안내와 다르면:** 예전 설치 프로그램에는 「Add Python to PATH」라는 체크박스가 있었지만 설치 관리자 화면은 다릅니다. 안 보이는 체크박스를 찾느라 멈추지 마세요. 화면을 [ChatGPT.com](https://chatgpt.com)에 보여 주고 한 단계씩 안내받으세요. 기존 Python을 삭제하지 않습니다. [현재 공식 Windows 설치 설명](https://docs.python.org/3/using/windows.html#python-install-manager)

회사·학교 PC에서 설치가 막히고 관리자 비밀번호를 요구하면 그 PC의 담당자 허락이 필요합니다. 개인 실습은 설치 가능한 본인 PC에서 이어갈 수 있습니다.

### 내 텔레그램 번호를 알려 주는 봇이 답하지 않을 때

[녹음 비서 안내서](https://github.com/aiautomationstudy/study_exercises/blob/main/3기/실습/3기_심화실습_2_녹음하면_알아서_정리하는_내_비서_만들기.md)의 **12-2**를 엽니다. `@userinfobot` 직접 링크와 **내 봇으로 번호를 확인하는 복사 문장**이 있습니다. 그 문장을 Codex에 보내면 됩니다. 다른 봇을 계속 찾아다니지 않습니다.

**봇 토큰은 비밀번호입니다.** 메모장에 저장하고, 질문·카톡·게시판·화면 캡처에는 넣지 않습니다. 이번 실습의 내 봇 알림과 허브 프로필의 「스터디 답변 알림」은 서로 다른 기능입니다.

## 7. 녹음 파일을 넣었는데 정리가 안 돼요

**Codex가 파일을 직접 찾아 확인하게 하세요.** 검은 창이나 어려운 프로그램 이름을 여러분이 해석할 필요는 없습니다.

```text
녹음 비서 실습에서 녹음 파일을 넣었는데 결과 문서가 안 생겨.
기존 녹음자동처리 폴더와 내가 넣은 녹음 파일을 찾아 확인해 줘.
녹음을 글로 옮기는 프로그램과 ffmpeg가 실제로 실행되는지 네가 확인해 줘.
없거나 경로가 잘못됐으면 공식 설치와 경로 수정을 가능한 범위에서 직접 해 줘.
원본 녹음과 기존 결과는 지우지 말고, 샘플 녹음 한 개로 직접 처리해 줘.
끝에는 생긴 문서의 실제 위치를 알려 줘. 다섯 문서 중 일부만 생겼다면 빠진 단계만 해결해 줘.
한글 폴더 이름 때문이라고 추측하지 말고 실제 오류로 확인해 줘.
내가 해야만 할 것이 있으면 한 단계씩 쉽게 알려 줘.
```

**성공 확인:** `notes` 아래 해당 녹음의 폴더에 전사 원문·정제본·상세정리·요약·확인사항 문서가 생깁니다. 안내서의 기본 결과는 다섯 문서입니다.

### 잘 안 될 때 참고

| 막힌 것 | Codex에게 덧붙일 문장 |
|---|---|
| `ffmpeg`를 찾지 못한다고 함 | "ffmpeg가 실제로 있는지 확인하고 없으면 설치해 줘. 내가 명령어를 입력하지 않도록 직접 실행까지 확인해 줘." |
| 일부 결과만 생김 | "이미 생긴 결과를 지우지 말고, 어느 단계에서 멈췄는지 확인해서 빠진 문서만 만들어 줘." |
| 한글 사용자명·폴더 이름이 원인이라고 함 | "실제 오류와 경로로 확인해 줘. 내 Windows 사용자 이름은 바꾸지 마. 경로 문제로 확인되면 원본을 보존하고 실습 파일만 안전한 위치에서 시험해 줘." |
| 5분마다 검은 창이 떠서 불편함 | "기존 자동 처리가 검은 창을 띄우는지 확인해 줘. 처리는 유지하고 조용히 실행할 수 있게 수정·검증해 줘." |
| Windows가 프로그램을 막음 | "탐지 화면과 프로그램 출처를 확인해 줘. Windows 보안을 끄거나 폴더 전체를 예외로 하지 말고 다음에 할 한 가지만 알려 줘." |

**심화실습 #3을 먼저 시작하셨나요?** #3은 #2의 **Part 5 「브라우저 관제판 만들기」까지** 준비가 필요합니다. Codex에 "#3을 시작하려고 해. #2의 Part 5까지 내 폴더에 무엇이 준비됐는지 확인하고 빠진 것부터 진행해 줘"라고 보내세요.

## 8. 휴대폰 녹음 옮기기·Notion 연결에서 막혔어요

이 부분은 녹음 비서의 **선택 확장**입니다. 여기서 막혀도 컴퓨터에 직접 넣은 녹음 한 개를 정리하는 기본 실습부터 끝낼 수 있습니다.

| 막힌 곳 | 지금 하실 것 |
|---|---|
| 휴대폰에서 컴퓨터로 녹음이 안 넘어옴 | 먼저 녹음 하나를 컴퓨터의 `inbox`에 직접 옮겨 기본 처리를 확인합니다. 휴대폰 전송 설정은 아래 문장으로 따로 맡깁니다. |
| Notion에 페이지가 안 생김·권한 오류 | 연결하려는 Notion 페이지를 열고 아래 문장과 오류를 Codex에 보냅니다. 비밀번호·연결용 비밀값은 보내지 않습니다. |

```text
녹음 비서의 휴대폰 전송 또는 Notion 연결에서 막혔어.
어느 단계인지는 아래에 적을게. 이미 컴퓨터에서 되는 녹음 처리는 그대로 보존해 줘.
내가 쓰는 휴대폰과 전송 앱, 또는 연결하려는 Notion 페이지의 권한을 실제로 확인해 줘.
네가 수정할 수 있는 설정·프로그램은 직접 해결해 줘.
휴대폰에서 권한을 누르거나 Notion 페이지에서 연결을 허용해야 한다면,
어느 기기의 어떤 앱에서 무슨 버튼을 누르는지 한 단계씩 알려 줘.
연결 비밀번호나 비밀값을 대화창에 달라고 하지 마.
끝에는 녹음 한 개가 실제로 넘어왔는지 또는 Notion 페이지가 실제로 생겼는지 확인해 줘.
```

## 9. 자료·과제는 어디에 있나요? 결과는 어떻게 올리나요?

### 자료 다시 보기

[스터디 허브](https://study.saedongne.com/automation/)에서 **학습자료**를 누릅니다. 주차별 안내서와 녹화 영상을 찾아볼 수 있습니다. 아직 시작하지 못했다면 하려던 기본 실습 안내서 하나부터 보세요. 이 안내서는 새 과제가 아니라 **막힌 곳을 해결하는 도움말**입니다.

### 결과 올리기

1. [과제·실습 공유](https://study.saedongne.com/automation/board.html?board=13)를 엽니다.
2. 「글쓰기」를 누르고 **제목**과 **무엇을 만들어 봤는지** 적습니다.
3. 공개해도 되는 결과 링크를 붙이거나 캡처 이미지를 올립니다. 캡처 붙여넣기가 안 되면 글쓰기 화면의 **이미지 첨부**에서 저장한 PNG/JPG 파일을 선택합니다.
4. 저장한 뒤 내 글을 다시 열어 **이미지나 링크가 실제로 보이는지** 확인합니다.

미완성이어도 어디까지 됐고 어디에서 막혔는지 함께 적을 수 있습니다. 질문은 [묻고 답하기](https://study.saedongne.com/automation/board.html?board=16)에 남겨 주세요.

**`.md` 파일만 있나요?** Codex에 "이 문서를 읽기 편한 HTML 파일로 만들어 줘. 내가 내용을 확인한 뒤 공유할 수 있게 해 줘. 아직 공개하지는 마"라고 요청합니다. `.md`는 글 문서입니다. MarkText로 열면 보기 편합니다. 메모장에서 보이는 `#`·`**`는 문서 서식 표시입니다.

요구사항 정의서에 대한 **개별 답변은 해당 학습자료 글의 댓글**에서 확인합니다. 파일 첨부·본문 길이 오류가 나면 같은 글을 여러 번 올리지 말고 오류 화면과 글 제목을 질문에 함께 적어 주세요.

## 10. 음성 입력·사용 한도·사이트 수정에서 막혔어요

### 말을 했는데 엉뚱한 글자가 나와요

지금 실습은 **글로 입력해서 먼저 이어갈 수 있습니다.** Windows의 「음성 녹음기/녹음기」에서 짧게 녹음해 내 목소리가 들리는지 확인합니다. 들리지 않거나 ChatGPT에서만 잘못 받아쓰면 그 결과와 화면을 [ChatGPT.com](https://chatgpt.com)에 보여 주고 한 단계씩 점검해 달라고 하세요. 마이크 고장이라고 단정하지 않습니다.

### 사용 한도에 도달했다고 나와요

화면에 나온 **도구 이름·한도 안내·다시 쓸 수 있는 시각**을 확인합니다. 어떤 서비스의 한도인지 모른 채 추가 결제하지 않습니다. ChatGPT.com을 쓸 수 있으면 화면을 보여 주고 "지금 한도가 무엇인지, 추가 결제 없이 언제 무엇을 할 수 있는지 설명해 줘"라고 물어보세요. 기다리는 동안에는 안내서를 읽거나 다음에 만들 내용을 메모해 둘 수 있습니다.

### 만든 사이트가 수정되지 않아요 / 게시가 차단됐어요

```text
이미 만든 사이트를 수정하려다 막혔어. 아래에 사이트 주소와 오류를 붙일게.
원본 파일과 현재 공개된 화면을 각각 확인해 줘.
어떤 수정이 저장됐고 실제 사이트에는 무엇이 반영됐는지 구분해 줘.
가능한 수정은 기존 결과를 보존하고 직접 진행해 줘.
게시 권한이나 로그인에서 사람이 할 일이 있다면 한 단계씩 알려 줘.
실제 사이트를 다시 열어 확인하기 전에는 반영됐다고 말하지 마.
이미 실패한 방법을 반복하거나 보호 설정을 임의로 바꾸지 마.
```

허락 요청조차 안 된다는 오류가 반복되면 [2번](#chat)으로 옮겨 물어보세요. 임시로 컴퓨터에서 열리는 결과 파일을 만들 수 있는지도 확인하게 합니다. **컴퓨터에서 보이는 파일과 다른 사람이 볼 수 있는 공개 사이트는 다릅니다.**

## 11. 그래도 막히면 이렇게 질문해 주세요

[묻고 답하기](https://study.saedongne.com/automation/board.html?board=16) 또는 [Q&A 챗봇](https://study.saedongne.com/automation/qna.html)에 아래 형식으로 남기면 확인하기 쉽습니다.

```text
하던 실습과 안내서 주소:
막힌 단계:
화면에 나온 말(그대로 복사):
이미 해 본 것과 결과:
사용 중인 컴퓨터: Windows / Mac
```

화면도 함께 올릴 수 있습니다. 이름·전화번호·계정·비밀번호·봇 토큰은 가려 주세요. **전체 설정 파일이나 전체 대화 기록을 올릴 필요는 없습니다.**

Q&A 챗봇의 답은 **그 질문 대화에서** 확인합니다. 운영진의 추가 답변도 같은 대화에 남을 수 있으니 [Q&A의 질문 기록](https://study.saedongne.com/automation/qna.html?tab=hist)에서 내 질문을 다시 열어 보세요.
