# 기본실습 — AI에게 브라우저 일 맡기기

쉬운 따라 하기 개정: 2026-10-27

**오늘은 AI에게 서울숲 정보를 찾아 한 장 안내문으로 만들게 합니다.** 그 안내문의 글씨를 크게 바꿔 보고, 실제로 달라졌는지 확인하면 됩니다. 서울에 살지 않아도 이 예제로 연습할 수 있습니다.

**오늘의 순서: 준비 → 조사해 만들기 → 한 군데 고치기.** 처음에는 아래 순서 하나만 따라 하세요. 다른 예제는 끝낸 뒤 골라도 됩니다.

## 시작 전에: 이 안내서는 어디에서 보나요?

**컴퓨터에서 이 안내서를 열어 두세요.** 휴대폰으로 읽고 있다면 같은 주소를 컴퓨터에서도 엽니다. 실습은 컴퓨터에서 합니다.

화면 두 개를 번갈아 씁니다.

- **이 안내서:** 읽고 「문장 복사」를 누르는 곳입니다.
- **ChatGPT 앱(Codex):** 복사한 문장을 보내고, AI의 답을 읽는 곳입니다. 인터넷 주소창이나 스터디 Q&A에 붙이지 않습니다.

**매번 이렇게 합니다.**

1. 이 안내서에서 초록색 **「문장 복사」**를 누릅니다.
2. **ChatGPT 앱(Codex)**으로 갑니다. 화면 아래 **메시지를 쓰는 빈칸**을 한 번 누릅니다.
3. 키보드의 **Ctrl을 누른 채 V**를 누릅니다. Mac은 **⌘를 누른 채 V**입니다.
4. 글이 들어갔는지 보고 **보내기 화살표**를 누릅니다.
5. AI의 답을 읽고 필요한 질문에 답합니다. **한 단계가 끝난 뒤 다음 문장**을 보냅니다.

문장이 길어도 직접 입력하거나 외울 필요는 없습니다. 복사 단추가 없는 Markdown 화면이라면 문장 상자 안의 글 전체를 선택해 복사하세요.

## 0. 앱과 내 작업 폴더 열기

**전에 하던 실습이 있나요?** ChatGPT 앱(Codex)의 왼쪽 목록에서 그때의 대화를 누르세요. 같은 일을 다시 시작하거나 파일을 지울 필요는 없습니다.

**처음인가요?**

1. 컴퓨터에서 **ChatGPT 앱**을 열고 **Codex**를 선택합니다.
2. **새 채팅(New chat)**을 엽니다. 파일을 저장할 폴더를 고르라는 화면이 나오면, 아래 방법으로 내 실습 폴더를 만듭니다.
3. 폴더 선택 화면에서 **문서 → 새 폴더**를 누르고 아래 안내된 이름을 적습니다. 만든 폴더를 선택합니다. **폴더**는 이번 실습의 파일을 모아 두는 곳입니다.
4. **Aside**도 켜 둡니다. AI가 인터넷을 열어 일하는 모습을 확인하는 프로그램입니다.

화면에 「프로젝트 추가(Add new project)」나 「폴더 열기」가 보이면 그것으로 내 실습 폴더를 열어도 됩니다. 모델 이름이나 추론 설정은 지금 바꾸지 않아도 됩니다.

**앱이 없거나 로그인부터 안 되나요?** [앱·Aside 준비 안내](https://study.saedongne.com/automation/board.html?id=1175)를 보세요. 이미 설치한 프로그램은 다시 설치하지 않습니다. 로그인은 **본인 계정**으로 하고, 비밀번호·인증번호는 AI 대화창에 쓰지 않습니다.

처음 만드는 폴더 이름은 **ai-practice**로 적으세요. 이미 이 실습을 하던 폴더가 있으면 그것을 씁니다.

## 1. AI에게 준비 확인 맡기기

아래 문장을 복사해 보냅니다. 영어 명령을 직접 입력할 필요는 없습니다.

```text
나는 컴퓨터 초보야. 이 대화에서 실습을 이어가고 싶어.
이미 설치한 앱과 만든 파일은 보존하고, 내 실습 폴더부터 확인해줘.
ChatGPT 앱(Codex)에서 Aside로 직접 웹 작업을 할 준비가 됐는지 확인해줘.
설치된 aside-browser 스킬과 현재 공식 가이드를 읽고, 실제 연결 상태를 확인해줘.
웹 작업은 Codex인 네가 aside repl로 직접 해줘. Aside 안의 별도 AI에게 작업을 넘기지 마.
준비가 덜 됐다면 아래 준비 안내서에서 내 컴퓨터에 해당하는 부분만 확인해줘.
https://github.com/aiautomationstudy/study_exercises/blob/main/3기/실습/3기_3주차_사전준비_안내서.md
준비 안내서 읽기와 Aside 자체 설치·복구에 필요한 공개 자료는 공식 주소와 위 안내서에서 내려받아도 돼.
반복 설치하거나 보안 설정을 모두 끄지 말고, 같은 오류가 두 번 나면 멈추고 알려줘.
내가 로그인하거나 허락해야 할 때는 어느 화면에서 무엇을 누르는지 한 가지씩 알려줘.
끝나면 준비된 것, 아직 안 된 것, 내가 다음에 할 일을 쉬운 말로 알려줘.
아직 조사나 글 작성은 시작하지 마.
```

**다음으로 넘어갈 때:** AI가 내 작업 폴더와 Aside 연결을 확인했다고 알려 줍니다. 「명령을 찾지 못했다」·「로그인 필요」·「연결 실패」라면 아직 준비 중입니다. AI가 안내한 한 가지를 처리한 뒤 **“했어. 다시 확인해줘”**라고 답합니다.

## 2. 서울숲 안내문 한 장 만들기

**1단계의 같은 대화**에 아래 문장을 보냅니다. 이번에는 주제를 고르거나 빈칸을 채울 필요가 없습니다.

```text
서울숲에 처음 가는 사람을 위한 한 장 안내문을 만들어줘.
Codex인 네가 Aside에서 서울시·서울숲의 공식 안내 페이지를 직접 열어 확인해줘.
검색이 필요하면 네이버에서 찾고, 가입이나 결제가 필요한 자료는 쓰지 마.
주소, 대중교통으로 가는 방법, 처음 방문할 때 알아둘 점 세 가지를 쉬운 말로 정리해줘.
실제로 읽은 출처의 제목·주소와 확인 날짜를 함께 넣고, 확인하지 못한 것은 미확인이라고 적어줘.
이전 실습 파일이 있으면 확인해서 이어 쓰고, 원본을 덮어쓰기 전에는 사본을 남겨줘.
내 실습 폴더에 안내문.html로 저장하고, 내가 실제 결과 화면을 볼 수 있게 열어줘.
웹을 읽고 결과를 열 때는 aside repl을 사용하고, 내 마우스나 다른 작업 중인 탭은 건드리지 마.
가능하면 하나의 지속 세션에서 작업하고, 끝나면 내가 결과를 볼 수 있게 그 작업 탭을 남겨줘.
탭을 남길 수 없으면 결과 파일을 다시 여는 방법을 한 가지씩 알려줘.
화면에 안 열렸다면 파일을 저장한 것과 화면 확인을 구분해서 알려줘.
공개 게시·가입·결제·메시지 발송은 하지 마.
```

**내 눈으로 확인할 것 세 가지:**

1. 결과 화면에 **서울숲 안내문**이 보이나요?
2. **주소와 가는 방법**이 적혀 있나요?
3. **출처 링크 하나**를 눌렀을 때 근거가 된 공식 페이지가 열리나요?

**AI가 “완료”라고 해도 안내문 화면이 안 보이면** “만든 안내문이 안 보여. 내가 지금 어디를 눌러야 하는지 한 가지씩 알려줘”라고 답하세요. 글이 보이기 전에는 다음 단계로 가지 않습니다.

**안내문.html은 결과 파일 이름입니다.** 파일을 두 번 눌러 열면 인터넷 페이지처럼 읽을 수 있습니다. 이 파일을 만들었다고 인터넷에 공개된 것은 아닙니다.

## 3. 글씨를 크게 바꾸기

같은 대화에 보냅니다.

```text
방금 만든 서울숲 안내문을 고쳐줘. 새 안내문을 처음부터 만들지는 마.
고치기 전 파일은 사본으로 남기고, 본문 글씨를 지금보다 크게 해줘.
내용과 출처 링크는 그대로 두고, 저장한 뒤 결과 화면을 다시 열거나 새로고침해줘.
내가 같은 화면에서 글씨가 커졌는지 확인하게 해줘.
결과 파일을 다음에 다시 여는 방법과 저장 위치를 쉬운 말로 알려줘.
```

**완료 확인:** 안내문 글씨가 커졌고, 출처 링크가 계속 열리면 **오늘의 기본실습을 마쳤습니다.** 더 많은 주제나 퀴즈를 지금 모두 할 필요는 없습니다.

## 다음에 이어서 하려면

ChatGPT 앱(Codex)의 왼쪽 목록에서 **이번 실습 대화**를 다시 열고 말합니다.

```text
지난 브라우저 실습을 이어서 하고 싶어.
이전에 만든 안내문과 작업 기록을 확인하고, 된 작업은 반복하지 마.
다음에는 내가 정하는 장소로 안내문을 바꾸고 싶어. 장소 이름부터 물어봐줘.
```

## 막히면 여기만 보세요

다음 문장을 **지금까지 실습하던 ChatGPT 앱(Codex)의 같은 대화**에 보냅니다. 오류 문구가 있으면 바로 다음 메시지에 그대로 보내세요.

```text
여기서 막혔어. 나는 컴퓨터를 잘 몰라.
이미 만든 파일과 끝낸 작업은 보존하고, 현재 상태부터 확인해줘.
지금 내가 해야 할 한 가지만, 어느 화면에서 무엇을 누르는지 알려줘.
같은 방법이 두 번 실패했다면 또 반복하지 말고 다른 방법을 확인해줘.
지금 안 되는 기능은 됐다고 하지 말고, 된 것과 안 된 것을 구분해줘.
```

AI가 대답하지 않아 문장을 보낼 수 없다면 [실습하다 막혔을 때, 이렇게 해 보세요](https://study.saedongne.com/automation/board.html?id=1268)를 먼저 보세요. 그래도 안 되면 [묻고 답하기](https://study.saedongne.com/automation/board.html?board=16)에 **어느 실습·어느 단계인지, 오류 문구, 이미 해 본 방법**을 적어 주세요. 화면을 올릴 때는 이름·비밀번호·인증번호·토큰을 가립니다.

## 결과를 나누고 싶다면

[과제·실습 공유](https://study.saedongne.com/automation/board.html?board=13)에서 **글쓰기**를 누릅니다. 해 본 일과 막힌 점을 적고, 결과 화면을 이미지로 넣은 뒤 **완료하고 올리기**를 누릅니다. 이미 올린 글은 **고치기**로 보완하면 됩니다.

내 컴퓨터의 파일 주소나 `localhost` 주소는 다른 사람이 열 수 없습니다. 공개한 글 주소나 화면 캡처를 올리세요. 비공개 원고·내부 지침·계정 정보는 올리지 않습니다.
