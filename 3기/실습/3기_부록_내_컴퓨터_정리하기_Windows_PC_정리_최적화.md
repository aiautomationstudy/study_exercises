# 3기 부록 — 내 컴퓨터 정리하기 (Windows PC 정리·최적화)

## Codex에게 맡겨서, 느린 컴퓨터를 안전하게 청소하고 빠르게 만들기

> **이 안내서로 할 수 있는 것**
>
> - Windows 업데이트가 밀려 있는지 확인하고 최신으로 맞춥니다.
> - **기간이 끝난 유료 백신**(맥아피·노턴·V3·알약 등), 컴퓨터 살 때 같이 깔려 온 **불필요한 프로그램**, 이름 모를 **수상한 프로그램**을 찾아서 **내가 고른 것만** 지웁니다.
> - 컴퓨터를 켤 때마다 저절로 켜지는 프로그램을 줄여서 **부팅 속도**를 높입니다.
> - 임시 파일·휴지통·오래된 설치 파일을 치워서 **저장 공간**을 확보합니다.
> - **Windows 보안(Windows Defender)** 으로 악성 프로그램을 검사합니다.
> - 끝나고 나면 **전·후 비교 보고서**를 받습니다.
>
> **걸리는 시간**: 2~3시간 (기다리는 시간이 대부분입니다. 나눠서 해도 됩니다)
> **어려운 것**: 없습니다. 여러분은 **회색 상자를 복사해서 붙여넣고**, Codex가 보여 주는 목록에서 **지울 번호를 고르기만** 합니다.

> **⚠ 시작하기 전에 딱 네 가지**
>
> 1. **내 개인 컴퓨터**에서 하세요. **회사·학교에서 준 컴퓨터는 하지 마세요.** 관리자가 깔아 둔 보안 프로그램을 지우면 문제가 됩니다.
> 2. **전원 어댑터를 꽂으세요.** 업데이트 도중에 배터리가 끝나면 컴퓨터가 망가질 수 있습니다.
> 3. **소중한 파일이 있으면 미리 복사해 두세요.** (사진·문서를 USB나 클라우드에) 이 안내서는 **내 문서·사진·바탕화면·다운로드 폴더의 파일을 지우지 않게** 만들었지만, 백업은 언제나 안전합니다.
> 4. **인터넷이 연결돼 있어야** 합니다. (업데이트를 받기 때문입니다)

# 0장. 이 안내서를 읽는 법

## 「Codex」가 뭔가요? (처음 들어 보셔도 괜찮습니다)

**Codex는 ChatGPT 앱 안에 들어 있는 「내 컴퓨터를 직접 만져 주는 AI 도우미」** 입니다.

| | 하는 일 | 비유 |
| --- | --- | --- |
| **브라우저의 ChatGPT** (chatgpt.com) | 대화만 합니다. 내 컴퓨터는 못 만집니다 | 전화 상담원 — 말로만 알려 줌 |
| **ChatGPT 앱의 Codex** | 내 컴퓨터를 **직접 살펴보고, 설치하고, 정리하고, 고칩니다** | **집에 와서 직접 손봐 주는 수리 기사** |

이 안내서에서는 여러분이 **컴퓨터 설정을 직접 뒤지지 않습니다.** 회색 상자의 글을 Codex에게 전해 주면, Codex가 컴퓨터를 살펴보고 **「이런 게 있는데 지울까요?」** 하고 물어봅니다. 여러분은 **번호로 답하기만** 하면 됩니다.

> **안심하세요.** Codex는 **내가 허락한 것만** 합니다. 무언가를 하기 전에 **허락 창**이 뜨고, 이 안내서는 **지우기 전에 반드시 목록을 보여 주고 내가 고른 것만** 지우도록 시킵니다.

**Codex를 쓰려면 세 가지가 필요합니다.** 1장에서 차례로 확인합니다.

1. 컴퓨터에 **ChatGPT 앱**이 설치돼 있다 (브라우저가 아니라 **프로그램**입니다)
2. 그 앱에 **내 ChatGPT 계정으로 로그인**돼 있다
3. 앱 안에서 **Codex를 선택**했다

## 이 안내서는 「심화실습」과 같은 방식입니다

회색 상자를 **통째로 복사 → ChatGPT 앱(Codex)에 붙여넣기 → Enter**. 이게 전부입니다. 직접 타이핑하지 않습니다.

## 회색 상자는 전부 「여기」에 붙여넣습니다

**컴퓨터에 설치한 ChatGPT 앱 → Codex → 「pc-cleanup」 프로젝트의 채팅 맨 아래 입력창**

| ⭕ 여기에 붙여넣습니다 | ❌ 여기가 아닙니다 |
| --- | --- |
| **ChatGPT 앱**의 **Codex** 화면 맨 아래 입력창 | 크롬·엣지로 연 chatgpt.com |
| | 검은 창(PowerShell), 메모장 |

### 복사해서 붙여넣는 법 (매번 똑같습니다)

1. 회색 상자 **오른쪽 위 구석**에 마우스를 올리면 **네모 두 개가 겹친 복사 단추**가 나옵니다. 한 번 누릅니다.
2. **ChatGPT 앱** 창을 누르고, 맨 아래 **입력창을 한 번 클릭**합니다.
3. **Ctrl + V** 를 누릅니다. 글이 통째로 들어옵니다. **고치지 않습니다.**
4. **Enter** 를 누릅니다.

**한 상자 = 한 번에 통째로.** 끝나면 Codex가 결과를 알려 줄 때까지 기다렸다가 **같은 채팅에 이어서** 다음 상자를 붙여넣습니다. 새 채팅을 만들지 않습니다.

## ChatGPT 앱이 아예 안 열리거나 Codex가 안 보이면

Windows 업데이트가 오래 밀려 있으면 앱이 안 켜지기도 합니다. 이때는 **1장의 「손으로 하는 Windows 업데이트」** 를 먼저 끝내고 앱을 다시 켜 보세요. 그래도 안 되면 스터디 허브 Q&A에 **화면 캡처**와 함께 올려 주세요.

👉 https://study.saedongne.com/automation/qna.html

## Codex의 「허락 창」과 Windows의 「변경 허용 창」은 다릅니다

이 실습에서는 두 종류의 창이 뜹니다.

| 창 | 모양 | 어떻게 하나요 |
| --- | --- | --- |
| **Codex의 허락 창** | ChatGPT 앱 안에 「한 번만 허용」「이 대화 허용」「거부」 단추 | 내용을 읽고 **「한 번만 허용」**. **“파일 삭제”** 라는 말이 있으면 누르지 말고 Codex에게 “무엇을 왜 지우려는 거야?”라고 물으세요 |
| **Windows의 변경 허용 창** | 화면이 어두워지며 **「이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?」** | **Codex가 방금 “관리자 권한이 필요합니다”라고 알려 준 직후**에만 **「예」**. 아무 일도 안 시켰는데 갑자기 뜨면 **「아니요」** |

> 업데이트·프로그램 제거는 「관리자 권한」이 있어야 합니다. 그래서 Windows의 변경 허용 창이 여러 번 뜹니다. 정상입니다.

## 이 안내서의 안전 규칙 (Codex에게도 그대로 시킵니다)

- **내 파일은 안 지웁니다.** 문서·사진·바탕화면·다운로드·음악·동영상 폴더는 건드리지 않습니다.
- **지우기 전에 반드시 목록을 보여 주고, 내가 번호로 고른 것만** 지웁니다.
- **Windows 보안(Defender)·방화벽·Windows 업데이트는 끄지 않습니다.**
- **「PC 최적화」「레지스트리 청소」 같은 프로그램은 깔지 않습니다.** (무료를 미끼로 오히려 컴퓨터를 망치는 경우가 많습니다)
- 시작하기 전에 **복원 지점**(문제가 생기면 돌아갈 수 있는 저장 시점)을 만듭니다.
- **은행·관공서 보안 프로그램**(키보드보안·공동인증서·IPinside 등)은 **지우지 않고 물어봅니다.** 인터넷뱅킹에 필요합니다.

# 1장. 준비 — 작업 폴더 만들고 Codex에 연결하기

이번 실습 전용 폴더를 만듭니다. Codex가 점검 결과와 보고서를 여기에 적습니다.

## 1-1. 폴더 만들기

1. 키보드 **Windows 키 + E** → 파일 탐색기가 열립니다.
2. 위쪽 **주소창을 한 번 클릭**하고 `%USERPROFILE%` 이라고 친 뒤 **Enter** → 내 홈 폴더가 열립니다.
3. 이미 **`ai-work`** 폴더가 있으면(앞 실습에서 만든 것) 그 안으로 들어갑니다. 없으면 빈 곳에서 **마우스 오른쪽 → 새로 만들기 → 폴더** → 이름을 `ai-work` 로 하고 들어갑니다.
4. 그 안에서 같은 방법으로 폴더를 하나 더 만듭니다. 이름은 **`pc-cleanup`** (영문 소문자, 하이픈).

> 폴더 이름에 **한글이나 공백을 넣지 마세요.** 뒤에서 막히는 원인이 됩니다.

## 1-2. ChatGPT 앱을 열고 Codex 선택하기

### ① ChatGPT 앱이 설치돼 있나요?

1. 키보드의 **Windows 키**(창문 모양, 키보드 왼쪽 아래)를 누릅니다.
2. 바로 `ChatGPT` 라고 입력합니다. (검색창이 저절로 열립니다)
3. 결과에 **ChatGPT 앱**이 보이면 **Enter** → **앱이 열립니다.** ②로 가세요.
4. **앱이 안 보이면 아직 설치하지 않은 것**입니다. 아래 주소의 안내대로 설치하고 돌아오세요.
   👉 https://study.saedongne.com/automation/board.html?id=880

> **헷갈리기 쉬운 점**: 크롬·엣지 같은 **인터넷 창**에서 chatgpt.com 을 여는 것은 **앱이 아닙니다.** 그쪽에는 Codex가 없습니다. 반드시 **Windows 키로 찾아서 여는 ChatGPT 프로그램**이어야 합니다.
>
> **설치는 됐는데 켜면 아무 반응이 없다면**: 윈도우 사용자 이름이 **한글**이거나(`C:\Users\홍길동`) Windows 업데이트가 많이 밀려서일 수 있습니다. 위 주소의 글에 해결법이 있습니다. 먼저 **1-4의 Windows 업데이트**를 끝내고 다시 켜 보세요.

### ② 로그인하기

- 앱이 처음 열리면 **로그인 화면**이 나옵니다. **내 ChatGPT 계정**(이메일)으로 로그인합니다.
- 이미 대화 화면이 보이면 **로그인돼 있는 것**입니다. 다시 하지 않습니다.
- 비밀번호·인증 번호를 묻는 창이 나오면 **그때만 직접 입력**합니다.

### ③ 「Codex」 선택하기

ChatGPT 앱에는 **세 가지 작업 공간**이 있고, 이름을 눌러서 바꿉니다.

| 이름 | 하는 일 |
| --- | --- |
| **Chat** | 그냥 대화 (평소 쓰던 ChatGPT) |
| **Work** | 문서·자료 작업 |
| **Codex** | **내 컴퓨터를 직접 만지는 작업** ← **이 안내서는 전부 여기서 합니다** |

1. 앱 창 **왼쪽 위 부분(왼쪽 메뉴)** 을 봅니다.
2. **「Codex」** 라는 글자를 **한 번 클릭**합니다.
3. 화면이 바뀌면서 **「프로젝트」** 나 **「새 프로젝트 추가」**, 또는 **글 쓰는 칸**이 보이면 **Codex가 선택된 것**입니다.

> **Codex가 안 보이면**
> - 앱이 **옛 버전**일 수 있습니다. 앱을 **완전히 끄고**(오른쪽 아래 작업 표시줄에서도 종료) 다시 켜 보세요. 그래도 없으면 **Windows 업데이트(1-4)** 후에 다시 확인하세요.
> - **다른 계정으로 로그인**돼 있을 수 있습니다. 앱 왼쪽 아래 **내 이름**을 눌러 계정이 맞는지 보세요.
> - 위 방법으로도 안 되면 앱 화면을 **캡처**해서 스터디 허브 Q&A에 올려 주세요. (캡처 방법은 11장)

## 1-3. Codex에 이 폴더 열어 주기

Codex는 **어느 폴더에서 일할지** 알아야 합니다. 방금 만든 **`pc-cleanup`** 폴더를 알려 줍니다. (내 문서나 사진이 있는 폴더가 아니라, **보고서만 들어갈 빈 폴더**입니다.)

1. **Codex**가 선택된 화면에서 **「새 프로젝트 추가」** 를 누릅니다.
2. **「기존 폴더 사용」** 을 누릅니다. (「처음부터 시작」이 아닙니다)
3. 폴더 고르는 창에서 **내 홈 폴더 → `ai-work` → `pc-cleanup`** 을 한 번 누르고 **「폴더 선택」**.
4. **“이 폴더를 신뢰할까요?”** 라고 물으면 **「폴더 신뢰」**. (내가 방금 만든 빈 폴더이니 안전합니다)
5. 화면에 **`pc-cleanup`** 이라는 이름이 보이고, **맨 아래에 글 쓰는 칸(입력창)** 이 있으면 준비 끝입니다.

### 화면이 이렇게 생겼습니다

```text
┌──────────────┬─────────────────────────────────────┐
│ 왼쪽          │  가운데: Codex와 나눈 대화가          │
│  Codex        │  위에서 아래로 쌓입니다               │
│  └ pc-cleanup │                                     │
│    └ 채팅들    │                                     │
│              ├─────────────────────────────────────┤
│              │  ★ 맨 아래 글 쓰는 칸 (입력창) ★      │
│              │  여기에 회색 상자를 붙여넣습니다       │
└──────────────┴─────────────────────────────────────┘
```

> **「새 프로젝트 추가」 글자가 안 보이면**: 왼쪽 위의 **프로젝트 이름(또는 「프로젝트 선택」)** 을 눌러 보세요. 목록 맨 아래에 있습니다. 버튼 글자가 조금 달라 보여도 **「폴더를 새로 추가한다」** 는 뜻의 버튼을 찾으면 됩니다.

### 한 번 인사해 보기 (제대로 연결됐는지 확인)

입력창을 한 번 클릭하고 **직접 타이핑해서** 이렇게 씁니다. (이번에 한해서는 짧으니 그냥 치세요)

```text
안녕. 지금 네가 일하는 폴더 이름을 알려 줘.
```

**Enter** → Codex가 **`pc-cleanup`** 이라고 대답하면 성공입니다.

- 대답이 **다른 폴더 이름**이면: 왼쪽에서 **`pc-cleanup`** 을 다시 누르고 **「새 채팅」** 을 눌러 같은 질문을 하세요.
- **아무 반응이 없으면**: 10~20초 기다려 보세요. 그래도 없으면 **Enter를 한 번 더** 누르세요.

### Codex가 일을 시작하면 이렇게 보입니다

- 입력창 위쪽 또는 가운데에 **「작업 중…」** 이라는 표시가 뜨고 **글이 계속 올라옵니다.** 일하는 중이니 **끄지 말고 기다립니다.**
- Codex가 **「이 작업을 해도 될까요?」** 하는 **허락 창**을 띄우면 내용을 읽고 **「한 번만 허용」** 을 누릅니다. (자세한 기준은 0장 「허락 창」 표)
- 끝나면 Codex가 **정리된 답**을 보여 줍니다. 답이 끝나기 전에 **다음 상자를 붙여넣지 마세요.**

### 채팅을 다시 찾는 법

중간에 앱을 껐다 켜도 **대화는 사라지지 않습니다.**

1. ChatGPT 앱을 열고 **Codex**를 선택합니다.
2. 왼쪽에서 **`pc-cleanup`** 을 누릅니다.
3. 그 아래 **어제 하던 채팅**을 누르면 이어서 할 수 있습니다.
4. 입력창에 “**다시 켰어. 이어서 진행해 줘.**”라고 쓰고 Enter.

## 1-4. 손으로 하는 Windows 업데이트 (먼저 한 번만)

Codex가 업데이트 **상태는 확인**할 수 있지만, 설치 단추는 **내가 누르는 것이 가장 확실**합니다. 지금 합니다.

1. **Windows 키 + I** → 설정이 열립니다.
2. 왼쪽 또는 아래쪽의 **「Windows 업데이트」** 를 누릅니다. (Windows 10은 「업데이트 및 보안」 → 「Windows 업데이트」)
3. **「업데이트 확인」** 을 누릅니다.
4. 뭔가 나타나면 **「모두 다운로드 및 설치」** 또는 **「지금 설치」** 를 누릅니다.
5. **「지금 다시 시작」** 이 나오면 누릅니다. 컴퓨터가 **여러 번 다시 켜질 수 있습니다.** 전원을 끄지 말고 기다립니다.
6. 다시 켜진 뒤 **2번부터 반복**해서 **「최신 상태입니다」** 가 나올 때까지 합니다.

> **오래 안 했다면 1시간 넘게 걸립니다.** 밤에 자기 전에 걸어 두고 자도 됩니다. 전원 어댑터를 꽂았는지 꼭 확인하세요.

**끝까지 해서 「최신 상태입니다」** 가 나왔으면 2장으로 갑니다. 중간에 **오류 번호**(예: `0x80070...`)가 뜨면 화면을 캡처해 두고 **그냥 2장으로** 갑니다. 그 오류는 **5장**에서 Codex가 고쳐 줍니다.

# 4장. 보안 프로그램 정리 — Windows 보안(Defender) 하나만 남기기

## 왜 Windows 보안 하나만 쓰나요

- Windows에는 **Windows 보안(Windows Defender)** 이라는 **무료 백신**이 **처음부터 들어 있습니다.** 성능도 충분합니다.
- 컴퓨터 살 때 **체험판으로 깔려 온 백신**(맥아피·노턴·V3 등)은 **기간이 끝나면 보호도 못 하면서 컴퓨터만 느리게** 합니다. 그런데 **Windows 보안이 "다른 백신이 있네" 하며 자기를 꺼 두는 경우**가 있어서, **기간 끝난 백신이 있으면 오히려 컴퓨터가 무방비**일 수 있습니다.
- **백신이 둘 이상 켜져 있으면 서로 싸워서** 더 느려집니다.

> 그래서 **기간이 끝났거나 안 쓰는 백신은 지우고, Windows 보안을 켜 둡니다.** 지금 **돈 내고 잘 쓰고 있는 백신**이 있다면 **그건 지우지 마세요.** Codex가 기간을 확인해서 물어봅니다.

## 지울 때는 「그 회사의 공식 제거 도구」를 씁니다

백신은 「프로그램 추가/제거」로 지우면 **찌꺼기가 남아** 나중에 Windows 보안과 충돌하는 일이 많습니다. 그래서 **그 회사가 공식으로 제공하는 제거 도구**를 써야 합니다. Codex가 **회사 공식 사이트에서만** 찾아 받습니다. **아무 사이트에서나 받지 않습니다.**

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ③ — 보안 프로그램 점검과 정리**

```text
①에서 정한 안전 규칙을 계속 지켜 줘. 이번에는 보안 프로그램(백신)을 정리할 거야.

1. 01_점검결과.md를 바탕으로, 이 컴퓨터에 설치된 보안 프로그램을 전부 번호 목록으로 보여 줘. 각각에 대해 이름, 회사, 지금 켜져 있는지, 사용 기간이 끝났는지(만료·체험판·무료 기간 종료), 그리고 Windows 보안(Defender)과 동시에 돌고 있는지를 알려 줘.
2. "기간이 끝났거나 체험판이라 보호가 안 되는 것", "아직 유효한 것", "확실하지 않은 것"으로 나눠서 알려 줘. 확실하지 않은 것은 추측하지 말고 "확인 못 함"이라고 해 줘.
3. 지우기 전에 나에게 "이 중 ○번 ○번을 지울까요?"라고 물어보고, 내가 답하기 전에는 아무것도 지우지 마. 내가 돈 내고 쓰고 있다고 말한 것은 지우지 마.
4. 내가 고른 것을 지울 때는 「프로그램 추가/제거」로만 지우지 말고, 그 회사의 공식 사이트에서 공식 제거 도구(예: 맥아피는 McAfee Consumer Product Removal 도구, 노턴은 Norton Remove and Reinstall 도구)를 찾아서 써 줘. 공식 사이트 주소를 나에게 먼저 보여 주고 받아. 출처가 불분명한 사이트의 도구는 쓰지 마. 한국 백신(V3, 알약 등)은 공식 사이트의 제거 방법을 따라 줘.
5. 제거 후 컴퓨터를 다시 시작해야 하면 내가 저장할 시간을 주고 나서 알려 줘. 다시 시작한 뒤에 이어서 진행할 수 있게, 어디까지 했는지 03_보안정리_진행.md 에 적어 둬.
6. 마지막으로 Windows 보안(Defender)의 실시간 보호가 켜져 있는지, 바이러스 정의(검사용 최신 정보)가 최신인지 확인하고, 꺼져 있으면 켜는 방법을 알려 주거나 네가 켜 줘. 방화벽도 켜져 있는지 확인해 줘.
7. 마지막에 "지금 내 컴퓨터의 보호 상태"를 한 줄로 알려 줘.
```

**이렇게 답하세요**

Codex가 이런 식으로 물어보면:

```text
1. 맥아피 (2025-03 기간 만료)
2. Windows 보안 (켜짐)
3. 알약 (기간 없음, 켜짐)
어느 것을 지울까요?
```

입력창에 **번호만** 쓰면 됩니다. 예:

```text
1번 지워 줘. 3번은 그대로 둬.
```

**확인할 것:** 마지막에 **“Windows 보안 실시간 보호: 켜짐”** 이 나오면 성공입니다.

> **Windows 보안 화면을 직접 보고 싶다면**: Windows 키를 누르고 `Windows 보안` 이라고 친 뒤 Enter → **「바이러스 및 위협 방지」** 에 **초록색 체크**가 보이면 정상입니다. **빨간 X·노란 느낌표**가 있으면 Codex에게 그 화면을 캡처해서 붙여넣고 “**이 경고를 해결해 줘.**”라고 하세요.

# 5장. Windows 업데이트 마무리 (1-4에서 막혔던 것까지)

1-4에서 **오류가 났거나 업데이트가 안 끝났다면** 여기서 고칩니다. **이미 「최신 상태입니다」가 나왔다면** 이 장은 건너뛰고 6장으로 가세요.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ④ — 업데이트 문제 해결**

```text
①에서 정한 안전 규칙을 계속 지켜 줘. 이번에는 Windows 업데이트를 끝까지 맞출 거야.

1. 지금 밀려 있는 업데이트와 실패한 업데이트 기록(오류 번호 포함)을 확인해서 쉬운 말로 알려 줘.
2. C 드라이브 남은 용량이 업데이트에 충분한지(보통 20GB 이상 권장) 확인해 줘. 부족하면 알려 줘. 용량 확보는 6장에서 할 거야.
3. 업데이트가 계속 실패하면 Windows 공식 문제 해결 방법을 써 줘. 예: Windows 업데이트 문제 해결사 실행, Windows 업데이트 구성 요소 재설정, 시스템 파일 검사(sfc /scannow)와 이미지 복구(DISM). 강한 방법으로 가기 전에 이유를 설명하고 내 허락을 받아. 출처가 불분명한 "업데이트 수정 도구"는 쓰지 마.
4. 업데이트를 설치하거나 다시 시작해야 하면 내가 저장할 시간을 주고 알려 줘. 다시 켠 뒤에 이어서 할 수 있게 04_업데이트_진행.md 에 어디까지 했는지 적어 줘.
5. 끝나면 설정 > Windows 업데이트에서 "최신 상태"인지 확인하고 결과를 알려 줘. 안 된 것은 "확인 못 함"과 그 이유를 정직하게 알려 줘.
```

> **다시 시작한 뒤에는**: Codex 채팅이 그대로 남아 있습니다. ChatGPT 앱을 열고 **`pc-cleanup`** 의 같은 채팅을 누른 뒤, 입력창에 “**다시 켰어. 이어서 진행해 줘.**”라고 쓰고 Enter.

> **Windows 10을 쓰는 분**: Windows 10은 2025년 10월에 공식 지원이 끝났습니다. 그래서 「최신 상태」여도 **새 보안 업데이트가 더는 안 올 수 있습니다.** Codex가 내 컴퓨터가 Windows 11로 올릴 수 있는지 알려 줍니다. **올리는 것은 이 안내서에서 하지 않습니다.** 자료를 백업한 뒤 **따로, 천천히** 결정하세요.

# 6장. 불필요한 프로그램 정리

컴퓨터 살 때 같이 깔려 온 **제조사 프로그램(블로트웨어)**, 안 쓰는 프로그램, 이름 모를 **수상한 프로그램**(검색창을 바꾸는 툴바, 광고 프로그램 등)을 찾아서 지웁니다.

**지우는 것은 내가 번호로 고른 것만**입니다. Codex는 **분류해서 추천**만 합니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ⑤ — 프로그램 목록 만들기 (지우지 않음)**

```text
①에서 정한 안전 규칙을 계속 지켜 줘. 이번에는 설치된 프로그램을 정리할 거야. 이 단계에서는 목록만 만들고 아무것도 지우지 마.

1. 설치된 프로그램을 전부 조사해서 아래 네 가지로 나눠 번호 목록으로 보여 줘. 각 줄에는 이름, 회사, 설치 날짜, 크기, 그리고 "이게 뭔지·왜 그렇게 분류했는지" 한 줄 설명을 붙여 줘.
   A. 지워도 안전한 것: 컴퓨터 구입 때 깔려 온 체험판·광고성 프로그램, 오래 안 쓴 중복 프로그램, 툴바, 출처 불분명한 프로그램 (확실한 것만)
   B. 지워도 되지만 내가 쓰는지 알아야 하는 것: 제조사 지원 프로그램, 사진·동영상·문서 편집 프로그램, 게임 런처, 메신저, 클라우드 저장 프로그램 등
   C. 지우면 안 되는 것(필수): Windows 구성 요소, Microsoft Visual C++/.NET 같은 실행 환경, 그래픽·소리·와이파이·터치패드 드라이버, 은행·관공서 보안 프로그램(키보드 보안, 공동인증서, IPinside, nProtect, TouchEn, Veraport, AhnLab Safe Transaction 등), 한글·오피스 같은 업무 프로그램, 이번 작업에 쓰는 것(ChatGPT, Codex, Aside, Python, ffmpeg 등)
   D. 잘 모르겠는 것: 추측하지 말고 "확인 못 함"이라고 적어 줘. 이름으로 공식 자료를 검색해서 확인할 수 있으면 해 줘.
2. 이름이 수상하거나 출처를 알 수 없는 프로그램은 따로 "⚠ 수상한 프로그램" 목록으로 뽑아 줘. 회사 이름이 없거나, 검색창·홈페이지를 바꾸는 툴바이거나, 광고를 띄우는 것 등을 기준으로 해 줘.
3. 이 결과를 05_프로그램_목록.md 에 저장해 줘.
4. 채팅에는 A 목록 전체와 ⚠ 수상한 프로그램 목록만 보여 주고, "이 중 지울 번호를 알려 주세요"라고 물어봐 줘. B와 D는 "궁금한 번호가 있으면 물어보세요"라고만 해 줘.
```

### 목록을 보고 고르는 법

| 이렇게 생각하세요 | 결정 |
| --- | --- |
| 이름을 봐도 **뭔지 전혀 모르겠고**, 내가 깐 기억이 없다 | Codex에게 “**○번이 뭐야?**” 물어본 뒤 결정 |
| **체험판·광고**라고 써 있다 | 지워도 됩니다 |
| **안 쓰는 게임·메신저·예전 프로그램** | 지워도 됩니다 |
| **은행·공공기관·인증서·보안 프로그램**이라고 써 있다 | **지우지 마세요.** (인터넷뱅킹이 안 됩니다) |
| **한글·엑셀·포토샵 등 내가 쓰는 것** | **지우지 마세요** |
| 그래픽·소리·와이파이·터치패드 **드라이버** | **지우지 마세요** |

**모르면 지우지 않는 것이 안전합니다.** 나중에 언제든 지울 수 있습니다.

고르셨으면 같은 채팅에 **번호만** 쓰세요.

```text
A 목록 전부 지워 줘. 수상한 프로그램은 2번, 5번 지워 줘. 나머지는 그대로 둬.
```

또는

```text
A 목록에서 3번, 4번, 7번만 지워 줘. 나머지는 그대로 둬.
```

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ⑥ — 고른 프로그램 지우기**

(위에서 **번호를 답한 뒤에** 이 상자를 붙여넣습니다)

```text
①에서 정한 안전 규칙을 계속 지켜 줘. 방금 내가 고른 번호의 프로그램만 지워 줘.

1. 지우기 전에 내가 고른 번호와 프로그램 이름을 그대로 한 번 읽어서 확인해 줘. 내가 고르지 않은 것은 절대 지우지 마. 내가 고른 것 중에 C 목록(필수)에 해당하는 게 섞여 있으면 지우지 말고 알려 줘.
2. 공식 제거 방법(프로그램 추가/제거의 제거 프로그램)으로 하나씩 지우고, 각각 성공했는지 확인해 줘. 제거 창이 뜨면 "제거", "예", "다음"처럼 그 프로그램을 지우는 쪽 단추는 네가 눌러 줘. 다른 프로그램을 같이 깔자는 체크 표시는 전부 해제해 줘.
3. 지우다가 "삭제할 수 없다"고 나오는 것은 억지로 지우지 말고 이유를 알려 주고 그대로 둬.
4. 끝나면 지운 것, 못 지운 것, 그대로 둔 것을 06_지운_프로그램.md 에 정리하고 채팅에도 알려 줘. 컴퓨터를 다시 시작해야 하면 내가 저장할 시간을 주고 알려 줘.
```

**확인할 것:** Codex가 “지운 것 ○개, 못 지운 것 ○개”를 알려 주면 됩니다.

# 7장. 컴퓨터 켤 때 자동으로 켜지는 프로그램 줄이기

컴퓨터를 켜면 **사용자가 안 불렀는데도 저절로 켜지는 프로그램**이 있습니다. 이게 많으면 **켜는 데 오래 걸리고 계속 느립니다.** 이걸 줄이면 체감 효과가 **가장 큽니다.**

> 「끄는 것」은 **지우는 것이 아닙니다.** 프로그램은 그대로 있고 **자동으로 안 켜질 뿐**입니다. 필요하면 내가 직접 켜서 쓰면 됩니다. 언제든 되돌릴 수 있습니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ⑦ — 시작 프로그램 줄이기**

```text
①에서 정한 안전 규칙을 계속 지켜 줘. 이번에는 컴퓨터를 켤 때 자동으로 시작되는 프로그램을 줄일 거야.

1. 시작 프로그램과 예약된 작업 중에서, 켜는 속도와 메모리에 영향을 주는 것을 번호 목록으로 보여 줘. 각 줄에는 이름, 회사, 부팅 속도에 주는 영향(높음·보통·낮음), "이게 뭔지, 꺼도 되는지" 한 줄 설명을 붙여 줘.
2. 세 가지로 나눠 줘.
   A. 꺼도 되는 것: 자동 업데이트 확인, 광고·홍보 프로그램, 게임 런처, 메신저 자동 실행 등
   B. 꺼도 되지만 내가 쓰는지 알아야 하는 것
   C. 끄면 안 되는 것: 보안 프로그램(Windows 보안 포함), 소리·그래픽·터치패드 드라이버 관련, 은행·관공서 보안 프로그램, 클라우드 동기화(OneDrive 등 내가 쓰는 것)
3. 이 단계에서는 끄지 말고 목록만 보여 줘. 그리고 "끌 번호를 알려 주세요"라고 물어봐 줘.
4. 내가 번호를 답하면, 지우지 말고 "자동 시작만 끄기"로 처리해 줘(작업 관리자의 시작 앱 사용 안 함 방식). 끄기 전의 상태를 07_시작프로그램_전.md 에 저장해 두고, 다시 켜는 방법도 함께 적어 줘.
5. 끝나면 끈 것과 그대로 둔 것을 정리해 주고, 컴퓨터를 다시 시작해서 속도를 확인해 볼지 나에게 물어봐 줘.
```

**고르는 법:** 6장과 똑같이 **번호만** 답합니다. 예: `A 목록 전부 꺼 줘. B는 3번만 꺼 줘.`

> **쓰는 프로그램까지 끄고 싶지 않다면**: 「이건 매일 쓰는데」 싶은 것은 그냥 두세요. Codex에게 “**3번은 내가 매일 써. 그건 그대로 둬.**”라고 답하면 됩니다.

# 8장. 저장 공간 확보 — 임시 파일·휴지통 정리

컴퓨터에는 **써도 안 지워지는 임시 파일**(프로그램이 잠깐 만들고 버린 것, 업데이트 설치 찌꺼기 등)이 쌓입니다. **쌓이면 수십 GB**가 되기도 합니다. Windows가 **공식으로 제공하는 방법**으로만 치웁니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ⑧ — 안전한 정리 (Windows 공식 기능만)**

```text
①에서 정한 안전 규칙을 계속 지켜 줘. 이번에는 저장 공간을 확보할 거야. 제3자 프로그램은 쓰지 말고 Windows 자체 기능(디스크 정리, 저장 공간 센스, 임시 파일 삭제)과 안전한 임시 폴더 정리만 써 줘.

1. C 드라이브의 지금 여유 공간을 먼저 알려 줘.
2. 정리할 수 있는 항목을 용량과 함께 번호 목록으로 보여 줘. 다음 항목만 후보로 삼아 줘.
   - 임시 파일(사용자 임시 폴더, Windows 임시 폴더)
   - 휴지통(비우기 전에 안에 든 파일 이름 몇 개를 보여 주고 내가 확인하게 해 줘)
   - Windows 업데이트 정리 파일, 이전 Windows 설치 파일(Windows.old는 삭제하면 이전 버전으로 못 돌아가니 이유를 설명하고 따로 물어봐 줘)
   - 오류 보고·로그 파일, 축소판 그림 캐시, 배달 최적화 파일
   - 브라우저 캐시(쿠키와 저장된 비밀번호는 지우지 않게, 캐시만)
3. 다음은 절대 건드리지 마: 문서·사진·바탕화면·다운로드·음악·동영상 폴더, OneDrive 폴더, 다른 프로그램의 설정·데이터 폴더, 이 폴더(pc-cleanup), 내가 받아 둔 설치 파일.
   다운로드 폴더는 지우지 말고 "큰 파일 상위 10개의 이름·크기·날짜"만 알려 줘. 지울지는 내가 정할게.
4. 이 단계에서는 목록만 보여 주고 "정리할 번호를 알려 주세요"라고 물어봐 줘. 내가 답하면 그것만 정리해 줘.
5. 끝나면 정리 전후의 여유 공간을 비교해서 08_공간정리.md 에 저장하고 채팅에도 알려 줘.
6. 여유 공간이 전체의 15% 미만으로 계속 부족하면 그 사실과 앞으로의 선택지(안 쓰는 큰 프로그램 제거, 사진·동영상을 외장하드나 클라우드로 옮기기 등)를 쉬운 말로 알려 줘. 대신 옮기지는 마.
```

**고르는 법:** 이번에도 **번호만**. 예: `1, 2, 3, 4번 정리해 줘. 5번은 그대로 둬.`

**다운로드 폴더 큰 파일**은 **내가 이름을 보고 결정**합니다. “3번은 지워 줘”라고 답하면 Codex가 **다시 한 번 확인**한 뒤 지웁니다.

# 9장. 악성 프로그램(바이러스) 검사

**Windows 보안**으로 검사합니다. **Codex가 검사를 시작하고**, 끝나면 결과를 알려 줍니다.

> 검사 시간은 **30분~2시간**입니다. **검사 중에도 컴퓨터를 쓸 수 있지만 느려집니다.** 식사하러 가거나 쉬는 시간에 걸어 두세요.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ⑨ — 검사와 수상한 것 점검**

```text
①에서 정한 안전 규칙을 계속 지켜 줘. 이번에는 악성 프로그램과 수상한 설정을 검사할 거야. Windows 보안(Defender)만 써 줘. 다른 회사의 "무료 검사 프로그램"은 받지 마.

1. Windows 보안의 바이러스 정의를 최신으로 업데이트해 줘.
2. 전체 검사(Full scan)를 시작해 줘. 시간이 오래 걸리니 시작했다고 알려 주고, 끝났는지 주기적으로 확인하되 같은 말만 반복해서 보고하지 마. 끝나거나 위협이 발견됐을 때만 알려 줘.
3. 위협이 발견되면 이름·위치·위험도를 쉬운 말로 설명하고, 어떻게 처리할지(격리, 제거) 나에게 물어본 뒤에 처리해 줘. 자동으로 지우지 마. 내 개인 파일 안에서 발견된 것은 특히 더 조심해서 설명해 줘.
4. 검사가 끝나면 아래도 점검해 줘. 읽기만 하고 바꾸지는 마.
   - 크롬·엣지·웨일 같은 브라우저의 확장 프로그램 중 수상한 것(쓰지 않는 것, 출처 불분명한 것, 광고나 검색 바꿈 의심)
   - 브라우저의 시작 페이지·기본 검색엔진이 내가 모르는 사이트로 바뀌어 있는지
   - 원격 제어 프로그램(AnyDesk, TeamViewer, 그 밖의 원격 지원 프로그램 등)이 내가 모르게 설치돼 있거나 켜져 있는지
   - hosts 파일이나 프록시 설정이 이상하게 바뀌어 있는지
5. 수상한 것은 번호 목록으로 보여 주고 "어떻게 할까요?"라고 물어봐 줘. 내가 고른 것만 처리해 줘.
6. 결과를 09_검사결과.md 에 저장하고, 채팅에는 "위협 ○건 발견 / ○건 처리 / 수상한 설정 ○건"처럼 한 줄로 요약해 줘.
7. Windows 보안의 "Microsoft Defender 오프라인 검사"는 컴퓨터를 다시 시작해서 하는 더 깊은 검사야. 이걸 해 볼 만한 이유가 있는지 알려 주고, 할지 내게 물어봐 줘. 내가 "해 줘"라고 할 때만 해 줘.
```

**확인할 것:** “위협 0건” 또는 “위협 ○건 발견, ○건 처리”가 나오면 됩니다.

> **위협이 발견됐다면** 놀라지 마세요. Codex가 **설명하고 물어봅니다.** 잘 모르겠으면 Codex에게 “**이게 얼마나 위험해? 내 컴퓨터에서 무슨 일을 하는 거야?**”라고 물어보세요.
>
> **그리고 이 컴퓨터로 은행·쇼핑몰에 로그인한 적이 있다면**, 위협이 발견된 경우에는 **다른 기기(휴대폰)에서 중요한 사이트의 비밀번호를 바꾸는 것**이 안전합니다.

# 10장. 마무리 — 전·후 비교 보고서 받기

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ⑩ — 최종 점검과 보고서**


# 12장. 자주 묻는 질문

**Q. Windows 보안(Defender)만 써도 안전한가요?**
A. 일반 사용에는 충분합니다. 수상한 사이트·파일을 열지 않는 습관이 더 중요합니다. **Windows 보안이 켜져 있고 업데이트되어 있으면** 기간 끝난 유료 백신보다 훨씬 안전합니다.

**Q. 돈 내고 쓰는 백신이 있는데 지워야 하나요?**
A. **아니요.** 기간이 남아 있고 잘 쓰고 있다면 그대로 두세요. 다만 **백신은 하나만** 켜 두는 것이 원칙입니다. Codex가 기간을 확인해서 알려 줍니다.

**Q. Codex가 제 개인 파일을 지울까 봐 걱정돼요.**
A. 안전 규칙으로 **개인 폴더는 건드리지 않도록** 시켰습니다. 그리고 **지우기 전에 목록을 보여 주고 내가 고른 것만** 지웁니다. 그래도 불안하면 **미리 백업**하고 시작하세요. 이 안내서의 시작 부분에도 적어 두었습니다.

**Q. 얼마나 자주 해야 하나요?**
A. **한 번 제대로 하고**, 이후에는 10장의 체크리스트대로 **한 달에 한 번 업데이트 확인, 석 달에 한 번 정리**하면 충분합니다.

**Q. 이걸 하면 컴퓨터가 새것처럼 빨라지나요?**
A. **눈에 띄게 빨라지는 경우가 많지만 새것 같지는 않습니다.** 컴퓨터가 **아주 오래됐거나**(5~7년 이상) **저장장치가 옛날 방식(HDD)** 이면 한계가 있습니다. 이때는 SSD로 바꾸거나 새 컴퓨터를 고려하는 것이 효과가 큽니다. Codex가 2장에서 저장장치 종류를 알려 줍니다.

**Q. 맥(Mac)에서도 되나요?**
A. 이 안내서는 **Windows PC 전용**입니다. 맥은 방식이 다릅니다.

**Q. 이 안내서 때문에 오히려 문제가 생기면요?**
A. 3장에서 만든 **복원 지점**으로 돌아갈 수 있습니다. 방법은 02_되돌리는_방법.md 에 있습니다. 그래도 안 되면 위의 「그래도 안 되면」으로 오세요.

# 13장. 용어 사전

| 용어 | 쉬운 설명 |
| --- | --- |
| **Windows 보안 (Windows Defender)** | Windows에 처음부터 들어 있는 **무료 백신**. 별도 설치 없이 기본으로 켜져 있음 |
| **실시간 보호** | 파일을 열거나 받을 때마다 **자동으로 검사**해 주는 기능. 켜져 있어야 함 |
| **복원 지점** | 컴퓨터의 **특정 시점 상태를 저장**해 둔 것. 게임의 세이브처럼 나중에 돌아갈 수 있음 |
| **블로트웨어** | 컴퓨터 살 때 **미리 깔려 온 불필요한 프로그램**. 제조사 홍보·체험판이 대부분 |
| **시작 프로그램** | 컴퓨터를 켤 때 **저절로 같이 켜지는** 프로그램. 많을수록 부팅이 느림 |
| **임시 파일** | 프로그램이 **잠깐 쓰고 안 지운 파일**. 지워도 문제없음 |
| **드라이버** | 소리·화면·와이파이 같은 **장치를 작동시키는 프로그램**. 지우면 안 됨 |
| **관리자 권한** | 컴퓨터 설정을 **바꿀 수 있는 권한**. 이게 필요할 때 Windows가 변경 허용 창을 띄움 |
| **SSD / HDD** | 저장장치 종류. **SSD는 빠르고 HDD는 느림**. 오래된 컴퓨터에 HDD가 많음 |
| **레지스트리** | Windows 설정 정보가 들어 있는 **아주 민감한 곳**. **"레지스트리 청소" 프로그램은 쓰지 마세요.** 잘못 건드리면 컴퓨터가 안 켜질 수 있음 |
| **공식 제거 도구** | 백신 같은 프로그램을 **그 회사가 만든 전용 도구**로 완전히 지우는 것. 찌꺼기가 남지 않음 |
