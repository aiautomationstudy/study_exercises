# 3기 심화실습 #3 — AI 비서가 말하게 하기

녹음 파일이 들어오면 “새 녹음 파일이 접수됐습니다”, 정리가 끝나면 “녹음 처리가 완료됐습니다”라고 말하고, 녹음 내용을 짧게 음성으로 요약하는 비서를 만듭니다.

> **시작 조건:** [심화실습 #2 — 녹음하면 알아서 정리하는 내 비서](3기_심화실습_2_녹음하면_알아서_정리하는_내_비서_만들기.md)의 **Part 5. 브라우저 관제판 만들기**까지 끝냈다면 시작할 수 있습니다. Part 6~8은 하지 않았어도 됩니다.

이 안내서는 **Windows PC** 기준입니다. 휴대전화만으로는 진행할 수 없습니다. 지난 실습의 **녹음자동처리** 폴더, ChatGPT 앱(Codex), 스피커나 이어폰이 필요합니다. Mac이라면 각 상자를 붙여넣을 때 맨 앞에 “나는 macOS를 사용해. Windows 부분을 내 컴퓨터에 맞게 바꿔 줘.”를 붙이세요.

**원칙: AI가 할 수 있는 일은 AI에게 맡깁니다.** 사람이 직접 하는 일은 Aside 설치와 본인 계정 로그인, 회색 상자를 복사해 붙여넣는 것, 소리를 듣고 마음에 드는지 판단하는 것뿐입니다. 설치 확인, 웹사이트 조작, 파일 만들기, 코드 수정, 오류 해결, 시험은 Codex가 합니다. 궁금한 점은 매 단계가 끝날 때 Codex에게 물어보면 됩니다.

| 순서 | 결과 | 사람이 할 일 |
| --- | --- | --- |
| 1 | Aside를 Codex의 웹 작업 도구로 연결 | Aside 설치·계정 연결, 상자 ① 붙여넣기 |
| 2 | Google 음성 서비스용 개인 열쇠 | 상자 ② 붙여넣기, 필요할 때 Google 로그인 |
| 3 | 한국어 음성 파일 하나 | 상자 ③ 붙여넣기, 소리 들어 보기 |
| 4 | 녹음 접수·완료 알림과 음성 요약 | 상자 ④ 붙여넣기, 원하는 목소리인지 판단 |
| 5 | 실제 녹음으로 끝까지 확인 | 상자 ⑤ 붙여넣기, 결과 듣기 |

> **새 용어:** **TTS**는 글자를 소리로 읽어 주는 기능입니다. **API 키**는 Google 음성 서비스를 쓰는 컴퓨터의 비밀번호 같은 열쇠입니다. 키는 채팅, 화면 캡처, GitHub에 올리지 않습니다.

## 먼저 읽으세요 — 회색 상자 ①~⑤는 전부 「여기」에 붙여넣습니다

이 실습에는 회색 상자가 다섯 개(①~⑤) 나옵니다. **다섯 개 모두 붙여넣는 곳이 같습니다.**

**컴퓨터에 설치한 ChatGPT 앱 → Codex → 「녹음자동처리」 채팅의 맨 아래 글 쓰는 칸(입력창)** 입니다. 심화실습 #2에서 상자를 붙여넣던 바로 그곳입니다.

| ⭕ 여기에 붙여넣습니다 | ❌ 여기가 아닙니다 |
| --- | --- |
| **ChatGPT 앱**의 **Codex** 화면, 「녹음자동처리」 채팅의 **맨 아래 입력창** | **Aside** 창 (1단계에서 새로 설치하는 브라우저) |
| | **Google AI Studio** 화면의 글 쓰는 칸 |
| | 크롬·엣지로 연 **chatgpt.com** |
| | 검은 창(PowerShell), 메모장, 관제판 화면 |

> 이 실습에서는 Aside와 Google AI Studio 창이 함께 떠 있게 됩니다. 두 곳 모두 글 쓰는 칸이 있어서 헷갈리기 쉽습니다. **상자는 늘 ChatGPT 앱으로 돌아와서 붙여넣습니다.** Aside와 Google 화면은 Codex가 알아서 다룹니다.

### ChatGPT 앱에서 「녹음자동처리」 여는 법 (이 실습을 처음 시작할 때)

1. 키보드의 **Windows 키**(창문 모양)를 누르고 `ChatGPT` 라고 친 뒤 **Enter** — ChatGPT 앱이 열립니다.
2. 왼쪽 메뉴에서 **Codex**를 누릅니다. (심화실습 #2 때 누르던 그곳입니다.)
3. 왼쪽 목록에서 **「녹음자동처리」** 를 찾아 누릅니다.
4. **「새 채팅」** 을 누릅니다. 이 실습용 채팅이 새로 열립니다. **새 채팅은 처음 시작할 때 한 번만 엽니다.**
5. 화면에 **「녹음자동처리」** 라는 이름이 보이고, 맨 아래에 글 쓰는 칸이 있으면 준비 끝입니다.

**왼쪽 목록에 「녹음자동처리」가 없으면:** **「새 프로젝트 추가」 → 「기존 폴더 사용」** → 폴더 고르는 창에서 **문서 → 녹음자동처리** 를 한 번 눌러 고르고 **「폴더 선택」**. “이 폴더를 신뢰할까요?”라고 물으면 **「폴더 신뢰」** 를 누릅니다.

### 상자를 복사해서 붙여넣는 법 (매번 똑같습니다)

1. 회색 상자 **오른쪽 위 구석**에 마우스를 올리면 **네모 두 개가 겹친 모양의 복사 단추**가 나타납니다. 한 번 누릅니다. 상자 안의 글이 전부 복사됩니다.
2. **ChatGPT 앱** 창을 누르고, 맨 아래 **입력창을 한 번 클릭**합니다.
3. **Ctrl + V** 를 누릅니다. 상자의 글이 통째로 들어옵니다. **고치지 않습니다.**
4. **Enter** 를 누릅니다. Codex가 일을 시작합니다.

직접 타이핑하지 않습니다. 상자를 나눠서 붙여넣지도 않습니다. **한 상자 = 한 번에 통째로** 입니다.

### 다섯 상자는 「같은 채팅」에 이어서 붙여넣습니다

①을 붙여넣은 채팅에 ②, ③, ④, ⑤를 **차례로 이어서** 붙여넣습니다. 새 채팅을 만들지 않습니다. 같은 채팅이어야 Codex가 앞 단계에서 한 일(열쇠를 어디에 저장했는지 등)을 기억합니다.

**한 상자를 붙여넣은 뒤에는 Codex가 일을 마치고 결과를 알려 줄 때까지 기다렸다가** 다음 상자로 갑니다.

### Codex가 “해도 될까요?”라고 물으면

Codex는 프로그램을 설치하거나 파일을 고치기 전에 허락을 구하는 창을 띄웁니다. 이 실습에서는 여러 번 뜹니다. 정상입니다.

- **「한 번만 허용」** 이나 **「이 대화 허용」** 을 누릅니다.
- **“파일을 삭제”** 하겠다는 내용이면 누르지 말고 입력창에 “왜 지워야 해? 지우지 않는 방법으로 해 줘.”라고 쓰고 Enter.

## 1단계. Aside 설치와 ChatGPT 계정 연결

Aside는 Codex가 **내가 로그인한 웹사이트를 브라우저에서 다룰 수 있게 하는 별도 브라우저**입니다. Aside의 ChatGPT 계정 연결과 Google 사이트 로그인은 서로 다른 일입니다.

**직접 할 일**

1. Windows에서 [Aside 공식 다운로드](https://aside.com/download)를 열어 Windows 설치 파일을 받아 실행합니다.
2. Aside를 열고 본인 Aside 계정으로 로그인합니다.
3. **설정 → 모델(Models) → Providers → Connect → Subscription → ChatGPT Subscription**을 열어 본인이 사용하는 ChatGPT 계정을 연결합니다. 로그인 창이 뜨면 완료합니다.
4. Aside에서 [Google AI Studio](https://aistudio.google.com/)를 열고 **사용할 Google 계정**으로 로그인합니다. 비밀번호·2단계 인증·약관 동의가 뜨면 이때만 직접 처리합니다. 이미 로그인돼 있다면 다시 하지 않습니다.

여기까지 했으면 Aside 창은 **그대로 두고**, **ChatGPT 앱**으로 갑니다. 위 「ChatGPT 앱에서 「녹음자동처리」 여는 법」대로 「녹음자동처리」의 **새 채팅**을 열고, 아래 상자 ①을 붙여넣습니다.

**AI가 웹사이트에서 일하는 동안 다른 일을 해도 됩니다.** 아래 상자 ①에는 마우스를 멋대로 움직이거나, 보고 있던 창·탭·데스크톱을 바꾸지 않도록 하는 설정이 들어 있습니다. Aside 설정 화면에서 별도 단추를 찾을 필요는 없습니다. **이전에 1단계를 끝냈다면**, 같은 채팅에 “설치는 다시 하지 말고 아래 상자 ①의 다른 작업을 방해하지 않는 규칙만 추가해 줘.”라고 쓴 뒤 상자 ①을 붙여넣으세요.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ① — Aside를 앞으로의 웹 작업 도구로 설정**

```text
나는 Windows PC에서 심화실습 #2 Part 5까지 만든 녹음자동처리 프로젝트를 열었다. 나는 컴퓨터 초보자다. Aside 브라우저를 설치하고, 설정 > 모델에서 내 ChatGPT Subscription을 연결했으며, Aside 안의 Google AI Studio에 내 Google 계정으로 로그인했다.

이 컴퓨터에서 네가 직접 다음을 해 줘.
1. Aside 공식 문서 https://docs.aside.com/help/developers 와 설치된 Aside의 개발자 설정을 확인해 Aside CLI를 설치해 줘. Windows에서는 공식 서명된 설치 경로를 사용하고, 이미 설치됐으면 재설치하지 마.
2. aside --update, aside guide, aside account list로 CLI가 실행되고 Aside 계정이 로그인됐는지 확인해 줘. Google AI Studio 로그인도 Aside의 실제 화면에서 확인해 줘.
3. Codex의 전역 skills 폴더에 aside-browser 스킬을 설치하거나, 공식 aside guide를 읽도록 하는 작은 로컬 스킬을 만들어 줘. 출처가 불분명한 제3자 설치 스크립트는 쓰지 마. 실제로 로드될 수 있는지 확인해 줘.
4. Codex가 실제 사용하는 전역 지침 파일을 찾아 기존 내용을 보존한 채 다음 규칙을 추가해 줘: “로그인한 웹사이트의 탐색·입력·결과 확인은 기본적으로 Aside CLI와 aside-browser 스킬을 사용한다. 사용 전에 aside --update와 aside guide를 읽는다. 웹 자동 회귀 시험은 별도 테스트 도구를 쓸 수 있다.” 이 프로젝트에만 적용되는 파일에 적고 끝내지 마.
   “Aside의 탭·DOM 조작으로 백그라운드에서 처리한다. 실제 마우스 이동·클릭이나 전역 키보드 입력을 하지 않고, 창을 앞으로 가져오거나 내가 보고 있는 탭·데스크톱을 바꾸지 않는다. 작업 대상 탭만 다루고 내가 다른 일을 하는 탭은 건드리지 않는다. aside exec에 맡길 때도 이 조건을 전달한다. 백그라운드로 안 되는 단계는 다른 방법을 먼저 찾고, 화면 조작이 꼭 필요하면 필요한 조작과 영향을 설명한 뒤 내 허락을 받는다.”도 추가해 줘.
   이 컴퓨터에서 Claude도 사용 중이면 Claude의 전역 지침에도 같은 규칙을 추가하고, 없으면 설치하지 마. 지침 파일이 자동 생성되는 파일이면 정본을 수정하고 적용해 줘.
5. 기존 프로젝트와 다른 전역 규칙을 덮어쓰지 말고, 변경한 파일 위치와 실제 확인 결과를 쉬운 한국어로 알려 줘. 사람의 로그인이나 Windows 권한 창이 꼭 필요할 때만 그 한 단계를 나에게 요청해 줘.

이후 웹 관련 작업은 새 규칙에 따라 진행해 줘.
```

**확인할 것:** Codex가 “Aside CLI 실행”, “Google AI Studio 로그인”, “다른 작업을 방해하지 않는 전역 지침의 저장 위치”를 알려 주면 다음으로 갑니다. 확인하는 동안 **내 마우스와 보고 있는 창·탭·데스크톱이 그대로인지**도 봅니다. **같은 채팅에 그대로** ②를 붙여넣습니다. Codex가 “새 채팅을 열어야 새 규칙이 적용된다”고 **분명히 말한 경우에만** 「녹음자동처리」에서 「새 채팅」을 열고 거기에 ②부터 이어 갑니다.

궁금하면 “CLI가 뭐야? 전역 지침은 이번 프로젝트 설정과 뭐가 달라? 내 컴퓨터의 예로 설명해 줘.”라고 물어보세요.

## 2단계. Google 음성 서비스의 개인 열쇠 준비

[Google AI Studio API Keys](https://aistudio.google.com/api-keys) 화면을 **Codex가 Aside로 직접** 다룹니다. 여러분이 그 화면에서 할 일은 없습니다. 키를 복사해 채팅에 붙여넣지 마세요.

**붙여넣는 곳:** ①을 붙여넣었던 **ChatGPT 앱(Codex)의 같은 채팅**입니다. Google AI Studio 화면이 아닙니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ② — 키 발급과 안전한 보관**

```text
Aside를 통해 Google AI Studio API Keys 화면을 열고 이번 녹음 비서의 Gemini TTS용 API 키를 준비해 줘.

1. 현재 로그인된 Google 계정과 선택한 프로젝트의 Billing Tier를 확인해 줘. 무료 티어 프로젝트를 사용하고 “Set up billing”이나 결제·유료 전환은 누르지 마. 이미 이 실습용으로 쓸 수 있는 키가 있으면 재사용해 중복 발급하지 않아도 돼. 없으면 “녹음 비서 TTS”처럼 알아볼 수 있는 이름으로 새 키를 만들어 줘.
2. 키 문자열은 채팅 답변, 터미널 출력, 로그, 프로젝트 코드, Git 기록에 남기지 마. Aside 화면의 복사 기능과 임시 클립보드 등을 이용해 내 Windows 사용자만 읽는 프로젝트 바깥 보안 파일에 저장해 줘. 저장 직후 클립보드도 비워 줘. 프로그램은 그 파일을 읽게 하고 파일 경로만 알려 줘.
3. Gemini 공식 문서에서 실제 음성 모델 이름, 무료 티어, 내 계정의 Rate Limit을 확인해 줘. gemini-3.8-flash-lite-tts를 우선 사용하고 일반 텍스트 모델을 음성 모델로 착각하지 마.
4. 키 발급 또는 재사용 성공 여부, 무료/유료 상태, 키 파일 권한을 확인해 줘. 키 값은 한 글자도 보여 주지 마. Google 로그인·2단계 인증·필수 약관 동의가 뜨면 그 화면에서만 나를 불러 줘. 결제가 필요하다고 나오면 결제하지 말고 무료 경로가 있는지 찾아 줘.
5. 키 파일이 있는 위치(경로)만 녹음자동처리 폴더의 config\tts_key_location.txt 에 한 줄로 적어 둬. 나중에 새 채팅에서도 네가 키 파일을 찾기 위한 메모다. 이 메모에 키 값은 절대 적지 마.
```

**확인할 것:** “키 파일 저장”과 “무료/유료 티어”가 보이면 됩니다. **키 글자 자체는 안 보이는 것이 정상**입니다.

## 3단계. “안녕하세요” 한마디 들어 보기

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장 ⑤ — 검증과 쉬운 최종 보고**

```text
이제 만든 기능을 내 실제 녹음 자동 처리 흐름에서 끝까지 시험해 줘. 내가 새 명령을 실행하게 하지 말고 네가 진행해 줘.

1. 새 시험 녹음 하나를 넣거나 기존 시험 녹음을 안전하게 재처리해 접수 음성 → 전사·정리 문서 → 완료 음성 → 짧은 음성 요약 순서를 확인해 줘. 관제판의 “요약 듣기” 버튼도 직접 눌러 확인해 줘.
2. 같은 파일을 한 번 더 처리 주기에 걸리게 해 봐. 접수·완료 음성이 중복되지 않아야 한다. TTS가 실패해도 문서 처리와 텔레그램이 멈추지 않는지 확인해 줘.
3. 요약과 원문을 대조해 없던 사람·장소·결정이 생기지 않았는지 확인해 줘. API 키가 화면·코드·Git 기록에 없는지도 확인해 줘. 무료/유료 상태와 실제 호출 수도 확인할 수 있으면 알려 줘.
4. 안 된 것은 “확인 못 함”이라고 정확히 적고, 스스로 고칠 수 있는 것은 끝까지 고쳐 줘.
5. 마지막 답변은 컴퓨터를 잘 모르는 사람도 이해하게 친절하게 써 줘. “무엇을 만들었는지 → 내 컴퓨터에서 실제로 어떻게 흘러가는지 → 직접 확인된 결과 → 남은 일과 내가 할 일” 순서로, 코드 이름만 던지지 말고 쉬운 말로 설명해 줘. 긴 명령 목록 대신 중요한 결과를 알려 줘.
```

**완료 기준:** 처음 넣은 녹음을 한 번만 알리고, 성공 뒤 완료와 **그 녹음의 실제 요약**을 들려주며, 관제판 버튼으로 다시 들을 수 있으면 됩니다. Codex가 “코드를 만들었다”고만 답하면 **실제 재생 결과**를 더 물어보세요.

## 무료 사용과 개인정보

2026년 9월 30일 기준, Google의 [Gemini 3.8 Flash-Lite TTS 가격표](https://ai.google.dev/gemini-api/docs/pricing)는 **무료 티어를 제공**합니다. 무료 요청 횟수는 계정·프로젝트의 현재 한도에 따라 달라집니다. **모든 사람이 하루 1,500회 무료라고 단정할 수 없습니다.** Codex가 여러분의 AI Studio **Billing Tier, Rate Limit, Usage** 화면을 확인하도록 한 이유입니다. [공식 키 발급 설명](https://ai.google.dev/gemini-api/docs/api-key)에도 키 생성과 권한 조건이 나옵니다. 카드 등록이나 유료 전환은 이 실습에 포함되지 않습니다.

읽어 달라고 한 문장은 Google 음성 서비스로 전송됩니다. 실제 고객 이름·전화번호·민감한 회의 내용이 들어 있는 요약은 시험에 쓰지 마세요. **API 키와 녹음 원본은 스터디 게시판에 올리지 않습니다.**
