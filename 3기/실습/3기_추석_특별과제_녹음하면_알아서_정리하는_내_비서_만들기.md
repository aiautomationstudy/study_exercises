## 녹음하면 알아서 글로 옮기고, 정리하고, 휴대폰으로 알려 주는 「내 비서」 만들기

> **이번 연휴에 만드는 것**
> 
> 휴대폰으로 녹음한 파일을 컴퓨터의 **한 폴더에 넣기만 하면**,
> ① 글로 옮기고(전사) → ② 읽기 좋게 정리하고 → ③ 요약하고 → ④ **휴대폰 텔레그램으로 "정리 끝났어요" 알림**을 보내고 → ⑤ **브라우저 화면(관제판)** 에서 지금까지 정리한 것을 한눈에 보는

> 
> 한 번 만들어 두면 그다음부터 할 일은 **녹음 버튼을 누르는 것**뿐입니다.

## 「ChatGPT 앱(Codex)」이 뭔가요

컴퓨터에 설치한 ChatGPT 앱 안에 **Codex**라는 것이 들어 있습니다. 브라우저의 ChatGPT는 대화만 하지만, **Codex는 내 컴퓨터의 폴더를 열고, 파일을 만들고, 프로그램을 설치하는 일을 직접 합니다.** 이 과제에서 "붙여넣으세요"라고 하는 상자는 전부 이 Codex에게 시키는 말입니다.

ChatGPT 앱을 열고 **Codex** 탭(또는 메뉴)을 누르면 됩니다. 처음 열면 "어느 폴더에서 일할까요?"라고 묻는데, 2장에서 만들 `녹음자동처리` 폴더를 고르면 됩니다.

**오류는 정상입니다.** 사람마다 컴퓨터가 다르기 때문입니다. 막히면:

1. 화면에 뜬 **빨간 글씨(오류 메시지)를 그대로 복사**합니다.
2. Codex에게 붙여넣고 **"이 오류 해결해 줘. 컴퓨터 초보자니까 한 단계씩 설명해 줘."** 라고 합니다.

# Part 1. 준비 (약 40분)

# 1장. ChatGPT 앱과 Codex CLI 확인

이 과제에는 Codex가 **두 가지 모습**으로 쓰입니다.

|                      | 역할                       | 누가 쓰나      |
| -------------------- | ------------------------ | ---------- |
| **ChatGPT 앱의 Codex** | 내가 말을 붙여넣으면 일해 주는 화면     | 사람(나)      |
| **Codex CLI**        | 화면 없이 뒤에서 조용히 돌아가는 Codex | 자동 처리 프로그램 |

둘은 같은 Codex인데 실행되는 방식이 다릅니다. 밤에 자동으로 정리가 되려면 화면 없는 쪽(CLI)도 있어야 합니다.

## 1-1. ChatGPT 앱의 Codex 열어 보기

ChatGPT 앱을 열고 Codex에 아래를 붙여넣습니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
안녕. 지금부터 "녹음 자동 정리" 과제를 시작할 거야.
나는 컴퓨터 초보자야. 앞으로 내가 붙여넣는 요청을 한 단계씩 쉽게 설명하면서 진행해 줘.
그리고 매번 마지막에 "실제로 확인한 것"과 "확인하지 못한 것"을 구분해서 알려 줘.
```

답이 오면 됩니다.

## 1-2. Codex CLI 확인·설치

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
이 컴퓨터에 Codex CLI가 준비되어 있는지 확인해 줘.

확인할 것:
1. PowerShell에서 codex --version 이 실행되는지
2. codex login 이 되어 있는지
3. 현재 터미널에서 codex 명령이 실행되는지

모두 정상이면 "Codex CLI 준비 완료"라고 알려 줘.

없으면 설치해 줘:
1. PowerShell에서 공식 설치 명령을 실행: powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
2. 설치 후 codex --version 으로 확인
3. codex 명령을 못 찾으면 PATH 문제인지 확인하고, 새 PowerShell 창을 열어야 반영된다는 점도 알려 줘
4. 공식 설치가 실패하면 node -v, npm -v 확인 후 npm install -g @openai/codex 방식으로 안내해 줘
5. codex login 을 실행해서 로그인 절차를 진행해 줘. 브라우저가 열리면 내가 ChatGPT 계정으로 직접 로그인해야 한다고 알려 줘
6. 로그인 후 codex 명령이 정상 실행되는지 확인해 줘

각 단계를 한국어로 쉽게 설명해 줘.
```

> **ℹ CLI가 끝내 안 되면**
> 
> 그래도 과제는 계속할 수 있습니다. 전사(글로 옮기기)까지는 되고, 정리·요약만 자동이 안 됩니다. 그 경우 23장 끝의 「수동 대체 문장」으로 손으로 만들면 됩니다. 일단 넘어가세요.

# 2장. 작업 폴더 만들기

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
Windows의 내 문서(Documents) 폴더 아래에 "녹음자동처리" 폴더를 만들고,
그 안에 inbox, notes, tools, models, logs 하위 폴더를 만들어 줘.
완료 후 전체 폴더 구조를 보여 주고, 탐색기에서 이 폴더를 열어 줘.
```

만들어진 구조는 이렇습니다. 외울 필요 없습니다. **inbox 하나만 기억**하세요.

```text
문서\녹음자동처리
  ├─ inbox    ← ★ 녹음 파일을 여기에 넣으면 자동 처리 시작
  ├─ notes    ← 정리된 문서가 여기에 생김
  ├─ tools    ← 프로그램 (Codex가 알아서 넣음)
  ├─ models   ← 전사 모델 (Codex가 알아서 넣음)
  └─ logs     ← 실행 기록 (오류 확인용)
```

> **ℹ 「문서」 폴더가 어디인가요**
> 
> 탐색기(Windows 키 + E) 왼쪽에 보이는 **문서**(영문 윈도우는 Documents) 폴더입니다. 실제 위치는 보통 `C:\Users\내이름\Documents` 입니다.
> 
> **최근 윈도우는 「문서」가 OneDrive 안에 있기도 합니다** (`C:\Users\내이름\OneDrive\Documents`). 이러면 나중에 폴더 경로를 적을 때 헷갈립니다. Codex가 알려 준 **실제 경로를 메모장에 복사**해 두세요. 탐색기에서 `녹음자동처리` 폴더를 열고 **주소창을 클릭**해도 전체 경로가 보입니다.

Codex가 폴더를 만들면, **ChatGPT 앱의 Codex 작업 폴더를 이 `녹음자동처리` 폴더로 지정**하세요. (Codex 화면 위쪽의 폴더 이름을 눌러 바꿀 수 있습니다.) 앞으로 모든 작업이 이 안에서 이루어집니다.

# 3장. 음성을 글로 바꾸는 프로그램 준비 (whisper.cpp + ffmpeg)

**whisper.cpp**는 음성을 글자로 바꿔 주는 무료 프로그램입니다. 녹음이 인터넷으로 나가지 않고 **내 컴퓨터 안에서만** 처리됩니다.

> **⚠ 2기에서 가장 많이 막힌 곳입니다**
> 
> whisper.cpp는 휴대폰 녹음 파일(.m4a)을 바로 못 읽습니다. 중간에 **ffmpeg**라는 변환 도구가 하나 더 필요합니다. 아래 문장에 둘 다 들어 있으니 그대로 붙여넣으면 됩니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
Documents\녹음자동처리\tools 폴더 아래에 whisper.cpp와 ffmpeg를 준비해 줘.

1) whisper.cpp
- tools 폴더 아래에 whisper-cli.exe, main.exe, whisper.exe 중 실행 가능한 파일이 있는지 확인해 줘.
- 있으면 --help 로 정상 실행되는지 확인해 줘.
- 없으면 최신 Windows x64용 whisper.cpp 실행 파일을 받아서 tools\whispercpp 폴더에 정리해 줘.
- 참고: 최신 버전은 main.exe 대신 whisper-cli.exe 라는 이름을 쓴다.

2) ffmpeg
- 이 PC에서 ffmpeg 명령이 실행되는지 확인해 줘.
- 없으면 Windows용 ffmpeg를 받아서 tools\ffmpeg 폴더에 정리하고, 스크립트에서 전체 경로로 부를 수 있게 위치를 알려 줘.
- ffmpeg -version 으로 정상 동작을 확인해 줘.

3) 마지막에 두 프로그램의 실제 실행 파일 전체 경로를 알려 줘.
각 단계를 컴퓨터 초보자가 이해할 수 있게 한국어로 설명해 줘.
```

# 4장. 전사 모델 받기

whisper.cpp는 **모델 파일**이 있어야 동작합니다. 모델은 "귀와 뇌" 역할을 하는 파일이라고 생각하면 됩니다. 클수록 잘 알아듣지만 느립니다.

**이번 과제는 `base-ko`로 시작하세요.** 작고(150MB) 빨라서 **흐름을 끝까지 만드는 데 가장 좋습니다.** 정확도가 아쉬우면 나중에 한 줄만 바꿔 `small`로 올리면 됩니다(10장).

| 모델                     | 크기    | 언제                         |
| ---------------------- | ----- | -------------------------- |
| **base-ko** (이번 과제 기본) | 150MB | 빠르게 완주하고 싶을 때. 오래된 노트북도 됨  |
| small                  | 500MB | 완주한 뒤 정확도를 올리고 싶을 때        |
| medium-korean          | 1.5GB | 메모리 16GB 이상, 회의록 품질이 중요할 때 |

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
whisper.cpp용 한국어 전사 모델을 받아 줘.

내가 쓸 모델: base-ko
저장 위치: Documents\녹음자동처리\models\

1. base-ko 인 경우:
   https://huggingface.co/wabisabisocial/whisper-base-korean-ggml/resolve/main/ggml-base-ko.bin
   에서 받아 ggml-base-ko.bin 으로 저장해 줘.
2. small 인 경우:
   https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin 을 받아 줘.
   이 모델은 다국어 모델이라 전사할 때 반드시 -l ko 옵션으로 한국어를 지정한다.

공통 확인:
3. 다운로드가 끝나면 파일이 실제로 있는지, 크기가 0바이트가 아니고 예상 크기와 비슷한지 확인해 줘.
   (오류 페이지가 .bin 이름으로 저장되는 경우가 있어서 크기 확인이 중요해.)
4. 주소가 죽어 있으면 whisper.cpp 공식 모델(ggml-base.bin / ggml-small.bin) 중 비슷한 크기로 대체하고, 파일명이 달라졌다고 알려 줘.
5. 최종 저장된 모델 파일의 전체 경로와 파일명을 알려 줘. 이 값을 자동 처리 스크립트에서 쓸 거야.
```

> **⚠ 마지막에 알려 준 파일 이름을 적어 두세요**

> 7장에서 이 이름을 그대로 써야 합니다. `ggml-base-ko.bin`인지 다른 이름인지 메모장에 적어 두세요.

# 5장. 테스트 녹음 2개 만들기

**처음부터 긴 회의 녹음으로 시작하지 마세요.** 짧은 녹음 두 개로 먼저 합니다. 이 두 개는 나중에 **"AI가 없는 말을 지어내지 않는지"** 확인하는 데도 씁니다.

휴대폰 녹음 앱(갤럭시 「음성 녹음」 / 아이폰 「음성 메모」)으로 아래 두 문장을 **각각 따로** 녹음합니다. 10~20초면 됩니다.

**녹음 A** (파일 이름: `독서모임A`)

```text
다음 주 독서 모임을 준비하고 있어. 장소는 아직 확정하지 않았어.
안내문 초안은 금요일까지 만들자는 제안이 나왔지만, 담당자는 아직 정하지 않았어.
```

**녹음 B** (파일 이름: `독서모임B`)

```text
아까 이야기 이어서, 참가 인원은 10명이 아니라 15명으로 정정할게.
장소는 여전히 미정이고, 간식은 준비하면 좋겠다는 아이디어만 나온 상태야.
```

```text
상세 요구사항:

1. 기본 경로
- 루트: Documents\녹음자동처리
- 입력: inbox / 결과: notes / 로그: logs

2. 처리할 확장자: .m4a .mp3 .wav .aac .ogg .opus .flac

3. 오디오 변환 (중요)
- whisper.cpp는 16kHz 모노 wav만 안정적으로 읽는다.

- 이름이 ~syncthing~ 로 시작하는 파일, .stfolder .stignore .stversions 폴더와 그 안

- 끝나면 lock을 삭제하고, 오류가 나도 finally 블록에서 반드시 정리해 줘.
- lock이 2시간 이상 남아 있으면 비정상 종료로 보고 무시하고 진행해 줘.

  - 이름·숫자·금액·"아니라 ~로 정정" 같은 표현은 절대 임의로 바꾸지 말 것.

- 04_요약.md: 5~8줄 핵심 요약.
- 05_확인사항.md: 아직 정해지지 않은 것(미정), 불확실하게 들린 것, 제안만 나오고 확정되지 않은 것, 다시 확인해야 할 것을 목록으로. 없으면 "확인할 사항 없음"이라고 쓴다.
```

# Part 4. 텔레그램으로 알림 받기 (약 30분)

# 11장. 텔레그램 봇 만들기

"봇"은 텔레그램 안에서 자동으로 메시지를 보내 주는 **자동 계정**입니다. 내 컴퓨터가 이 봇을 통해 내 휴대폰에 알림을 보냅니다.

1. 휴대폰에 **텔레그램(Telegram)** 앱이 없으면 설치하고 가입합니다.
2. 텔레그램에서 위쪽 돋보기(검색)를 누르고 **`BotFather`** 를 검색합니다. **파란 체크(공식)** 가 있는 것을 고릅니다.
3. 대화를 열고 아래를 보냅니다.
   
   ```text
   /newbot
   ```
4. 봇의 **표시 이름**을 물어보면 아무거나 씁니다. 예: `철수AI비서`
5. 봇의 **사용자명**을 물어봅니다. 영어와 `_`로, **반드시 `bot`으로 끝나야** 합니다. 예: `chulsoo_ai_bot` (이미 쓰이는 이름이면 뒤에 숫자를 붙이세요)
6. 성공하면 BotFather가 축하 메시지를 보냅니다. 여기서 **두 가지**를 챙깁니다.
   - **봇 주소**: `t.me/...` 로 시작하는 링크
   - **토큰**: `Use this token to access the HTTP API:` **바로 아랫줄**의 긴 문자열 (예: `8887747616:ABCD...`)

**토큰 줄만 복사해서 메모장에 붙여 두세요.** 13장에서 씁니다.

> **⚠ 토큰은 비밀번호입니다**
> 
> 남에게 보여 주거나 카톡·게시판·화면 공유에 올리지 마세요. 실수로 노출했으면 BotFather에게 `/revoke`를 보내면 새 토큰이 나옵니다.

# 12장. 봇 시작하고 내 번호(chat_id) 알아내기

## 12-1. 내 봇 시작하기

1. 11장 축하 메시지의 **`t.me/...` 링크**를 누릅니다.
2. 내 봇 대화창이 열리면 아래 **`Start`(시작)** 버튼을 누릅니다. 끝입니다.

(봇은 내가 먼저 말을 걸어야 나에게 메시지를 보낼 수 있습니다.)

## 12-2. 내 chat_id 알아내기

봇이 **누구에게** 보낼지 알려면 내 텔레그램 고유 번호가 필요합니다.

1. 텔레그램 검색에서 **`@userinfobot`** 을 검색합니다. (이름이 User Info 처럼 보입니다)
2. 대화를 열고 **`Start`** 를 누릅니다.
3. 봇이 내 정보를 보여 줍니다. **`Id`** 옆의 숫자가 내 chat_id입니다. 예: `987654321`

이 숫자를 메모장에 적어 두세요.

> **⚠ 헷갈리지 마세요**
> 
> `@userinfobot`은 번호만 알려 주는 남의 봇입니다. **알림을 보내는 건 11장에서 내가 만든 봇**입니다.

# 13장. 알림 설정 저장하고 테스트하기

# 15장. 처리 기록장 만들기

처리한 녹음을 **엑셀 표처럼 한 줄씩** 기록하는 작은 기록장(SQLite)을 만듭니다. 따로 설치할 것은 없습니다. Python 안에 이미 들어 있습니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
녹음 처리 기록을 담는 기록장(SQLite)과 거기에 기록하는 도구를 만들고, 처리 스크립트가 기록을 남기게 연결해 줘.

먼저 준비:
- python --version 이 3.10 이상인지, pip 가 되는지 확인해 줘. 없으면 설치를 안내해 줘.
- pip install fastapi "uvicorn[standard]" jinja2 python-multipart markdown 을 설치해 줘.

1. 기록장 파일: Documents\녹음자동처리\data\status.db (data 폴더가 없으면 만들어 줘)
2. recordings 표를 만들어 줘. 칸은:
   - id (자동 증가), filename (같은 이름은 한 줄만 = UNIQUE), status (done / failed / queued / processing),
   - rec_type (녹음 유형), summary (요약 첫 줄), error (실패 원인), notes_path (결과 폴더), created_at, updated_at
3. 명령줄 도구 Documents\녹음자동처리\app\db.py 를 만들어 줘.
   - python app\db.py init → 기록장과 표를 만든다 (있으면 그대로)
   - python app\db.py set --filename "독서모임A.m4a" --status done --rec-type "회의" --summary "..." --notes-path "notes\독서모임A"
   - python app\db.py set --filename "독서모임A.m4a" --status failed --error "모델 파일을 찾을 수 없음"
   - 같은 filename이 있으면 새 줄을 만들지 말고 그 줄을 갱신한다. updated_at은 매번 현재 시각으로.
   - 한글은 UTF-8.
4. process-recordings.ps1 을 수정해서 (수정 전 .bak 백업):
   - 처리 시작 때: status processing
   - 성공 때: status done + rec_type + summary + notes_path
   - 실패 때: status failed + error (실제 오류 메시지 요약)
   - 기록장에 남긴 다음 텔레그램 알림을 보내는 순서로.
   - db.py 호출이 실패해도 녹음 처리는 멈추지 않게.
5. python app\db.py init 를 실행하고, notes\독서모임A 를 지운 뒤 스크립트를 한 번 돌려 status.db 에 done 으로 기록되는지 확인해 줘.

각 단계를 컴퓨터 초보자도 이해할 수 있게 한국어로 설명해 줘.
```

```text
녹음 관제판 웹 앱이 Windows 로그인 시 자동으로 켜지도록 등록해 줘.
1. Documents\녹음자동처리 에서 python -m uvicorn app.main:app --port 8500 을 자동 시작으로 등록 (--reload 는 빼 줘)
2. 작업 스케줄러 "로그인할 때" 트리거나 시작프로그램(shell:startup) 중 초보자에게 안전한 쪽으로
3. 창이 계속 떠 있지 않게 조용히 실행
4. 재시작 없이 한 번 실행해서 http://127.0.0.1:8500 이 열리는지 확인
5. 바탕화면에 http://127.0.0.1:8500 바로가기를 만들어 줘
6. 나중에 끄는 방법도 알려 줘
```

**Part 5 완성.** 이제 흐름이 이렇게 됩니다.

```text
녹음 → inbox → 5분 안에 자동 정리 → 텔레그램 알림
                       ↓ 실패하면
              관제판에서 원인 확인 → 재처리 버튼 → 완료 알림
```

# 19장. [갤럭시] Syncthing으로 녹음 폴더 자동 전송

> **ℹ 아이폰 사용자는 20장으로 건너뛰세요.**

## 19-1. 휴대폰에서 녹음이 저장되는 폴더 찾기

이 단계가 중요합니다. Syncthing은 "**어느 폴더를** 보낼지"를 내가 골라 줘야 하는데, 폴더를 잘못 고르면 아무것도 안 넘어옵니다.

1. 휴대폰 **음성 녹음** 앱을 열고 5초쯤 녹음하고 저장합니다.
2. **내 파일** 앱을 엽니다 → **내장 저장공간**
3. 아래 폴더를 차례로 찾아봅니다. 최근 갤럭시는 첫 번째가 가장 흔합니다.
   
   ```text
   내장 저장공간\Recordings\Voice Recorder   ← 가장 흔함
   내장 저장공간\Voice Recorder
   내장 저장공간\Sounds
   내장 저장공간\Music\Voice Recorder
   ```
4. 못 찾겠으면 **확실한 방법**: 「내 파일」 오른쪽 위 돋보기 → 방금 녹음한 파일 이름 검색 → 파일을 **길게 누름** → **상세정보** → **"위치"** 에 나온 폴더를 그대로 적어 둡니다.

파일 끝은 보통 `.m4a` 입니다.

> **⚠ 반드시 지킬 것**
> 
> - **내장 저장공간 전체**를 통째로 동기화하지 마세요. 수만 개 파일이 컴퓨터로 쏟아집니다.
> - DCIM(사진), Download, Android 같은 큰 폴더도 안 됩니다.
> - **녹음 파일이 들어 있는 작은 폴더 하나만** 고릅니다.
> - 안드로이드 11 이상은 보안 때문에 `Android\data` 아래 폴더는 접근이 막힙니다. 녹음 앱이 거기에 저장한다면 녹음 앱 설정에서 저장 위치를 바꾸거나, 삼성 기본 「음성 녹음」 앱을 쓰세요.

## 19-2. 휴대폰에 Syncthing-Fork 설치

1. **Play 스토어**에서 `Syncthing-Fork` 검색
2. 개발자가 **Catfriend1** 인 앱을 설치합니다. **비슷한 이름의 다른 앱이 있으니 개발자명을 꼭 확인**하세요.
3. 처음 실행 때 권한 요청(파일/오디오 접근, 알림, 근처 기기)은 **전부 허용**합니다.

## 19-3. 배터리 제한 해제 — ★ 건너뛰면 다음 날부터 안 됩니다

2기에서 **가장 흔한 실패 원인**이었습니다. "처음엔 됐는데 다음 날부터 안 와요"가 전부 이것입니다. 삼성이 배터리를 아끼려고 앱을 재워 버리기 때문입니다.

1. 휴대폰 **설정 → 애플리케이션 → Syncthing-Fork → 배터리**
2. 가장 강한 허용을 고릅니다. 기종에 따라 이름이 다릅니다.
   
   ```text
   제한 없음  /  최적화 안 함  /  배터리 사용량 제한 안 함  /  백그라운드 사용 허용
   ```
3. 하나 더: **설정 → 배터리 및 디바이스 케어 → 배터리 → 백그라운드 사용 제한**
   여기서 Syncthing-Fork가 **절전 상태 앱** 또는 **초절전 상태 앱** 목록에 있으면 **빼냅니다.** 그리고 **"사용하지 않는 앱 절전 상태로 전환"** 이 켜져 있으면 끄거나, Syncthing-Fork를 **"절전 상태로 전환 안 함"** 목록에 넣습니다.
4. Syncthing-Fork 앱 안에 `Running` / `동작 중` / `Listening` 이 보이면 정상. 멈춰 있으면 앱 안의 시작 버튼을 누릅니다.

## 19-4. 컴퓨터에 SyncTrayzor 설치

컴퓨터 쪽에도 Syncthing이 돌아가야 합니다. 초보자는 **SyncTrayzor**(Syncthing을 쉽게 켜고 끄는 윈도우 프로그램)를 씁니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
내 Windows PC에 SyncTrayzor(Syncthing 윈도우 프로그램)를 설치해 줘.
1. https://github.com/canton7/SyncTrayzor/releases 에서 SyncTrayzorSetup-x64.exe 를 받아 기본값으로 설치하도록 안내해 줘.
2. 설치 후 실행해서 브라우저에 http://127.0.0.1:8384 관리 화면이 열리는지 확인해 줘.
3. 처음 실행 때 Windows 방화벽 창이 뜨면 "개인 네트워크"에 체크하고 "액세스 허용"을 눌러야 한다고 미리 알려 줘.
4. 관리 화면에서 사용자 이름·비밀번호 설정을 권하는 안내가 나오면 설정하라고 알려 줘. (평소 쓰는 중요한 비밀번호는 쓰지 말 것)
각 단계를 초보자가 이해할 수 있게 설명해 줘.
```

정상이면 브라우저에 Syncthing 관리 화면이 열립니다. 주소는 이것입니다.

```text
http://127.0.0.1:8384
```

이 주소는 **내 컴퓨터 안에서만** 열리는 화면입니다. 인터넷에 공개되지 않습니다.

### 19-4-1. 설치했는데 화면이 안 열릴 때

SyncTrayzor는 오래된 프로그램이라 어떤 컴퓨터에서는 설치 후 바로 안 뜨거나, 재설치해야 되는 경우가 있습니다. **여러분 잘못이 아닙니다.** 순서대로 해 보세요.

**① 트레이에 숨어 있나 확인**

1. 화면 오른쪽 아래 작업 표시줄의 **숨겨진 아이콘 ^** 를 누릅니다.
2. SyncTrayzor 아이콘이 있으면 **오른쪽 클릭 → Open Syncthing**
3. 브라우저에서 `http://127.0.0.1:8384` 를 직접 쳐 봅니다. 열리면 정상 실행 중인 겁니다.

**② Codex에게 진단 맡기기**

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
SyncTrayzor를 설치했는데 Syncthing 화면(http://127.0.0.1:8384)이 열리지 않아. 초보자도 따라할 수 있게 아래 순서로 확인하고 고쳐 줘.
1. SyncTrayzor 프로세스가 실행 중인지
2. syncthing.exe 프로세스가 실행 중인지
3. http://127.0.0.1:8384 가 열리는지
4. Windows 방화벽이 막고 있는지
5. 이미 다른 Syncthing이 실행 중이라 8384 포트가 겹치는지
6. 실제 오류 메시지가 있으면 그것을 기준으로 해결
```

**③ 재설치 (설치가 꼬였다 싶을 때)**

1. SyncTrayzor 창을 닫고, 트레이 아이콘에서 **완전히 종료**
2. 윈도우 **설정 → 앱 → 설치된 앱** → SyncTrayzor **제거**
3. **컴퓨터 재부팅** (건너뛰지 마세요)
4. 최신 설치 파일을 다시 받아 설치
5. 실행해서 `http://127.0.0.1:8384` 확인

그래도 안 되면:

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
SyncTrayzor를 제거하고 재설치했는데도 안 돼. 내 PC에 남아 있는 SyncTrayzor/Syncthing 설정과 실행 상태를 확인해 줘.
주의:
- 녹음 파일이나 notes 결과물은 절대 삭제하지 마.
- 설정 폴더를 지워야 한다면 먼저 백업 위치를 알려 주고 내가 확인한 뒤 진행해.
- SyncTrayzor와 별도 Syncthing 서비스가 동시에 실행되는 충돌이 있는지 확인해.
```

**④ 대안 1 — 새 버전 SyncTrayzor**

기존 SyncTrayzor가 계속 불안정하면, 새로 관리되는 버전이 있습니다.

```text
https://github.com/GermanCoding/SyncTrayzor/releases
```

기존 것을 제거 → 재부팅 → 이걸 설치. **둘을 동시에 설치해 실행하지 마세요.** 같은 8384번 창구를 두고 충돌합니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
기존 SyncTrayzor가 불안정해서 https://github.com/GermanCoding/SyncTrayzor/releases 의 새 버전으로 바꾸고 싶어.
1. 기존 SyncTrayzor가 실행 중이면 안전하게 종료해 줘.
2. 기존 프로그램 제거 방법을 안내해 줘.
3. 위 주소에서 최신 Windows 설치 파일을 받도록 안내해 줘.
4. 설치 후 http://127.0.0.1:8384 가 열리는지 확인해 줘.
5. 기존 설정을 지워야 한다면 먼저 백업을 안내하고, 내가 확인하기 전에는 지우지 마.
```

**⑤ 대안 2 — SyncTrayzor 없이 Syncthing만**

SyncTrayzor가 끝내 안 되면 Syncthing 본체만 설치하고 로그인할 때 자동 실행되게 합니다. 관리 화면 주소는 똑같습니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
SyncTrayzor 대신 공식 Syncthing을 Windows에서 직접 실행하는 방식으로 설정하고 싶어.
1. 공식 Syncthing Windows x64 실행 파일을 받아 Documents\녹음자동처리\tools\syncthing 폴더에 정리해 줘.
2. syncthing.exe 를 실행해서 http://127.0.0.1:8384 관리 화면이 열리는지 확인해 줘.
3. Windows 작업 스케줄러로 내가 로그인할 때 Syncthing이 자동 실행되게 등록해 줘. (Windows 서비스로는 등록하지 마. 초보자에게는 로그인 시 자동 실행이 안전해.)
4. SyncTrayzor가 같이 실행 중이면 충돌하니 종료하거나 제거하라고 안내해 줘.
5. 관리 화면 비밀번호 설정을 안내해 줘.
6. 컴퓨터 초보자도 이해할 수 있게 각 단계를 설명해 줘.
```

## 19-5. 컴퓨터와 휴대폰을 "아는 사이"로 만들기

두 기기가 **같은 Wi-Fi**에 있어야 합니다. 휴대폰이 모바일 데이터(5G/LTE)로 되어 있으면 안 됩니다.

**컴퓨터에서**

1. `http://127.0.0.1:8384` 화면 오른쪽 위 **Actions(동작) → Show ID(ID 표시)**
2. **QR 코드**가 뜹니다. 그 화면을 켜 둡니다.

**휴대폰에서**
3. Syncthing-Fork → **Devices(기기)** 탭 → **+**
4. **QR 코드 스캔** → 컴퓨터 화면의 QR을 찍습니다.
5. 기기 이름을 `내 PC` 처럼 알아보기 쉽게 → 저장

**다시 컴퓨터에서**
6. 잠시 뒤 화면 위쪽에 **"새 기기가 연결을 요청했습니다"** 파란 막대가 뜹니다 → **Add Device(수락)** → 저장
7. 양쪽 모두 상대가 **Connected(연결됨)** 로 보이면 성공.

> **💡 파란 막대가 안 뜨면**
> 
> - 브라우저 **F5(새로고침)** 
> - 두 기기가 **같은 Wi-Fi**인지. 휴대폰 Wi-Fi 설정에서 이름을 확인하세요. 집에 Wi-Fi 이름이 두 개(2.4GHz / 5GHz)인 경우 다른 쪽에 붙어 있을 수 있습니다. 보통은 같은 공유기라 되지만, 안 되면 **둘 다 같은 이름**에 붙이세요.
> - 휴대폰이 **모바일 데이터만** 쓰고 있지는 않은지
> - 컴퓨터 방화벽에서 Syncthing을 막고 있지 않은지 (19-4-2 표)
> - 그래도 안 되면 **휴대폰 핫스팟**을 켜고 컴퓨터를 거기 연결해 보세요. 둘만의 작은 네트워크가 되어 바로 연결됩니다. 연결만 되면 다시 집 Wi-Fi로 돌아와도 됩니다.

## 19-6. 녹음 폴더를 컴퓨터 inbox로 보내기

**휴대폰에서**

1. Syncthing-Fork → **Folders(폴더)** 탭 → **+**
2. 폴더 이름(Label): `녹음`
3. Folder ID: `noksound` (아무거나, 영문)
4. 폴더 경로: **19-1에서 확인한 실제 녹음 폴더** 선택 (보통 `Recordings\Voice Recorder`)
5. 폴더 유형(Folder Type): **Send Only (보내기 전용)**
   → 휴대폰은 **보내기만** 하고, 컴퓨터에서 무슨 일이 있어도 휴대폰 녹음은 안 건드립니다.
6. 공유 대상(Share with devices): **내 PC** 체크 → 저장

**컴퓨터에서**
7. 화면에 **"새 폴더를 추가할까요?"** 안내가 뜨면 **Add(추가)**
8. 폴더 경로(Folder Path)를 아래로 지정합니다. `내이름` 부분은 본인 것으로.

```text
C:\Users\내이름\Documents\녹음자동처리\inbox
```

> **⚠ 내 문서 폴더가 OneDrive 안에 있는 경우**
> 최근 윈도우는 「문서」 폴더가 `C:\Users\내이름\OneDrive\Documents` 에 있을 수 있습니다. 2장에서 Codex가 알려 준 실제 경로를 쓰세요. 모르겠으면 탐색기에서 `inbox` 폴더를 열고 **주소창을 클릭**하면 전체 경로가 보입니다. 그걸 복사하세요.
> 9. 폴더 유형: **Receive Only (받기 전용)** → 저장

**테스트**
10. 휴대폰에서 5초 녹음하고 저장
11. 1~2분 기다린 뒤 컴퓨터 `문서\녹음자동처리\inbox` 에 파일이 보이면 **성공.** 5분 안에 텔레그램이 울립니다.

### 19-6-1. 폴더 설정에서 자주 막히는 것

| 증상                            | 원인                       | 해결                                                                       |
| ----------------------------- | ------------------------ | ------------------------------------------------------------------------ |
| 컴퓨터에 "새 폴더" 안내가 안 뜸           | 휴대폰에서 공유 대상에 PC를 체크 안 함  | 휴대폰 폴더 설정 → Share with devices 확인                                        |
| 폴더가 계속 빨간색·오류                 | 컴퓨터 폴더 경로가 틀렸거나 권한 문제    | 경로를 탐색기 주소창에서 복사해 다시 지정                                                  |
| 휴대폰 폴더가 "No permission"       | 안드로이드 저장공간 권한            | 휴대폰 설정 → 애플리케이션 → Syncthing-Fork → 권한 → 파일 및 미디어 → **모든 파일 관리 허용**       |
| 파일이 안 넘어옴                     | 폴더를 잘못 골랐음               | 19-1의 "상세정보 → 위치"로 실제 폴더 다시 확인                                           |
| 처음엔 됐는데 다음 날 안 됨              | 배터리 제한                   | **19-3** 다시                                                              |
| 컴퓨터 화면이 **Out of Sync** 빨간 표시 | inbox의 파일을 컴퓨터에서 손으로 지웠음 | 오류 아님. 휴대폰에서 원본을 지우면 정리되고, 또는 Syncthing 화면 폴더에서 **Revert Local Changes** |
| 파일 이름이 `~syncthing~...tmp`    | 아직 전송 중                  | 잠시 기다리면 원래 이름으로 바뀜. 스크립트는 이 파일을 건너뜀                                      |

> **ℹ 휴대폰에서 녹음을 지우면 컴퓨터 inbox에서도 지워집니다.** (보내기 전용 → 받기 전용 설정이라 그렇습니다.) 하지만 이미 만들어진 **notes의 정리 문서는 그대로 남습니다.** 원본 음성을 오래 두고 싶으면 inbox 밖 다른 폴더에 복사해 두세요.

### 19-6-2. 그래도 안 넘어올 때 — 만능 문장

```text
갤럭시에서 녹음한 파일이 PC의 Documents\녹음자동처리\inbox 로 오지 않아. 초보자도 따라할 수 있게 순서대로 확인해 줘.

```

# 20장. [아이폰] LocalSend로 보내기 (갤럭시도 가능)

> **ℹ 갤럭시로 19장을 끝낸 분은 이 장을 건너뛰세요.**

아이폰은 보안 정책 때문에 "폴더를 통째로 자동 감시"하는 방식이 안 됩니다. 대신 **LocalSend**로 녹음을 **탭 세 번**에 보냅니다. 한 번 설정하면 갤럭시와 거의 같은 편의성입니다. **안드로이드에서도 됩니다** — Syncthing이 어렵다면 이걸 쓰세요.

만들 최종 모습:

```text
음성 메모에서 녹음 → 공유 → LocalSend → 내 PC 탭
        ↓
컴퓨터 inbox에 바로 저장 (수락 버튼도 안 눌러도 됨)
        ↓
5분 안에 자동 정리 → 텔레그램 알림
```

## 20-1. 컴퓨터에 LocalSend 설치

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
내 Windows PC에 LocalSend를 설치해 줘.
1. winget이 있으면 winget install LocalSend.LocalSend 로 설치해 줘. 없으면 https://localsend.org 에서 Windows용 설치 파일을 받아 설치하도록 안내해 줘.
2. 설치 후 LocalSend를 실행해 줘.
3. 처음 실행 때 Windows 방화벽 창("이 앱의 네트워크 액세스를 허용하시겠습니까?")이 뜨면 "개인 네트워크"에 체크하고 "액세스 허용"을 눌러야 한다고 알려 줘.
4. LocalSend가 쓰는 포트 53317(TCP/UDP)이 방화벽에서 열려 있는지 확인하고, 막혀 있으면 인바운드 허용 규칙을 추가해 줘.
5. 현재 네트워크 프로필이 "공용"으로 되어 있으면 "개인"으로 바꾸는 방법을 안내해 줘.
각 단계를 초보자가 이해할 수 있게 한국어로 설명해 줘.
```

> **⚠ 방화벽 창에서 「취소」를 누르면 아이폰에서 컴퓨터가 아예 안 보입니다**
> 
> 2기 아이폰 조 절반이 여기서 막혔습니다. 실수했으면 위 문장을 다시 붙여넣으면 Codex가 열어 줍니다.

## 20-2. 컴퓨터 LocalSend 설정 — ★ 이 장의 전부

이걸 하면 받은 파일을 손으로 옮길 일이 없어집니다.

1. 컴퓨터 LocalSend → 왼쪽 또는 아래의 **설정(Settings, 톱니바퀴)**
2. **저장 폴더 / Storage / Destination** 항목을 찾아 아래로 지정. `내이름`은 본인 것으로. (OneDrive 안에 있으면 그 경로로 — 탐색기 주소창에서 복사)
   
   ```text
   C:\Users\내이름\Documents\녹음자동처리\inbox
   ```
3. **자동 수신 / Quick Save / 빠른 저장** 을 **켬**
4. 같은 화면에서 이 컴퓨터의 **기기 이름**을 `내 PC` 처럼 알아보기 쉽게

이제 아이폰에서 보내면 컴퓨터에서 **수락 버튼을 누르지 않아도** inbox에 바로 저장됩니다.

> **⚠ 자동 수신은 집·개인 Wi-Fi에서만**
> 
> 켜 두면 **같은 Wi-Fi의 누구나** 내 컴퓨터로 파일을 밀어 넣을 수 있습니다. 집에서는 괜찮지만 **카페·사무실·학교 공용 Wi-Fi에서는 꺼 두세요.** 꺼도 「수락」 한 번만 누르면 되니 전송은 계속 됩니다.

## 20-3. 아이폰에 LocalSend 설치

1. **App Store**에서 `LocalSend` 검색 → 설치 (무료, 광고 없음)
2. 처음 열 때 **"로컬 네트워크 접근"** 권한을 묻습니다. **반드시 허용.**
3. 아이폰과 컴퓨터가 **같은 Wi-Fi** 인지 확인. 아이폰이 5G/LTE만 쓰면 서로 못 찾습니다.

> **⚠ 「로컬 네트워크」 권한을 거부하면 아무것도 안 됩니다**
> 
> 아이폰은 같은 Wi-Fi의 기기를 찾는 것도 따로 권한을 막아 둡니다. 실수로 거부했으면:
> 
> ```text
> 설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → LocalSend 를 켬
> ```

## 20-4. 첫 전송

1. **음성 메모** 앱에서 10초 녹음 → 저장
2. 목록에서 녹음을 누르고 → **제목을 알아보기 쉽게 바꿈** (예: `0925 가족회의`)
3. **···**(더 보기) → **공유** → 공유 메뉴에서 **LocalSend**
4. LocalSend가 열리면 주변 기기 목록에 **내 PC** 가 보입니다 → 한 번 탭
5. 초록색 완료 표시가 뜨면 끝. 컴퓨터 `문서\녹음자동처리\inbox` 에 파일이 있으면 성공.

> **💡 공유 메뉴에 LocalSend가 안 보이면**
> 
> 공유 메뉴의 앱 목록을 **왼쪽으로 끝까지 밀어** ··· (기타) → 목록에서 LocalSend를 **켜기** → 위로 끌어 올리기. 한 번만 하면 다음부터 맨 앞에 나옵니다.

> **⚠ 파일 이름을 바꾸고 보내세요**
> 
> 아이폰 음성 메모는 `새로운 녹음 3` 처럼 이름을 붙입니다. 동작은 되지만 결과 폴더 이름도 `새로운 녹음 3`이 되어 나중에 못 찾습니다. 보내기 전에 제목을 바꾸는 습관을 들이세요. `? * : " < > | \ /` 기호는 피합니다.

## 20-5. 앞으로 매번 하는 법

한 번 설정해 두면 이 **세 번의 탭**이 전부입니다.

1. 음성 메모에서 녹음 → 제목 바꾸기
2. **···** → **공유** → **LocalSend**
3. **내 PC** 탭

> **ℹ 컴퓨터가 꺼져 있으면**
> 
> LocalSend는 두 기기가 **동시에 켜져 있어야** 됩니다. 컴퓨터가 꺼져 있으면 아이폰에서 PC가 안 보입니다. 녹음은 그냥 두었다가 나중에 컴퓨터를 켠 뒤 보내면 됩니다. 여러 개를 한꺼번에 선택해 보낼 수도 있습니다.

## 20-6. 문제 해결: 아이폰에서 컴퓨터가 안 보여요

흔한 원인 순서입니다.

| 증상                     | 원인                                   | 해결                                                         |
| ---------------------- | ------------------------------------ | ---------------------------------------------------------- |
| 주변 기기 목록이 **비어 있음**    | 서로 다른 Wi-Fi, 또는 아이폰이 모바일 데이터         | 두 기기를 같은 Wi-Fi 이름에 연결. 아이폰 Wi-Fi 켜졌는지 확인                   |
| 계속 **검색만** 함           | 컴퓨터 방화벽이 LocalSend를 막음               | 20-1 문장 다시 붙여넣기 (방화벽 허용)                                   |
| 아이폰에서만 안 보임            | 로컬 네트워크 권한 거부                        | 설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → LocalSend 켬                  |
| 컴퓨터에 LocalSend가 안 떠 있음 | 프로그램이 꺼짐                             | LocalSend 실행 후 다시 (18장처럼 자동 시작 등록도 가능)                     |
| 전송은 됐는데 **inbox에 없음**  | 저장 폴더가 inbox가 아님                     | 20-2 저장 폴더 다시 확인. 「다운로드」 폴더에 있을 수 있음                       |
| 카페·회사·학교 Wi-Fi에서 안 됨   | 공용 Wi-Fi가 기기끼리 못 보게 막음(AP isolation) | **아이폰 핫스팟을 켜고 컴퓨터를 거기 연결** — 둘만의 네트워크가 되어 바로 됨. 데이터 거의 안 씀 |

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
아이폰(또는 안드로이드)의 LocalSend에서 내 Windows PC가 보이지 않아. 초보자도 따라할 수 있게 아래 순서로 확인하고 고쳐 줘.
1. PC에서 LocalSend 프로세스가 실행 중인지
2. PC의 IP 주소를 알려 주고, 휴대폰과 같은 네트워크 대역인지 판단하는 법을 알려 줘
3. Windows Defender 방화벽에서 LocalSend 인바운드 규칙이 개인 네트워크에 허용되어 있는지
4. 막혀 있으면 포트 53317 TCP/UDP 허용 규칙을 추가해 줘
5. 현재 네트워크 프로필이 "공용"이면 "개인"으로 바꾸는 방법을 안내해 줘
6. LocalSend 설정의 저장 폴더가 Documents\녹음자동처리\inbox 로 되어 있는지 (실제 경로 기준으로)
각 단계를 한국어로 쉽게 설명해 줘.
```

## 20-7. 대안 — LocalSend가 도저히 안 될 때

1. 컴퓨터에 **iCloud for Windows** 설치 → Apple ID 로그인 → iCloud Drive 동기화 켬
2. 음성 메모에서 녹음 공유 → **파일에 저장** → iCloud Drive의 원하는 폴더
3. 컴퓨터의 iCloud Drive 폴더에 파일이 나타나면 inbox로 복사. 옮기는 것도 Codex에게 시킬 수 있습니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
내 PC의 iCloud Drive 폴더에서 가장 최근에 추가된 오디오 파일을 찾아 Documents\녹음자동처리\inbox 로 옮겨 줘.
옮기기 전에 파일명과 크기를 먼저 보여 주고, 내 확인을 받은 뒤 옮겨 줘.
```

> **ℹ 왜 iCloud를 기본으로 권하지 않나요**
> 
> iCloud는 파일이 **Apple 서버를 거쳐** 옵니다. 녹음이 인터넷을 한 번 왕복하고, 몇 분씩 지연되기도 합니다. LocalSend는 서버 없이 Wi-Fi로 직접 보내 빠르고 밖으로 안 나갑니다.

> **⚠ 이 Secret은 비밀번호입니다.** 카톡·게시판·화면 공유에 올리지 마세요.

**③ 페이지에 출입증 연결하기 — 가장 많이 빼먹는 단계** — 보관함 페이지 오른쪽 위 **···** → **Connections(연결)** → `녹음자동처리` 검색 → 연결 → 확인

> 이걸 안 하면 100% 실패합니다. `object_not_found` / `Could not find page` 오류가 나면 거의 항상 이 단계를 안 한 것입니다.

**④ 페이지 ID 적어 두기** — 보관함 페이지 주소를 복사. 주소 끝의 **32자리 영문·숫자**가 페이지 ID입니다.


# Part 8. (심화) 정리한 기록에 질문하기

쌓인 녹음 기록에 **"지난주 독서모임 장소 정해졌어?"** 처럼 물어보면, 기록을 찾아 **근거와 함께** 답하는 챗봇을 관제판에 붙입니다. 2기 청년 한 분이 만든 것을 단순화한 것입니다.

**▶ ChatGPT 앱(Codex)에 붙여넣을 문장**

```text
관제판(app\main.py)에 "기록에 질문하기" 화면(/ask)을 추가해 줘.

1. 질문 범위를 고를 수 있게: 전체 기록 / 특정 녹음 하나
2. 질문을 넣으면 notes 아래 모든 02_정제본.md, 03_상세정리.md, 05_확인사항.md 에서 질문과 관련된 부분을 한국어 키워드로 찾는다. (벡터 검색 같은 어려운 건 쓰지 마. 첫 구현은 키워드 검색이면 충분해.)
3. 찾은 관련 구간(최대 5개, 각 1500자 이내)과 질문을 Codex CLI에 넘겨 답을 받는다.
   - 답에는 반드시 "근거: 어느 녹음의 어느 문서" 를 붙인다.
   - 기록에 없는 내용은 지어내지 말고 "기록에서 찾지 못했습니다"라고 한다.
   - 미정·확인사항으로 남아 있는 것은 미정이라고 답한다.
4. 답 아래에 "근거 펼치기"를 두어 실제 찾은 구간과 그 녹음의 상세 페이지 링크를 보여 준다.
5. 대화는 data\대화\<날짜_시각>.md 로 저장한다.
6. 만든 뒤 시험: "독서모임 참가 인원은 몇 명으로 정리됐어?" → 15명과 근거가 나와야 하고, 이어서 "장소는 정해졌어?" → 미정이라고 답해야 한다. "오늘 날씨 어때?" → 기록에 없다고 답해야 한다.
7. 실제로 확인한 것과 못 한 것을 구분해서 알려 줘.
```

여기까지 되면 여러분은 **"녹음 → 정리 → 알림 → 관제 → 질문"** 을 전부 갖춘 개인 비서를 만든 겁니다. 2기 5·6주차 두 번에 걸쳐 한 것보다 많습니다.

# 24장. 자주 묻는 질문

**Q. 녹음 내용이 인터넷으로 나가나요?**  
음성 파일은 안 나갑니다. 전사(whisper.cpp)는 내 컴퓨터 안에서만 됩니다. 다만 **정리·요약 단계에서 전사된 글자**는 Codex(OpenAI)로 갑니다. 텔레그램 알림에는 요약 두 줄이, Notion을 켰으면 정리 문서가 갑니다. 민감한 회의는 `01_전사원문.md`까지만 쓰는 선택도 됩니다.

**Q. 무료인가요?**  
whisper.cpp·ffmpeg·텔레그램·Syncthing·LocalSend·Notion 무료 계정 — 전부 무료입니다. Codex는 여러분의 **ChatGPT 유료 플랜 사용량**을 씁니다. 녹음 몇 개 정리하는 정도는 부담이 없습니다.

**Q. 긴 녹음은 얼마나 걸리나요?**  
base-ko로 10분 녹음이 1~3분, small은 3~8분쯤입니다(컴퓨터 사양에 따라 다름). 노트북이 배터리로 돌면 더 걸립니다. **과제는 짧은 녹음으로 하고, 긴 회의는 완주한 뒤 돌리세요.**

**Q. 전사가 자꾸 틀려요.**  
10장에서 모델을 small로 올리세요. 마이크를 말하는 사람 쪽에 두고 에어컨·키보드 소음을 줄이는 것만으로도 꽤 좋아집니다. 이 과제의 목표는 완벽한 전사가 아니라 **자동으로 도는 흐름**입니다.

**Q. 컴퓨터를 껐다 켜면 다 사라지나요?**  
아니요. 정리 문서는 notes 폴더에, 기록장은 data\status.db 파일에 남습니다.

**Q. 회사 컴퓨터에서 해도 되나요?**  
회사 보안 정책에 따라 프로그램 설치나 PowerShell이 막혀 있을 수 있습니다. **회사 규정을 먼저 확인**하세요. 개인 노트북을 권합니다.

**Q. Codex 대신 Claude Code로 해도 되나요?**  
됩니다. 이 문서의 상자를 그대로 붙여넣으면 됩니다. 도구 이름만 다를 뿐 하는 일은 같습니다.

**Q. 갤럭시인데 아이폰 방식(LocalSend)을 써도 되나요?**  
됩니다. LocalSend는 안드로이드도 지원합니다. 설정이 Syncthing보다 쉬워서 오히려 편할 수 있습니다.
