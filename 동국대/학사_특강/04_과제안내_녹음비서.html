① 폴더 만들기 · 내가 합니다

Windows

  1. Windows+E로 파일 탐색기를 엽니다.
  2. 왼쪽 문서를 누릅니다.
  3. 빈 곳에서 마우스 오른쪽 → 새로 만들기 → 폴더 → 이름 녹음자동처리 → Enter.

위치는 보통 C:\Users\내이름\Documents\녹음자동처리 입니다. 문서 폴더가 OneDrive 안에 있으면 나중에 권한 오류가 날 수 있습니다. 그때는 20장 표를 보세요.

Mac

  1. Finder를 엽니다.
  2. 화면 위 메뉴 이동 → 홈을 누릅니다. (집 모양, 내 이름 폴더)
  3. 메뉴 파일 → 새로운 폴더 → 이름 녹음자동처리 → Return.

문서·데스크탑·다운로드 폴더가 아니라 홈 폴더 바로 아래에 만듭니다. Mac은 보안 때문에, 예약해 둔 프로그램이 문서·데스크탑·다운로드 폴더를 열지 못하게 막을 수 있습니다. 위치는 /Users/내이름/녹음자동처리 입니다.

② Antigravity에 프로젝트 만들기 · 내가 합니다

  1. Antigravity 왼쪽 Projects 근처의 폴더 + 아이콘 → New Project → 이름 녹음비서.
  2. Add Folder → 방금 만든 녹음자동처리 폴더를 고릅니다. (그 위의 문서·홈 폴더 전체를 고르지 않습니다.)
  3. Create → 왼쪽에서 녹음비서 프로젝트를 고르고 새 대화를 엽니다. 실행 위치를 물으면 Local.

이 컴퓨터에 Antigravity CLI(명령어 이름 agy)를 설치해 줘.

1. 먼저 agy --version 이 실행되는지 확인해 줘. 이미 있으면 다시 설치하지 마.
   agy라는 명령이 있어도 데스크톱 앱을 여는 명령일 수 있으니, agy --version 결과로 CLI가 맞는지 확인해 줘.
2. 없으면 공식 안내(https://antigravity.google/docs/getting-started?tab=cli)의 방법으로 설치해 줘.
   - Mac: curl -fsSL https://antigravity.google/cli/install.sh | bash
   - Windows(PowerShell): irm https://antigravity.google/cli/install.ps1 | iex
3. 설치 뒤 agy --version 으로 확인해 줘. 명령을 못 찾으면 설치 위치(Mac은 ~/.local/bin, Windows는 AppData\Local\agy\bin)가 PATH에 들어갔는지 확인하고 고쳐 줘.
4. agy를 처음 실행할 때 화면 설정과 Google 로그인을 묻는 과정이 있는데, 그건 내가 직접 해야 해.
   내가 할 수 있게 터미널을 여는 방법과 칠 명령 한 줄을 알려 줘.
5. 설치된 agy의 전체 경로를 AGENTS.md 에 적어 줘. 자동 처리 프로그램이 이 경로로 부를 거야.

② 처음 한 번 로그인 · 내가 합니다

agy는 처음 켤 때 몇 가지를 묻고 Google 로그인을 합니다. 이 단계만 터미널(글자로 명령하는 창)에서 직접 합니다. 한 번만 하면 됩니다.

Windows

  1. Windows 키를 누르고 PowerShell을 입력 → Enter. 파란색 또는 검은색 창이 열립니다.
  2. agy 를 입력하고 Enter. “명령을 찾을 수 없다”고 나오면 창을 닫고 PowerShell을 새로 열어 다시 칩니다.
  3. 색·화면 방식 같은 질문은 Enter로 기본값을 고릅니다. 이 폴더를 믿겠느냐(trust)고 물으면 예.
  4. 브라우저가 열리면 Antigravity와 같은 개인 Google 계정으로 로그인하고 허용합니다.
  5. 터미널로 돌아와 안녕 이라고 쳐서 답이 오면 성공. 창을 닫습니다.

Mac

  1. ⌘+Space → 터미널(Terminal) 입력 → Return. 흰색 또는 검은색 창이 열립니다.
  2. agy 를 입력하고 Return. “command not found”가 나오면 창을 닫고 새 터미널을 열어 다시 칩니다. 그래도 안 되면 ~/.local/bin/agy 를 칩니다.
  3. 색·화면 방식 같은 질문은 Return으로 기본값을 고릅니다. 이 폴더를 믿겠느냐(trust)고 물으면 예.
  4. 브라우저가 열리면 Antigravity와 같은 개인 Google 계정으로 로그인하고 허용합니다.
  5. 터미널로 돌아와 안녕 이라고 쳐서 답이 오면 성공. 창을 닫습니다.

whisper.cpp는 음성을 글자로 바꿔 주는 무료 프로그램입니다. 녹음이 인터넷으로 나가지 않고 내 컴퓨터 안에서만 처리됩니다. 휴대폰 녹음 파일(.m4a)을 읽으려면 ffmpeg라는 변환 도구도 필요합니다. 이번 과제의 프로그램은 Windows·Mac 모두 쓰는 파이썬으로 만들기 때문에, 파이썬도 함께 준비합니다.

스터디 2기에서 가장 많이 막힌 곳입니다. whisper.cpp는 휴대폰 녹음을 바로 못 읽습니다. 아래 프롬프트에 ffmpeg까지 들어 있으니 그대로 붙여넣으면 됩니다.

3장 · whisper.cpp · ffmpeg · 파이썬 준비

버튼으로 프롬프트 전체를 복사해 Antigravity 대화 입력란에 붙여넣고 보내세요. 직접 타이핑하지 않습니다.

녹음자동처리\tools 아래에 음성을 글로 바꾸는 도구를 준비해 줘. 관리자 비밀번호 없이 되는 방법을 먼저 써 줘.

1) 파이썬
- uv(파이썬을 관리자 권한 없이 설치·실행해 주는 도구)가 있는지 확인하고, 없으면 공식 방법으로 설치해 줘.
  Mac: curl -LsSf https://astral.sh/uv/install.sh | sh
  Windows(PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
- uv로 파이썬 3.12를 준비하고, 앞으로 이 과제의 파이썬 프로그램은 uv run 으로 실행해 줘.

2) whisper.cpp
- tools 아래나 이 컴퓨터에 whisper-cli(옛 이름 main) 실행 파일이 있는지 확인하고, 있으면 --help 로 실행되는지 확인해 줘.
- 없으면 준비해 줘.
  Windows: 공식 GitHub 릴리스의 최신 Windows x64 실행 파일을 받아 tools\whispercpp 에 정리.
  Mac: Homebrew가 이미 있으면 brew install whisper-cpp. Homebrew가 없으면 관리자 비밀번호 없이 되는 방법을 먼저 찾아 줘
       (예: whisper.cpp를 tools 아래에 직접 빌드. 이때 Xcode 명령줄 도구 설치 창이 뜨면 내가 '설치'를 누르면 된다고 알려 줘).

3) ffmpeg
- ffmpeg -version 이 실행되는지 확인하고, 없으면 tools\ffmpeg 에 준비해 줘.
  Windows: 공식 안내에 있는 Windows용 빌드(zip)를 받아 압축 해제.
  Mac: Homebrew가 있으면 brew install ffmpeg, 없으면 관리자 권한 없이 쓰는 정적 실행 파일.

4) 마지막에 파이썬(uv), whisper-cli, ffmpeg 의 실제 실행 파일 전체 경로를 알려 주고 AGENTS.md 에도 적어 줘.
각 단계를 컴퓨터 초보자가 이해할 수 있게 한국어로 설명해 줘.

Windows에서 이런 창이 뜨면

  • “Windows의 PC 보호”(파란 창): 공개된 무료 프로그램을 처음 실행할 때 뜹니다. 추가 정보 → 실행을 누릅니다.
  • 백신이 whisper·ffmpeg를 지운다면: AI에게 “Windows Defender 제외 폴더에 녹음자동처리\tools 를 추가하는 방법을 알려 줘”라고 보내세요.

Mac에서 이런 창이 뜨면

  • “명령어 라인 개발자 도구를 설치하겠습니까?”: 설치를 누르고 끝날 때까지 기다립니다(몇 분). 끝나면 AI에게 “설치 끝났어, 이어서 해 줘”.
  • “확인되지 않은 개발자” 경고: AI에게 그 문구를 그대로 보내면 여는 방법을 알려 줍니다.
  • 터미널에서 비밀번호를 물으면: Mac 로그인 비밀번호를 칩니다. 쳐도 화면에 글자가 안 보이는 게 정상입니다. 다 치고 Return.

4장 · 사양 확인과 모델 받기

버튼으로 프롬프트 전체를 복사해 Antigravity 대화 입력란에 붙여넣고 보내세요. 직접 타이핑하지 않습니다.

프롬프트 내용 펼쳐보기 · AI에게 전달할 내용
이 노트북에 맞는 whisper.cpp 한국어 전사 모델을 골라서 받아 줘. 저장 위치는 녹음자동처리\models.

1. 먼저 이 노트북의 사양을 확인해서 표로 보여 줘.
   운영체제, CPU 이름과 코어 수(논리 프로세서 수), Apple 칩(M1 이상)인지, 메모리(RAM) 크기, 남은 저장 공간, NVIDIA 그래픽카드가 있는지.
2. 아래 기준으로 1순위 모델을 골라 줘. 나는 가능하면 medium-korean 을 쓰고 싶어.
   - medium-korean: Apple 칩 Mac이고 메모리 8GB 이상, 또는 그 밖의 컴퓨터는 메모리 16GB 이상이면서 논리 프로세서 8개 이상. 남은 저장 공간 3GB 이상.
   - small: 메모리 8GB 이상인데 medium-korean 기준에 못 미칠 때.
   - base-ko: 메모리 8GB 미만이거나 저장 공간이 부족할 때.
   왜 그 모델을 골랐는지 쉬운 말로 설명해 줘.
3. 고른 모델을 받아 줘. base-ko 는 어느 경우든 예비로 함께 받아 둬.
   - medium-korean: https://huggingface.co/royshilkrot/whisper-medium-korean-ggml/resolve/main/whisper-medium-korean.bin
     → whisper-medium-korean.bin, 약 1.53GB. Whisper medium을 한국어로 더 학습시킨 모델이야.
   - small: https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin
     → ggml-small.bin, 약 488MB. 여러 언어용 모델이라 전사할 때 반드시 -l ko.
   - base-ko: https://huggingface.co/wabisabisocial/whisper-base-korean-ggml/resolve/main/ggml-base-ko.bin
     → ggml-base-ko.bin, 약 148MB.
   어느 모델이든 전사할 때는 -l ko 로 한국어를 지정해.
4. 받은 파일마다 크기가 위의 예상과 비슷한지 확인해 줘. 오류 페이지가 .bin 이름으로 저장되는 경우가 있어서 크기 확인이 중요해.
   큰 파일이 중간에 끊기면 이어받기 방식으로 다시 받아 줘.
5. 주소가 죽어 있으면 whisper.cpp 공식 모델 중 같은 크기(ggml-medium.bin / ggml-small.bin / ggml-base.bin)로 대신 받고, 파일 이름이 달라졌다고 알려 줘.
6. 사양 표, 고른 모델과 이유, 받은 파일들의 전체 경로, 세 모델의 받는 주소를 AGENTS.md 에 적어 줘.
   "최종 모델은 속도 시험 뒤에 정한다"고 함께 적어 줘.

medium-korean은 1.5GB라 받는 데 시간이 걸립니다. 노트북을 전원에 연결하고, 받는 동안 5장의 시험 녹음을 만들어 두세요.

시험 녹음 두 개 만들기

처음부터 긴 강의 녹음으로 시작하지 마세요. 짧은 녹음 두 개로 먼저 합니다. 이 두 개는 나중에 “AI가 없는 말을 지어내지 않는지” 확인하는 데도 씁니다.

휴대폰 녹음 앱(갤럭시 「음성 녹음」 / 아이폰 「음성 메모」)으로 아래 두 문장을 각각 따로 녹음합니다. 10~20초면 됩니다.

녹음 A · 파일 이름 조모임A

다음 주 교육평가 조별 발표를 준비하고 있어. 모일 장소는 아직 정하지 않았어.
발표 자료 초안은 금요일까지 만들자는 제안이 나왔지만, 담당자는 아직 정하지 않았어.

녹음 B · 파일 이름 조모임B

아까 이야기 이어서, 우리 조 인원은 네 명이 아니라 다섯 명으로 정정할게.
장소는 여전히 미정이고, 리허설을 한 번 하면 좋겠다는 아이디어만 나온 상태야.
나중에 확인할 것 — 정리 결과에서 인원은 다섯 명, 장소·담당자는 미정, 금요일 초안과 리허설은 확정이 아니라 제안으로 나와야 합니다. AI가 그럴듯한 담당자나 장소를 채워 넣으면 틀린 것입니다. 8장에서 확인합니다.

녹음을 컴퓨터로 옮기기 · 가장 쉬운 방법

  1. 휴대폰 녹음 앱에서 파일을 공유 → 카카오톡 → 나와의 채팅으로 보냅니다.
  2. 컴퓨터 카카오톡에서 「나와의 채팅」을 열고 파일을 저장합니다. 보통 「다운로드」 폴더에 저장됩니다.
  3. 저장된 파일을 녹음자동처리 안의 inbox 폴더로 끌어다 놓습니다.

아이폰 + Mac이면 음성 메모에서 공유 → AirDrop → 내 Mac으로 보내도 됩니다. 다운로드 폴더에 들어온 파일을 inbox로 옮기세요.

어떤 방법이든 inbox에 파일만 들어가면 그 뒤는 똑같습니다. 휴대폰에서 자동으로 넘어오게 하는 방법은 Part 6(선택)에 있습니다.

손으로 한 번 전사하고, 모델 정하기

자동화를 만들기 전에, whisper.cpp가 내 노트북에서 실제로 되는지 확인합니다. 이때 걸린 시간도 잽니다. 4장에서 고른 모델이 내 노트북에서 너무 느리면 한 단계 낮춥니다.

6장 · 전사 시험과 속도 시험

버튼으로 프롬프트 전체를 복사해 Antigravity 대화 입력란에 붙여넣고 보내세요. 직접 타이핑하지 않습니다.

프롬프트 내용 펼쳐보기 · AI에게 전달할 내용
녹음자동처리 폴더를 기준으로 whisper.cpp 전사 시험을 하고, 이 노트북에서 쓸 모델을 최종으로 정해 줘.

1. inbox 안의 "조모임A", "조모임B" 파일을 ffmpeg로 16kHz, 모노, 16bit wav로 바꿔 줘. (임시 파일은 끝나면 지워 줘.)
2. 속도 시험용으로 조모임A와 조모임B를 이어 붙이고, 1분 안팎이 되도록 반복한 시험 파일을 만들어 줘.
   whisper는 30초 단위로 처리해서, 아주 짧은 녹음으로는 속도를 제대로 잴 수 없어. 시험 파일의 길이(초)를 알려 줘.
3. AGENTS.md 에 적은 1순위 모델로 시험 파일을 전사해 줘. 언어는 -l ko, 스레드(-t)는 이 노트북의 코어 수에 맞게.
4. 전사에 걸린 시간을 재 줘. 녹음 길이의 2배를 넘기면 이 노트북에는 너무 느린 거야.
   그럴 땐 한 단계 낮은 모델(medium-korean → small → base-ko)로 같은 시험을 다시 해 줘.
   2배 안에 들어오는 가장 큰 모델을 최종 모델로 정해. 낮은 모델이 아직 없으면 AGENTS.md 에 적어 둔 주소에서 받아 줘.
5. NVIDIA 그래픽카드가 있는데 medium-korean 이 2배를 넘기면, 그래픽카드를 쓰는 whisper.cpp 실행 파일이 이 노트북에서 되는지 한 번 시험해 보고, 되면 그걸로 다시 재 줘. 안 되면 넘어가.
6. 최종 모델로 조모임A 만 전사해서 notes\수동시험\01_전사원문.md 로 저장해 줘. 한글이 깨지지 않게 UTF-8로.
7. 모델별로 걸린 시간을 표로 보여 주고, 최종 모델과 이유를 쉬운 말로 설명해 줘.
   최종 모델, 걸린 시간 배율(걸린 시간 ÷ 녹음 길이), 스레드 수를 AGENTS.md 에 적어 줘. 자동 처리 프로그램이 이 값을 쓸 거야.

결과 파일을 열어 보세요. 전사가 완벽하지 않아도 괜찮습니다. 글자가 나왔으면 성공입니다. medium-korean이 아니어도 괜찮습니다. 흐름을 끝까지 만드는 게 먼저입니다.

왜 “녹음 길이의 2배”인가요? — 배율이 2배면 75분 강의 녹음을 글로 옮기는 데 약 2시간 반이 걸립니다. 노트북이 켜져 있는 동안 뒤에서 하는 일이라 그 정도는 괜찮지만, 그보다 느리면 녹음이 쌓이기만 합니다. 나중에 노트북을 바꾸거나 더 빠른 결과가 필요하면 “AGENTS.md의 모델을 바꾸고 조모임A로 다시 재 줘”라고 보내면 됩니다.

Part 3 · 자동 처리 · 7장

자동 처리 프로그램 만들기

이제 inbox에 들어온 녹음을 자동으로 처리하는 프로그램을 만듭니다. 이 장이 이 과제의 심장입니다.

「스크립트」가 뭔가요 — 컴퓨터에게 “이거 하고, 저거 하고, 그다음 이거 해”라고 미리 적어 둔 작업 지시서 파일입니다. 직접 쓸 필요 없습니다. 아래 프롬프트를 보내면 AI가 씁니다.

녹음 하나가 처리되면 이런 문서 다섯 개가 생깁니다.

상세 요구사항:

1. 기본 경로
- 루트: 이 프로그램이 있는 녹음자동처리 폴더 (경로를 코드에 박지 말고 파일 위치로 계산)
- 입력: inbox / 결과: notes / 로그: logs
- 맨 위에 설정 칸을 모아 둬: 전사 모델 파일 경로(6장에서 정한 최종 모델), 예비 모델(base-ko) 경로, whisper 스레드 수,
  whisper-cli 경로, ffmpeg 경로, agy 전체 경로, agy가 쓸 모델 이름.
  나중에 모델을 바꿀 때 그 줄 하나만 고치면 되게. 값은 AGENTS.md 에 적어 둔 것을 써.

2. 처리할 확장자: .m4a .mp3 .wav .aac .ogg .opus .flac

3. 오디오 변환 (중요)
- whisper.cpp는 16kHz 모노 wav만 안정적으로 읽는다.
- 그 형식이 아니면 ffmpeg로 16000Hz, 모노, 16bit PCM wav로 바꾼 뒤 전사한다. 임시 wav는 처리 후 지운다.

4. 건너뛸 파일
- 이름이 ~syncthing~ 으로 시작하거나 .tmp 로 끝나는 파일, 숨김 파일
- 수정된 지 60초가 안 된 파일 (아직 복사 중일 수 있음)
- notes\파일이름 폴더가 이미 있는 파일 (이미 처리한 것)

5. 중복 실행 방지
- logs 에 .running.lock 파일을 만들어 동시에 두 번 돌지 않게. 끝나면 지우고, 오류가 나도 반드시 정리.
- lock 파일에는 실행 중인 프로그램 번호(PID)를 적어 둬. 다음 실행 때 그 프로그램이 아직 살아 있으면 이번 실행은 건너뛰고,
  죽어 있으면 남은 lock을 지우고 진행해. (medium-korean 은 긴 강의 녹음에 몇 시간이 걸릴 수 있어서 시간만으로 판단하면 안 돼.)

6. 전사 단계
- whisper.cpp로 한국어 전사. 언어는 반드시 -l ko, 스레드는 설정 칸의 값.
- 최종 모델 파일이 없거나 전사에 실패하면 예비 모델(base-ko)로 한 번 더 시도하고, 그 사실을 로그와 결과 폴더에 남긴다.
- 두 모델 모두 없으면 "모델 파일을 찾을 수 없다"고 분명히 알리고 중단.
- 결과는 notes\파일이름\01_전사원문.md. UTF-8(BOM 없음).

7. agy 가공 단계 — 전사 결과로 아래 4개 파일을 만든다.
- 02_정제본.md: 의미와 순서는 유지하고 말더듬, 의미 없는 반복, "어·음·그" 같은 추임새만 지운 전문. 요약하지 말 것.
- 03_상세정리.md:

  - 맨 위에 "녹음 유형: ..." 으로 표시하고, 그 유형에 맞는 제목과 섹션을 스스로 구성한다. 무조건 회의록 구조로 고정하지 말 것.
  - 결정 사항·담당자·기한은 실제로 나온 경우에만 적는다. 나오지 않은 것을 지어내지 말 것.
  - 이름·숫자·날짜·"~가 아니라 ~로 정정" 같은 표현은 절대 임의로 바꾸지 말 것.
  - 구조 예시 — 강의: 주제/핵심 개념/예시/질문거리 · 조모임: 개요/논의/결정/할 일/다시 정할 것 · 아이디어: 핵심/배경/가능성/걱정/다음에 해 볼 것

Part 4 · 텔레그램 알림 · 10장

텔레그램 봇 만들기

지금은 정리가 끝났는지 폴더를 열어 봐야 압니다. 이제 휴대폰으로 “정리 끝났어요” 알림이 오게 합니다. 가장 재미있는 부분입니다. “봇”은 텔레그램 안에서 자동으로 메시지를 보내 주는 자동 계정입니다. 이 장은 휴대폰에서 직접 합니다.

  1. 휴대폰에 텔레그램(Telegram) 앱이 없으면 설치하고 가입합니다.
  2. 텔레그램 위쪽 돋보기(검색)에서 BotFather를 검색합니다. 파란 체크(공식)가 있는 것을 고릅니다.
  3. 대화를 열고 /newbot 을 보냅니다.
  4. 봇의 표시 이름을 물으면 아무거나 씁니다. 예: 내 녹음 비서
  5. 봇의 사용자명을 물으면 영어·숫자·_로, 반드시 bot으로 끝나게 씁니다. 예: minji_rec_2026_bot (이미 있으면 숫자를 바꾸세요)
  6. 성공하면 BotFather가 축하 메시지를 보냅니다. 두 가지를 챙깁니다. 봇 주소(t.me/... 링크)와 토큰(Use this token to access the HTTP API: 바로 아랫줄의 긴 글자, 예: 8887747616:ABCD...).

토큰은 12장에서 컴퓨터의 메모장에 붙여넣습니다. 휴대폰의 토큰을 컴퓨터로 옮길 때는 컴퓨터 브라우저에서 web.telegram.org에 로그인하세요. BotFather 대화가 그대로 보이니 거기서 토큰 줄을 복사하면 됩니다. 카톡 「나와의 채팅」으로 옮기지 마세요 — 카톡 서버에 남습니다.

토큰은 내 봇의 비밀번호입니다. 새어 나가도 큰일은 안 납니다 — 이 토큰으로 할 수 있는 건 내 봇으로 메시지를 보내고 받는 것뿐입니다. 그래도 카톡·게시판·화면 캡처에 올리지 마세요. 특히 Antigravity 대화창을 캡처하면 토큰이 같이 찍히니, 12장에서는 토큰을 대화창에 넣지 않습니다. 실수로 노출했으면 BotFather에게 /revoke를 보내 새 토큰을 받으세요.
