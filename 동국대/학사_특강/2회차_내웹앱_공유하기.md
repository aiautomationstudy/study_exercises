# 내가 만든 웹앱, 다른 사람과 함께 쓰기

**동국대 AI 특강 · 2회차 실습 뒤 · 기말 프로젝트에도 그대로 씁니다**

지금 만든 앱은 **내 컴퓨터 안에만** 있습니다. 친구가 열 수 있는 **인터넷 주소**를 만들어 봅니다.
아래 방법은 **모두 무료이고 카드 등록이 필요 없습니다.**

## 어떤 방법을 쓸까?

| 하고 싶은 것 | 방법 |
|---|---|
| 만든 앱을 친구에게 링크로 보여 주기 (오늘 만든 앱, 기말 프로젝트 모두) | [① GitHub Pages](#pages) |
| 친구들이 쓴 글이나 답을 모두가 같이 보는 앱 (게시판, 질문함, 투표, 신청서, 선생님이 학생 답을 모아 보는 퀴즈) | [① GitHub Pages](#pages) + [② Firebase 데이터베이스](#firebase) |
| Gemini의 Canvas로 만든 앱 | [③ Canvas 공유 단추](#canvas) |
| 정리한 문서(기획서·회의록·안내서)를 링크로 보여 주기 | [④ 문서도 웹페이지로](#docs) |

**링크만 공유하면, 각자 입력한 내용은 각자 브라우저에만 남습니다.** 오늘 만든 공부 체크 앱이 그렇습니다. 친구가 쓴 내용을 내 화면에서도 보려면 ②가 필요합니다.

<a id="pages"></a>

## ① GitHub Pages — 학기 내내 쓰는 내 앱 주소

- 주소는 `https://내아이디.github.io/앱이름/` 모양입니다. 이 실습 자료도 GitHub Pages로 올렸습니다.
- 무료입니다. 단, 앱 파일이 **누구나 볼 수 있게 공개**됩니다. 실제 이름·연락처·성적은 넣지 않습니다.
- 팀원을 초대해 함께 고칠 수 있고, 고친 기록이 남습니다.

### 꼭 할 것 · 15분

1. [github.com](https://github.com)에서 **Sign up**으로 가입합니다. 아이디가 주소에 들어가니 영문 소문자로 정합니다.
2. 앱 파일이 어디 있는지 확인합니다. Antigravity에 「방금 만든 앱 폴더를 파일 탐색기(Mac은 Finder)에서 열어 줘」라고 보냅니다.
3. GitHub 오른쪽 위 **+** → **New repository**를 누릅니다. **Repository name**에 앱 이름을 영문 소문자·숫자·하이픈(-)으로 씁니다(예: `study-planner`). **Public**을 고르고 **Create repository**를 누릅니다.
4. 새 화면에서 **uploading an existing file**을 누릅니다(안 보이면 **Add file** → **Upload files**). 앱 폴더 **안의 파일을 모두** 선택해 끌어다 놓고, 아래 **Commit changes**를 누릅니다. 폴더째가 아니라 `index.html`이 보이는 그 안의 파일들을 올립니다.
5. 위쪽 **Settings** → 왼쪽 **Pages**를 누릅니다. **Source**는 **Deploy from a branch**, **Branch**는 **main**과 **/(root)**를 고르고 **Save**를 누릅니다.
6. 1~2분 뒤 새로고침하면 위쪽에 **Your site is live at …** 이 나옵니다. **Visit site**를 눌러 열리면 그 주소를 친구에게 보냅니다. 길면 10분까지 걸립니다.

### 고칠 때

Antigravity로 앱을 고친 뒤, GitHub 저장소에서 **Add file** → **Upload files**를 누르고 바뀐 파일을 다시 끌어다 놓은 다음 **Commit changes**를 누릅니다. 이름이 같은 파일은 새 것으로 바뀝니다. 몇 분 뒤 같은 주소에 반영됩니다.

### 기말 프로젝트 팀이라면

- 팀에서 한 명이 저장소를 만들고 **Settings** → **Collaborators** → **Add people**로 팀원의 GitHub 아이디를 초대합니다. 초대를 받은 팀원도 파일을 올릴 수 있습니다.
- 두 사람이 같은 파일을 따로 고쳐 올리면 **나중에 올린 것이 앞의 것을 덮어씁니다.** 누가 언제 올릴지 팀에서 정합니다.

### Antigravity에게 맡겨도 됩니다

처음 한 번은 Git 설치와 GitHub 로그인을 물어봅니다. 그다음부터는 「고친 거 GitHub에도 올려 줘」 한마디면 됩니다.

```text
이 앱 폴더를 내 GitHub에 새 저장소로 올리고, GitHub Pages로 인터넷 주소를 만들어 줘.
저장소 이름은 [study-planner]로 하고, 공개(Public)로 해 줘.
프로그램 설치나 GitHub 로그인처럼 내가 직접 해야 하는 일은 한 단계씩 쉽게 알려 줘.
다 되면 실제 주소를 열어서 앱이 잘 열리는지 확인하고 주소를 알려 줘.
```

<a id="firebase"></a>

## ② Firebase — 여러 사람이 같은 데이터를 쓰는 앱

학과 게시판·질문함·투표·행사 신청처럼 **소통용 웹앱**이나, 선생님이 학생들의 답을 모아 보는 **교수-학습용 앱**에 필요합니다.
Google 계정으로 쓰는 Google의 서비스입니다. **무료 Spark 요금제**에서 데이터베이스(Firestore)와 Google 로그인을 카드 등록 없이 쓸 수 있습니다. 앱 주소는 ①의 GitHub Pages 주소를 그대로 씁니다.

### 꼭 할 것

앱을 만들던 Antigravity 대화에 아래 문장을 보내고, [ ] 부분을 내 앱에 맞게 바꿉니다.

```text
이 앱에서 [친구들이 쓴 글]을 모두가 같이 볼 수 있게 하고 싶어.
Firebase의 무료 Spark 요금제로 Firestore 데이터베이스를 연결해 줘.
결제 수단 등록(Blaze 요금제)이 필요한 기능은 쓰지 마. App Hosting과 Cloud Functions도 쓰지 마.
누가 읽고, 쓰고, 지울 수 있는지 보안 규칙도 정해서 적용해 줘.
내가 Firebase 콘솔(console.firebase.google.com)에서 직접 눌러야 하는 것은 한 단계씩 쉽게 알려 줘.
다 되면 다른 컴퓨터에서도 같은 내용이 보이는지 내가 확인하는 방법을 알려 줘.
```

### 꼭 지킬 것

- **카드를 등록하라는 화면이 나오면 멈춥니다.** 이 수업과 기말 프로젝트는 무료 요금제로 충분합니다. Antigravity에 「Publish my app」이라고만 하면 카드 등록이 필요한 App Hosting으로 진행될 수 있습니다.
- **보안 규칙을 꼭 정합니다.** 규칙 없이 「테스트 모드」로 두면 주소를 아는 사람 누구나 데이터를 지울 수 있습니다.
- 실제 학번·연락처·성적은 넣지 않습니다.
- 무료 사용량을 넘어도 돈이 나가지 않습니다. 그달 남은 기간 동안 그 기능이 멈출 뿐이고, 수업 과제 규모에서는 넘을 일이 거의 없습니다.

<a id="canvas"></a>

## ③ Gemini Canvas로 만든 앱이라면 — 공유 단추 하나

[Gemini](https://gemini.google.com) 입력창 아래 **파일 추가(＋)** → **Canvas**를 고르고 만든 앱은 이렇게 공유합니다.

1. Canvas 오른쪽 위 **공유 및 내보내기** → **공유**를 누릅니다.
2. 링크 옆 **링크 복사**를 누르고 친구에게 보냅니다.

- 링크는 컴퓨터나 휴대폰의 **인터넷 브라우저**(gemini.google.com)에서 열립니다. Gemini 휴대폰 앱에서는 열리지 않습니다.
- 만 18세 이상만 공유할 수 있습니다.
- 여러 사람이 데이터를 함께 쓰는 Canvas 앱이면, 링크를 가진 사람 누구나 그 데이터를 보고 고칠 수 있습니다.
- Antigravity로 만든 앱에는 이 단추가 없습니다. ①을 쓰세요.

<a id="docs"></a>

## ④ 정리한 문서도 웹페이지 링크로 · 조금 더 해 보기

AI에게 문서로 정리해 달라고 하면 보통 `.md` 파일(글 문서)로 줍니다. 메모장에서 열면 `#`·`**` 같은 기호가 보여 남에게 보여 주기 불편합니다.
①의 「Antigravity에게 맡겨도 됩니다」를 한 번 해 두었다면, 한마디만 더 하면 누구나 링크로 여는 웹페이지가 됩니다. 이 수업 자료 목록도 이렇게 만든 페이지입니다.

```text
[이 문서]를 보기 좋은 웹페이지로 만들어서 내 GitHub Pages에 올려 줘.
다 되면 실제 주소를 열어 확인하고 주소를 알려 줘.
```

기말 프로젝트의 기획서·회의록·앱 사용 안내서를 교수님과 팀원에게 링크로 보낼 때 씁니다. GitHub Pages 페이지는 누구나 볼 수 있으니 실제 학번·연락처·성적이 든 문서는 올리지 않습니다.

## 잘 안될 때 참고

- **주소를 열면 404가 나와요:** 5~10분 기다린 뒤 다시 엽니다. 그래도 같으면 저장소 첫 화면에 `index.html`이 바로 보이는지 확인합니다. 폴더 안에 또 폴더가 있으면 그 안의 파일을 올려야 합니다.
- **하얀 화면만 나와요:** 파일을 일부만 올렸을 수 있습니다. 앱 폴더 안의 파일을 모두 다시 올립니다.
- **수업 중에 1분 만에 임시 주소가 필요해요:** [netlify.com/drop](https://app.netlify.com/drop)에 앱 폴더를 끌어다 놓으면 바로 주소가 나옵니다. 가입하지 않으면 1시간 뒤 사라집니다. 오래 둘 앱은 ①로 올립니다.
- 그 밖에 막히면 [막혔을 때 안내](2회차_막혔을때_해결안내.html)의 순서대로 합니다. 하던 AI에게 「GitHub Pages 주소가 404야. 해결해 줘」처럼 막힌 상황을 그대로 말하면 됩니다.
