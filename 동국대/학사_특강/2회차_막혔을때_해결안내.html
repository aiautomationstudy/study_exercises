동국대 AI 특강 · 실습하다 막혔을 때

2회차 웹앱 실습, 녹음 비서 과제, 기말 프로젝트에 모두 쓸 수 있습니다.

먼저 이것만 기억하세요

AI는 거의 다 압니다. AI가 모르는 건 딱 두 가지입니다.

  1. 내가 지금 무엇을 하려는지
  2. 어디서, 어떻게 막혔는지

이 두 가지만 알려 주면 대부분 해결됩니다. 오류의 뜻을 몰라도 됩니다. 친구에게 묻듯 편하게 말해도 됩니다.

이 순서로 해 보세요

1. 하던 Antigravity 대화에 해결을 맡깁니다

막힌 그 대화에 아래 문장을 붙여넣고, [ ] 부분을 내 상황으로 바꿔 보냅니다. 화면에 빨간 오류 글씨가 있으면 통째로 복사해 맨 아래에 붙입니다.

나 지금 [조별 과제 역할표 앱을 만드는] 중이야.
그런데 [추가 버튼을 눌러도 아무것도 안 생겨].
네가 확인하고 고칠 수 있는 건 직접 해결해 줘.
내가 꼭 해야 하는 게 있으면 쉬운 말로 한 단계씩 알려 줘.
다 고치면 실제로 되는지 확인하고 알려 줘.

대부분 여기서 풀립니다. 이 문장이 아니어도 됩니다. 「이거 안 돼. 네가 해결해 줘」처럼 짧게 말하고 막힌 상황만 덧붙여도 됩니다.

2. 같은 실패가 두 번이면 ChatGPT나 Gemini에 물어봅니다

chatgpt.com 또는 gemini.google.com을 열고 아래 문장을 붙여넣습니다. 그 아래에 실습 안내서 주소, 막힌 상황, Antigravity가 한 말을 붙입니다.

코딩 에이전트 Antigravity로 [무엇]을 하다가 막혔어. 나는 컴퓨터를 잘 몰라.
아래에 실습 안내서 주소, 막힌 상황, Antigravity가 한 말을 붙일게.
다음에 할 일을 쉬운 말로 하나씩 알려 줘.
Antigravity에 그대로 붙여넣을 해결 문장도 만들어 줘.
내 화면을 보지 않고 원인을 단정하지는 마.
  • 안내서 주소 복사: 안내서가 열린 창 맨 위 주소창을 한 번 누르고 Ctrl + C(Mac은 Command + C)를 누릅니다.
  • 오류 화면 붙이기: Windows는 Windows 키 + Shift + S, Mac은 Command + Control + Shift + 4를 누르고 필요한 부분을 드래그합니다. 대화 입력창에서 Ctrl + V(Mac은 Command + V)로 붙여넣습니다.
  • ChatGPT·Gemini는 방법을 알려 주는 곳입니다. 내 컴퓨터의 파일을 고치는 것은 Antigravity입니다. 받은 해결 문장을 Antigravity의 하던 대화에 붙여넣으세요.

3. 먼저 해 본 친구에게 물어봅니다

「여기까지 했는데 이 화면 좀 봐 줄래?」
옆 친구가 먼저 겪어 본 일일 수 있습니다. 친구가 Antigravity에 보낸 문장을 알려 달라고 해서 내 대화에 그대로 써 봐도 됩니다.

4. 그래도 안 되면

수업 시간에는 손을 듭니다. 수업 밖에서는 아래 네 줄을 채워 교수님께 여쭙니다.

막힌 단계:
화면에 나온 말(그대로 복사):

사용 한도를 다 썼다고 나와요

결제하지 마세요. 사용 한도 안내를 봅니다. 기다리는 동안 Gemini 입력창 아래 파일 추가(＋) → Canvas를 고르고 같은 말을 보내면, Gemini 화면 안에서 앱을 만들어 볼 수 있습니다.

녹음 비서 과제에서 막혔어요

과제를 하던 Antigravity 대화에 위 1번 문장을 보냅니다. 녹음 비서 과제 안내의 주소와 막힌 장(예: 「6장 전사 시험에서」)을 함께 붙입니다.

하지 말 것

  • 비밀번호·인증번호를 AI 대화에 붙이지 않습니다. 로그인과 본인 확인은 직접 합니다.
  • 백신이나 Windows 보안을 끄라는 안내는 따르지 않습니다. 그런 말이 나오면 2번이나 4번으로 갑니다.
  • 한도 추가 결제 단추를 누르지 않습니다.
