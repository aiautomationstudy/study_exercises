AI와 함께 내 웹앱 만들기

요청문도 AI에게 작성하게 합니다. 내가 바라는 결과를 정하고, 만든 앱은 내 손으로 확인합니다.

오늘 끝낼 일
  1. 평소 쓰는 Gemini·ChatGPT·Claude에 Antigravity용 요청문을 작성하게 합니다.
  2. 그 요청문을 Antigravity에 보내 작은 웹앱을 만듭니다.
  3. 직접 눌러 확인하고, 수정하거나 조건을 한 번 바꿉니다.

Antigravity에서 지난번 실습 프로젝트(Dongguk Practice)를 엽니다. 이번 파일은 그 안의 webapp-session2 폴더에 만듭니다. 이전 실습은 그대로 둡니다.

녹음 비서 과제도 해 보았다면 된 것 또는 막힌 곳 하나를 준비하세요.

1. 내 앱 정하기 · 5분

기본 예시는 이번 주 학습 진도 체크 앱입니다. 내 과목이나 다른 작은 불편으로 바꿔도 됩니다. 오늘은 중요한 기능 하나가 작동하면 충분합니다.

아래 네 칸을 내 상황에 맞게 고치세요. 예: 실습 준비물 체크, 독서 계획 체크, 시험 공부 진도 체크. 실제 학생 명단·성적·상담 기록은 넣지 않습니다.

입력한 내용은 이 페이지에서만 요청문에 넣습니다. 이 안내서는 입력 내용을 서버에 보내거나 저장하지 않습니다.

2. 요청문 작성을 AI에게 맡기기

보낼 곳: 평소 쓰는 Gemini·ChatGPT·Claude의 일반 대화창 중 하나.

아래 버튼을 누르면 위의 네 칸이 반영됩니다. AI가 답한 Antigravity용 요청문 전체를 다음 단계에서 사용합니다.

Antigravity가 아래 웹앱을 만들고 실행할 프롬프트를 작성해 줘.
나는 코딩을 모르는 대학생이야. Antigravity에 그대로 붙여넣을 요청문만 답해 줘.

누가 쓸지: 교육학과 대학생인 나
해결할 불편: 이번 주 공부할 일과 끝낸 일을 자꾸 잊는다.
핵심 기능: 할 일을 추가하고, 완료 표시를 했다가 취소한다.
확인 기준:
1. 할 일을 추가하면 목록에 정확히 나타난다.
2. 빈칸이나 공백만 넣으면 추가하지 않고 이유를 알려 준다.
3. 완료 표시와 취소가 모두 되고, 새로고침해도 내 목록과 표시가 남는다.

범위는 내 컴퓨터에서 먼저 써 보는 작은 웹앱이야.
기존 Antigravity 실습 프로젝트 안의 webapp-session2 폴더에 만들어야 해. 다른 실습 파일은 그대로 둬.
유료 서비스, 외부 AI 연결, 로그인, 공개 배포 없이 작동하도록 해 줘.
계획만 설명하지 않고 실제 파일을 만들고, 실행 방법과 확인 결과를 알려 주게 써 줘.

답을 읽고 내 기능·확인 기준이 들어 있는지 봅니다. 로그인이나 결제 같은 일이 추가됐으면 아래 문장으로 줄입니다.

AI가 너무 큰 앱을 제안했을 때

방금 작성한 프롬프트에서 내가 바라는 기능과 확인 기준은 그대로 두고, 처음 만드는 사람이 실행하기 쉽게 더 짧게 정리해 줘.
로그인·결제·외부 AI 연결·공개 배포는 이번 실습에서 빼 줘. Antigravity에 붙여넣을 요청문만 답해 줘.

3. Antigravity에서 만들기 · 제작 시간 18분 안에

  1. Antigravity의 기존 실습 프로젝트에서 새 대화를 엽니다.
  2. 앞 단계에서 AI가 답한 요청문을 그대로 붙여넣습니다. 처음 보낸 ‘요청문 작성 부탁’ 문장을 다시 보내는 단계가 아닙니다.
  3. 계획을 읽고 내 의도와 맞으면 진행합니다. 원하지 않는 삭제·공개·결제 요청이 나오면 멈추고 손을 듭니다.
  4. 완료하면 AI가 알려 준 미리보기 주소나 파일을 열어 앱을 확인합니다. 주소가 없으면 ‘내가 어디를 열면 되는지, 직접 실행할 수 있게 준비해 줘’라고 합니다.

앱을 만드는 동안 다음 단계의 확인 표를 읽고 예상 결과부터 생각하세요.

요청문 작성용 AI를 쓸 수 없을 때 · AI가 작성한 실행 예시

내 조건을 고친 뒤 Antigravity에 보내세요. 이 예시는 요청문을 만드는 과정을 건너뛸 때 쓰는 대안입니다.

이번 주 공부할 일과 완료 상태를 관리하는 작은 웹앱을 만들어 줘.
기존 실습 프로젝트 안에 webapp-session2 폴더를 만들고 그 안에서만 작업해. 다른 파일은 고치지 마.
사용자는 교육학과 대학생인 나야. 화면은 한국어로 만들고 컴퓨터와 휴대폰에서 읽기 쉽게 해 줘.
할 일 추가, 완료 표시와 취소, 내 브라우저에 목록과 완료 상태 저장이 필요해.
확인 기준은 다음과 같아.
1. 할 일을 추가하면 목록에 입력한 내용이 정확히 나타난다.
2. 빈칸이나 공백만 넣으면 추가하지 않고 이유를 알려 준다.
3. 완료 표시와 취소가 모두 되고, 새로고침해도 목록과 표시가 남는다.
외부 AI 연결, 유료 서비스, 로그인, 공개 배포 없이 내 컴퓨터에서 실행하는 작은 앱으로 만들어.
계획 설명에 그치지 말고 실제 파일을 만들어. index.html 하나로 작동하면 충분해.
직접 실행할 수 있게 필요한 미리보기를 준비하고, 내가 열 주소나 파일을 알려 줘.
웹 확인에 Aside가 필요하면 기존 연결을 사용해. 연결 문제로 만들기까지 멈추지 말고 파일을 먼저 완성해.
위 기준으로 실제 확인한 결과와 확인하지 못한 것을 나눠 알려 줘. 마지막에는 내가 눌러 볼 순서를 짧게 적어 줘.

4. 내 손으로 확인하고 고치기 · 12분

AI가 시험했다고 답했어도 직접 누릅니다. 아래는 기본 앱의 확인 기준입니다. 다른 주제면 같은 방식으로 내 기능을 확인하세요.

내가 할 행동기대 결과
‘형성평가 개념 복습’ 입력 후 추가그 문장이 목록에 나타남
빈칸 또는 공백만 넣고 추가목록은 그대로, 입력 안내 표시
완료 체크 후 다시 취소상태와 완료 개수가 바뀌고 돌아옴
한 항목을 체크하고 새로고침목록과 완료 상태 유지

실패했으면: 한 행동·기대 결과·실제 결과를 자기 앱에 맞게 써서 Antigravity의 같은 대화에 보냅니다.

수정 요청 예시 · 실제로 이 문제가 있을 때 사용

내 앱에서 한 가지를 고쳐 줘.
한 행동: 아무것도 입력하지 않고 추가를 눌렀다.
기대 결과: 목록은 그대로이고, 할 일을 입력하라는 안내가 나온다.
실제 결과: 빈 할 일이 목록에 생겼다.
이 차이만 고치고, 할 일 추가와 완료 표시·취소가 여전히 되는지 다시 확인해 줘.
기존 목록과 다른 파일은 그대로 두고, 바꾼 것과 실제 확인 결과를 알려 줘.

모두 됐으면: 제목을 내 과목으로 바꾸거나 문구 하나를 바꾸게 하고, 원래 기능이 여전히 되는지 다시 확인합니다. 예: ‘완료’를 ‘복습 끝’으로 바꾸기.

할 일은 내 브라우저에 저장합니다. 다른 기기와 공유되지 않습니다. 브라우저 데이터를 지우면 사라질 수 있으므로 실습에는 가상 자료를 쓰세요.

5. 확인한 것을 지침으로 남기기

보낼 곳: Antigravity의 지금 대화. 실제로 확인한 기준에 맞게 아래 문장을 고쳐 보냅니다.

이번 웹앱에서 내가 직접 확인한 기준을 다음 대화에도 남기고 싶어.
webapp-session2/AGENTS.md에 아래 프로젝트 지침을 추가해 줘. 기존 내용이 있으면 그대로 두고 추가한 부분을 보여 줘.
지침: 이 앱을 수정할 때 빈칸·공백만 있는 할 일은 추가되지 않게 유지한다. 할 일 추가, 완료 표시·취소, 새로고침 뒤 저장 상태를 직접 시험하고, 확인하지 못한 것은 구분해 알린다.
근거: 내가 이 동작을 앱에서 직접 확인했고, 다음 수정에서도 유지해야 한다.

추가한 지침을 보고, 새 대화에서 아래 작은 수정을 맡깁니다. 지침을 읽었다는 말과 실제로 지킨 결과를 구분합니다. 시간이 부족하면 수업 뒤 이어 하세요.

webapp-session2/AGENTS.md와 앱 파일을 먼저 읽어 줘.
이 앱의 제목을 ‘나의 교육학 공부 계획’으로 바꿔 줘. 다른 기능과 기존 목록은 그대로 둬.
프로젝트 지침에 적힌 확인 기준으로 다시 시험하고, 실제 결과와 확인하지 못한 것을 알려 줘.

마지막 기록: 내 앱의 목적 / 직접 확인한 결과 / 실패 또는 바꾼 조건 / 남긴 지침. 제출 장소와 성적 반영은 교수님의 안내를 따릅니다.

잘 안될 때 참고

만들기가 안 되거나 AI가 계획만 말할 때

계획은 확인했어. 이번에는 webapp-session2 폴더에 실제 파일을 만들고, 내 컴퓨터에서 열어 볼 수 있게 진행해 줘.
진행을 막는 문제가 있으면 무엇인지와 지금 가능한 대안을 짧게 알려 줘. 한도를 다 썼다면 재시도하지 말고 알려 줘.

같은 오류가 두 번 나거나 사용 한도가 끝났으면 재시도를 반복하지 말고 손을 드세요.

Aside 연결·설치·로그인 문제

앱 파일은 먼저 만들고, 확인이 안 된 부분을 구분해 달라고 합니다. Windows에서는 Antigravity를 완전히 종료한 뒤 다시 열어 보세요. 계속 안 되면 기존 사전준비 안내의 해결 방법을 봅니다. 보안을 끄거나 서명 검사를 건너뛰지 않습니다.

Aside가 file:// 주소를 열지 못하면 Antigravity에 ‘앱 파일은 그대로 두고, 브라우저에서 열 수 있는 로컬 미리보기 주소를 준비해 줘’라고 합니다. 권한을 무조건 넓히거나 재설치하지 않습니다.

녹음 과제에서 막힌 곳대처
ffmpeg·whisper 없음과제를 진행하던 AI에게 설치 여부를 확인하고, 빠진 도구를 설치한 뒤 짧은 녹음으로 시험하게 합니다. 이번 웹앱에는 설치하지 않아도 됩니다.
휴대폰 녹음 파일 이동·동기화파일 하나를 노트북으로 직접 옮겨 먼저 시험합니다. 자동 동기화는 그 뒤에 확인합니다.
Notion 권한연결이 필요한 과제일 때만, 본인이 사용할 페이지의 연결 권한을 확인합니다. 이번 웹앱에는 Notion이 필요 없습니다.
Windows 한글 계정 경로실습용 폴더만 단순한 경로로 준비하게 하고, 계정 이름·기존 파일은 그대로 둡니다.

실습에서는 ffmpeg·whisper·Notion·휴대폰 동기화가 필요하지 않습니다. 이 도구나 동기화에서 막힌 녹음 과제는 과제 안내의 해당 단계와 오류를 보여 주세요. Windows 계정 이름에 한글이 있어 경로 오류가 나면 AI에게 ‘한글 경로 문제인지 확인하고, 이번 실습용 폴더만 단순한 경로에 준비해 줘. 내 계정 이름과 기존 파일은 그대로 둬’라고 합니다.

로그인·본인 확인·로봇 확인은 직접 합니다. 비밀번호·인증 코드를 AI 대화에 붙이지 않습니다.

사용 한도 또는 장비 문제로 제작을 못 할 때

학습 진도 완성 예시 열기

예시를 직접 누르며 확인 표를 실행하고, 내 주제로 바꿀 조건과 수정 요청을 작성합니다. 예시 확인에 참여한 것과 내 앱 제작 완료는 구분해 기록하세요.

저장되지 않거나 앱 화면이 하얗게 나올 때

기대 결과·실제 화면·오류 문구를 Antigravity에 알려 고치게 합니다. 저장이 안 되면 ‘현재 브라우저에서 저장 가능한지 확인하고, 안 되면 저장이 안 됨을 화면에 알려 줘’라고 합니다. AI가 준 주소가 닫혔으면 미리보기를 다시 실행하게 합니다. 전체 프로젝트를 지우거나 처음부터 재설치하지 않습니다.
