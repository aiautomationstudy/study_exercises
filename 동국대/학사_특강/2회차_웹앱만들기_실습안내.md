# 동국대 AI 특강 2회차 · AI와 함께 내 웹앱 만들기

10월 15일, 개인 실습. [실습 페이지](https://aiautomationstudy.github.io/study_exercises/동국대/학사_특강/2회차_웹앱만들기_실습안내.html)에서 내 조건을 넣고 요청문을 복사할 수 있습니다.

## 오늘 할 일

1. 평소 쓰는 Gemini·ChatGPT·Claude에게 Antigravity용 요청문을 작성하게 합니다.
2. 그 요청문을 Antigravity에 보내 작은 웹앱을 만듭니다.
3. 직접 눌러 확인하고, 수정하거나 조건을 한 번 바꿉니다.

## 시작 전

1회차 라운드 1~3의 결과를 준비합니다. 끝내지 못했으면 지금까지 한 화면과 막힌 지점이면 됩니다.
조사 결과·직접 대조한 출처, 퀴즈 화면·시험 결과, 남긴 지침·새 대화 결과를 구분합니다.
녹음 비서 과제도 해 보았다면 된 것 또는 막힌 곳 하나를 준비합니다.

Antigravity에서 기존 Dongguk Practice 프로젝트를 엽니다. 새 파일은 `webapp-session2` 폴더에 만들고 이전 실습은 그대로 둡니다.

## 1. 내 앱 정하기 · 5분

기본 예시는 이번 주 학습 진도 체크 앱입니다. 내 과목이나 작은 불편으로 바꿔도 됩니다.
누가 쓸지, 해결할 불편, 핵심 기능, 직접 확인할 기준을 정합니다.
실제 학생 명단·성적·상담 기록을 쓰지 않습니다.

## 2. 요청문 작성을 AI에게 맡기기

보낼 곳: **평소 쓰는 Gemini·ChatGPT·Claude의 일반 대화창 중 하나**.
아래는 기본 예시입니다. 내 조건을 바꾸거나 실습 페이지의 네 칸을 사용하세요.

```text
Antigravity가 아래 웹앱을 만들고 실행할 프롬프트를 작성해 줘.
나는 코딩을 모르는 대학생이야. Antigravity에 그대로 붙여넣을 요청문만 답해 줘.

누가 쓸지: 교육학과 대학생인 나
해결할 불편: 이번 주 공부할 일과 끝낸 일을 자꾸 잊는다.
핵심 기능: 할 일을 추가하고, 완료 표시를 했다가 취소한다.
확인 기준:
1. 할 일을 추가하면 목록에 정확히 나타난다.
2. 빈칸이나 공백만 넣으면 추가하지 않고 이유를 알려 준다.
3. 완료 표시와 취소가 모두 되고, 새로고침해도 내 목록과 표시가 남는다.

범위는 내 컴퓨터에서 먼저 써 보는 작은 웹앱이야.
기존 Antigravity 실습 프로젝트 안의 webapp-session2 폴더에 만들어야 해. 다른 실습 파일은 그대로 둬.
유료 서비스, 외부 AI 연결, 로그인, 공개 배포 없이 작동하도록 해 줘.
계획만 설명하지 않고 실제 파일을 만들고, 실행 방법과 확인 결과를 알려 주게 써 줘.
```

AI가 답한 **Antigravity용 요청문 전체**를 다음 단계에서 사용합니다.
내 기능과 확인 기준이 들어 있는지 봅니다. 요청문이 너무 커지면 같은 AI에게 아래처럼 줄이게 합니다.

```text
방금 작성한 프롬프트에서 내가 바라는 기능과 확인 기준은 그대로 두고, 처음 만드는 사람이 실행하기 쉽게 더 짧게 정리해 줘.
로그인·결제·외부 AI 연결·공개 배포는 이번 실습에서 빼 줘. Antigravity에 붙여넣을 요청문만 답해 줘.
```

## 3. Antigravity에서 만들기 · 제작 시간 18분 안에

1. 기존 실습 프로젝트에서 새 대화를 엽니다.
2. 앞 단계에서 AI가 답한 요청문을 붙여넣습니다. 처음 보낸 ‘요청문 작성 부탁’을 다시 보내는 단계가 아닙니다.
3. 내 의도와 맞으면 진행합니다. 원하지 않는 삭제·공개·결제는 멈추고 손을 듭니다.
4. AI가 알려 준 미리보기 주소나 파일을 엽니다. 실행 안내가 없으면 직접 준비해 달라고 합니다.

기다리는 동안 다음 표에서 기대 결과를 먼저 생각합니다.

## 4. 내 손으로 확인하고 고치기 · 12분

| 내 행동 | 기대 결과 |
|---|---|
| ‘형성평가 개념 복습’ 입력 후 추가 | 그 문장이 목록에 나타남 |
| 빈칸 또는 공백만 넣고 추가 | 목록 유지, 입력 안내 표시 |
| 완료 체크 후 취소 | 상태와 완료 개수가 바뀌고 돌아옴 |
| 한 항목을 체크하고 새로고침 | 목록과 완료 상태 유지 |

실패했으면 같은 대화에 **한 행동·기대 결과·실제 결과**를 써 보냅니다. 아래는 실제로 빈 할 일이 생겼을 때의 예시입니다.

```text
내 앱에서 한 가지를 고쳐 줘.
한 행동: 아무것도 입력하지 않고 추가를 눌렀다.
기대 결과: 목록은 그대로이고, 할 일을 입력하라는 안내가 나온다.
실제 결과: 빈 할 일이 목록에 생겼다.
이 차이만 고치고, 할 일 추가와 완료 표시·취소가 여전히 되는지 다시 확인해 줘.
기존 목록과 다른 파일은 그대로 두고, 바꾼 것과 실제 확인 결과를 알려 줘.
```

모두 됐으면 제목이나 문구를 내 주제로 바꾸게 한 뒤 원래 기능을 다시 확인합니다.
목록은 내 브라우저에 저장합니다. 다른 기기와 공유되지 않고, 브라우저 데이터를 지우면 사라질 수 있습니다.

## 5. 지침 남기기와 새 대화 확인

직접 확인한 기준에 맞게 아래를 고쳐 Antigravity의 지금 대화에 보냅니다.

```text
이번 웹앱에서 내가 직접 확인한 기준을 다음 대화에도 남기고 싶어.
webapp-session2/AGENTS.md에 아래 프로젝트 지침을 추가해 줘. 기존 내용이 있으면 그대로 두고 추가한 부분을 보여 줘.
지침: 이 앱을 수정할 때 빈칸·공백만 있는 할 일은 추가되지 않게 유지한다. 할 일 추가, 완료 표시·취소, 새로고침 뒤 저장 상태를 직접 시험하고, 확인하지 못한 것은 구분해 알린다.
근거: 내가 이 동작을 앱에서 직접 확인했고, 다음 수정에서도 유지해야 한다.
```

추가한 지침을 보고 새 대화에서 작은 수정을 맡깁니다. 시간이 부족하면 수업 뒤 이어 합니다.

```text
webapp-session2/AGENTS.md와 앱 파일을 먼저 읽어 줘.
이 앱의 제목을 ‘나의 교육학 공부 계획’으로 바꿔 줘. 다른 기능과 기존 목록은 그대로 둬.
프로젝트 지침에 적힌 확인 기준으로 다시 시험하고, 실제 결과와 확인하지 못한 것을 알려 줘.
```

마지막 기록: 내 앱의 목적 / 직접 확인한 결과 / 실패 또는 바꾼 조건 / 남긴 지침.
제출 장소와 성적 반영은 교수님의 안내를 따릅니다.

## 잘 안될 때 참고

| 녹음 과제에서 막힌 곳 | 대처 |
|---|---|
| ffmpeg·whisper 없음 | 과제를 진행하던 AI에게 빠진 도구를 확인·설치하고 짧은 녹음으로 시험하게 합니다. 이번 웹앱에는 필요 없습니다. |
| 휴대폰 녹음 파일 이동·동기화 | 파일 하나를 노트북으로 직접 옮겨 시험한 뒤 자동 동기화를 확인합니다. |
| Notion 권한 | 연결이 필요한 과제일 때만 사용할 페이지의 연결 권한을 확인합니다. 이번 웹앱에는 필요 없습니다. |
| Windows 한글 계정 경로 | 실습용 폴더만 단순한 경로로 준비하고 계정 이름·기존 파일은 그대로 둡니다. |

- **계획만 말함:** 다음 문장을 같은 Antigravity 대화에 보냅니다.

```text
계획은 확인했어. 이번에는 webapp-session2 폴더에 실제 파일을 만들고, 내 컴퓨터에서 열어 볼 수 있게 진행해 줘.
진행을 막는 문제가 있으면 무엇인지와 지금 가능한 대안을 짧게 알려 줘. 한도를 다 썼다면 재시도하지 말고 알려 줘.
```

- **Aside 연결:** 파일부터 만들고 미확인 항목은 구분하게 합니다. Windows에서는 Antigravity를 완전히 종료 후 다시 엽니다. 계속 안 되면 [사전준비 안내](03_학생_사전준비안내.html)를 봅니다. 서명 검사나 컴퓨터 보안을 끄지 않습니다.
- **Aside가 `file://` 주소를 못 엶:** Antigravity에 앱 파일은 그대로 두고 브라우저에서 열 수 있는 로컬 미리보기 주소를 준비하게 합니다. 권한을 무조건 넓히거나 재설치하지 않습니다.
- **한글 Windows 계정 경로:** AI에게 한글 경로 문제인지 확인하고 실습용 폴더만 단순한 경로로 준비하게 합니다. 계정 이름·기존 파일은 그대로 둡니다.
- **ffmpeg·whisper·휴대폰 동기화·Notion:** 이번 웹앱에는 필요 없습니다. 녹음 과제에서 막혔다면 [녹음 비서 과제](04_과제안내_녹음비서.html)의 해당 단계와 오류를 보여 주세요.
- **로그인·본인 확인·로봇 확인:** 직접 합니다. 비밀번호·인증 코드를 AI 대화에 붙이지 않습니다.
- **같은 오류 두 번·사용 한도:** 재시도를 반복하지 말고 손을 듭니다.
- **저장이 안 되거나 하얀 화면:** 기대 결과·실제 화면·오류를 AI에게 알려 고치게 합니다. 저장을 쓸 수 없으면 그 사실을 화면에 안내하게 합니다. 미리보기 주소가 닫혔으면 다시 실행하게 합니다.
- **제작을 못 함:** [완성 예시](2회차_학습진도_완성예시.html)를 시험하고 내 수정 요구를 적습니다. 예시 확인 참여와 내 앱 제작 완료는 구분합니다.

### 요청문 작성용 AI가 안 될 때 · AI가 작성한 실행 예시

내 조건을 고친 뒤 Antigravity에 보냅니다.

```text
이번 주 공부할 일과 완료 상태를 관리하는 작은 웹앱을 만들어 줘.
기존 실습 프로젝트 안에 webapp-session2 폴더를 만들고 그 안에서만 작업해. 다른 파일은 고치지 마.
사용자는 교육학과 대학생인 나야. 화면은 한국어로 만들고 컴퓨터와 휴대폰에서 읽기 쉽게 해 줘.
할 일 추가, 완료 표시와 취소, 내 브라우저에 목록과 완료 상태 저장이 필요해.
확인 기준은 다음과 같아.
1. 할 일을 추가하면 목록에 입력한 내용이 정확히 나타난다.
2. 빈칸이나 공백만 넣으면 추가하지 않고 이유를 알려 준다.
3. 완료 표시와 취소가 모두 되고, 새로고침해도 목록과 표시가 남는다.
외부 AI 연결, 유료 서비스, 로그인, 공개 배포 없이 내 컴퓨터에서 실행하는 작은 앱으로 만들어.
계획 설명에 그치지 말고 실제 파일을 만들어. index.html 하나로 작동하면 충분해.
직접 실행할 수 있게 필요한 미리보기를 준비하고, 내가 열 주소나 파일을 알려 줘.
웹 확인에 Aside가 필요하면 기존 연결을 사용해. 연결 문제로 만들기까지 멈추지 말고 파일을 먼저 완성해.
위 기준으로 실제 확인한 결과와 확인하지 못한 것을 나눠 알려 줘. 마지막에는 내가 눌러 볼 순서를 짧게 적어 줘.
```
