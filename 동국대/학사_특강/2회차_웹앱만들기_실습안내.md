# 동국대 AI 특강 2회차 · 말하면 만들어 주는 내 웹앱

**10월 15일 실습 안내**

오늘 기억할 한 문장: **필요한 것을 말하면, 코딩 에이전트가 만들어 줍니다.**
코드를 몰라도, 어려운 용어를 몰라도, 멋진 문장이 아니어도 됩니다. 친구에게 카톡 보내듯 편하게 말하세요.

## 꼭 할 것

1. **만들고 싶은 것 한 가지를 정합니다.** 공부·과제·교육봉사·과외에서 귀찮았던 일이면 됩니다. 떠오르지 않으면 [아래 예시](#ideas)에서 고르세요.
2. **Antigravity를 열고, Dongguk Practice 프로젝트에서 새 대화를 시작합니다.**
3. **만들고 싶은 것을 편하게 써서 보냅니다.** 끝에 「새 폴더 만들어서 거기에 만들어 줘」를 붙이면 지난주 실습 파일과 섞이지 않습니다.
4. **보내 놓고 강의를 들으세요.** 컴퓨터마다 몇 분에서 십몇 분 걸릴 수 있습니다. 오래 걸려도 정상입니다.
5. **가끔 내 화면을 봅니다.** 질문이나 허락 창이 떠 있으면 답해야 다음으로 넘어갑니다. 멈춘 것 같으면 「지금 뭐 하고 있어?」라고 물어보고, 그래도 그대로면 손을 듭니다.
6. **다 되면 열어서 직접 눌러 봅니다.** 여는 방법을 모르면 「다 만들었으면 내 브라우저에서 열어 줘」라고 보냅니다.
7. **마음에 안 드는 곳을 말로 고칩니다.** 한 번에 하나씩, 두세 번 해 봅니다. 고쳐 달라고 보낸 뒤에도 기다리는 동안 강의를 들으면 됩니다.

### 강사가 보낸 말 그대로

강사가 수업 전날 Antigravity에 실제로 보낸 말입니다. 4분이 안 돼 시험 공부 체크 앱이 만들어졌습니다. [그 앱 열어 보기](2회차_학습진도_완성예시.html)

```text
시험 기간만 되면 뭘 공부했는지 자꾸 까먹어. 과목이랑 공부할 거 적어 두고, 다 하면 체크하는 앱 하나 만들어 줘. 시험까지 며칠 남았는지도 보였으면 좋겠어. 새 폴더 만들어서 거기에 만들어 줘.
```

그대로 보내도 되고, 내 상황에 맞게 바꿔도 됩니다. 같은 말을 보내도 AI는 매번 조금씩 다르게 만듭니다. 내 앱이 강사 앱과 달라도 정상입니다.

### 이렇게 말하면 됩니다

| 이럴 때 | 이렇게 말해 보세요 |
|---|---|
| 다 됐다는데 어디 있는지 모를 때 | 어디에 만들었어? 내 브라우저에서 열어 줘 |
| 버튼이나 글씨가 불편할 때 | 버튼이 너무 작아. 폰에서도 누르기 편하게 해 줘 |
| 눌렀는데 아무 일도 없을 때 | 추가 눌렀는데 아무것도 안 생겨. 고쳐 줘 |
| 무슨 일인지 궁금할 때 | 방금 뭐 한 거야? 쉽게 설명해 줘 |
| 오래 걸릴 때 | 왜 오래 걸려? 몇 분 더 걸릴 것 같아? |
| 계획만 보여 주고 멈췄을 때 | 좋아, 그대로 만들어 줘 |
| 기능을 더하고 싶을 때 | 다 한 건 아래로 내려가게 해 줘 |

### 길고 꼼꼼한 프롬프트가 필요하면

보통은 위처럼 한두 마디면 충분합니다. 지난주 안내서처럼 길고 꼼꼼한 프롬프트가 필요하면, ChatGPT·Claude·Gemini에 아래처럼 보내고 AI가 써 준 프롬프트를 Antigravity에 붙여넣습니다. 이 수업의 안내서도 모두 이렇게 만들었습니다.

```text
[학과 친구들이 시험 공부 계획을 같이 볼 수 있는 앱을 만들고 싶어.]
Antigravity에서 실행할 프롬프트 만들어 줘.
```

### 무엇을 만들까? 예시

| 만들 것 | 이렇게 말해 보세요 |
|---|---|
| 개념 카드 퀴즈 | 교육학 개념이랑 뜻을 넣으면 퀴즈로 내 주고, 틀린 건 다시 나오게 해 줘 |
| 조별 과제 역할표 | 조원 이름이랑 맡은 일, 마감일을 적으면 누가 뭘 하는지 한눈에 보이게 해 줘 |
| 발표 순서 뽑기 | 이름을 넣으면 발표 순서를 랜덤으로 뽑아서 크게 보여 줘 |
| 독서 기록장 | 읽은 책이랑 한 줄 느낌을 적고 별점 매기는 앱 만들어 줘 |
| 칭찬 스티커판 | 교육봉사 아이들 이름을 넣고, 칭찬할 때마다 스티커를 붙이는 판 만들어 줘 |

기말 프로젝트에서 생각해 둔 주제가 있으면, 그중 작은 조각 하나를 오늘 먼저 만들어 봐도 좋습니다.

## 막혔을 때 · 이 순서로

**AI가 모르는 건 딱 두 가지입니다. 내가 지금 무엇을 하려는지, 어디서 어떻게 막혔는지.**
이 두 가지만 알려 주면 대부분 해결됩니다. 화면에 빨간 오류 글씨가 보이면 통째로 복사해서 같이 붙여넣습니다. 뜻은 몰라도 됩니다.

1. **하던 Antigravity 대화에 말합니다.** 예: 「조별 과제 앱 만드는 중인데, 추가 버튼을 눌러도 아무것도 안 생겨. 네가 해결해 줘.」
2. **같은 실패가 두 번 나오면 ChatGPT나 Gemini에 물어봅니다.** 이 안내서 주소, 막힌 상황, Antigravity가 한 말을 함께 붙입니다.
3. **먼저 해 본 친구에게 물어봅니다.** 「여기까지 했는데 이 화면 좀 봐 줄래?」
4. **그래도 안 되면 손을 듭니다.** 수업 밖이면 교수님께 여쭤봅니다.

그대로 복사해 쓸 문장은 [막혔을 때 안내](2회차_막혔을때_해결안내.html)에 있습니다.

## 잘 안될 때 참고

- **Antigravity 사용 한도를 다 썼다고 나오면:** 결제하지 마세요. [사용 한도 안내](06_Antigravity_사용한도_안내.html)를 봅니다. 그동안 [Gemini](https://gemini.google.com) 입력창 아래 **파일 추가(＋)** → **Canvas**를 고르고 같은 말을 보내면, Gemini 화면 안에서 앱을 만들어 볼 수 있습니다. Canvas는 모든 Gemini 사용자가 쓸 수 있습니다.
- **개인정보:** 실제 이름·성적·연락처·비밀번호는 넣지 않습니다. 예시 내용으로 충분합니다. 「지우기·결제·공개 전엔 나한테 먼저 물어봐」라고 한 줄 말해 둡니다.
- **만든 앱은 지금은 내 컴퓨터에서만 열립니다.** 친구가 링크로 열게 하는 무료 방법은 [내 웹앱 공유하기](2회차_내웹앱_공유하기.html)에 있습니다. 기말 프로젝트에도 그대로 씁니다.
